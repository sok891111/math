# 선율이의 열칸 블록섬

설치 없이 실행하는 어린이용 더하기 탐험 게임입니다. `index.html`을 브라우저로 열거나 이 폴더에서 아래 명령을 실행하세요.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 http://localhost:4173 을 엽니다.

- 방향키/WASD, 화면의 방향 버튼, 또는 땅을 눌러 이동합니다.
- ‘다리 만들러 가기’를 누르면 목적지까지 자동으로 걷습니다.
- 파란 블록을 누르거나 반대편 틀로 끌어 옮깁니다. 다시 돌려놓을 수도 있습니다.
- 7+8, 9+6, 8+5를 10개 묶음과 남은 낱개로 바꿉니다. 손 모양 시범, 반짝이는 빈칸과 한 단계씩 바뀌는 안내가 옮길 곳을 보여 줍니다.
- 식의 왼쪽 수와 주황 블록, 오른쪽 수와 파란 블록을 같은 순서와 색으로 연결합니다. 숫자를 누르면 해당 블록이 강조됩니다. 블록 이동에 따라 `9 + 4 = 10 + 3 = ?`처럼 식이 함께 바뀌고, `처음 파란 4개 = 옮긴 1개 + 남은 3개`로 두 번째 수가 어떻게 나뉘었는지 보여 줍니다.
- 열 칸을 채운 뒤 화면의 숫자 버튼이나 키보드로 합계를 직접 입력합니다. 정답을 입력하고 확인한 뒤에만 다리가 열립니다. 그전에는 화면과 음성에 정답이 나오지 않으며, 틀리면 다시 세어 보도록 안내합니다.
- 세 다리를 완성하면 자유 블록 정원이 열립니다. 완성한 다리의 ✓를 눌러 다시 놀 수 있습니다.
- 진행, 배지, 친구 하트, 보물과 정원은 이 브라우저에 저장됩니다. ? 안내창에서 처음부터 다시 시작할 수 있습니다.
- 효과음은 상단 ♫로 켜고 끕니다. 퍼즐의 듣기 버튼은 브라우저의 한국어 음성 지원 여부에 따라 작동합니다.

## 더 많은 놀이와 보상

- 합이 10~18이 되는 `1~9 + 1~9`의 45가지 문제를 제공합니다. 두 수의 순서를 구분합니다. 친구 놀이에서는 아직 풀지 않은 문제부터 나오며, 모두 풀어도 반복해서 놀 수 있습니다.
- 첫 다리를 건너면 여우 루루의 사과 소풍, 두 번째 다리 뒤에는 곰 보보의 보석 수레, 세 번째 다리 뒤에는 토끼 모모의 당근 정원이 열립니다. 열 칸 만들기와 직접 숫자 입력은 같은 방식으로 유지합니다.
- 문제를 맞힐 때마다 큰 메달, 축하 효과, `배지 +1`과 누적 개수를 표시합니다. 자동으로 닫히지 않으며, 다음 문제·배지 앨범·섬으로 돌아가기 중에서 선택합니다. 오답에는 보상이 없고 정답을 알려주지 않습니다.
- 같은 문제를 다시 풀어도 배지가 하나 더 쌓입니다. 제출 버튼을 중복으로 눌러도 한 번의 풀이에는 하나만 적립합니다. 5·10·20·45가지 문제를 풀면 특별 배지도 열립니다.
- 상단 🏅 버튼으로 45칸 배지 앨범을 엽니다. 기존 버전의 다리 진행은 유지되며, 완료한 다리에 해당하는 배지가 추가됩니다.
- 지도 위 친구를 직접 누르거나 상단 친구 버튼을 누르면 대화할 수 있습니다. 쓰다듬기, 함께 춤추기, 친구에게 걷기, 친구 놀이를 선택할 수 있으며 하트가 저장됩니다.
- 친구 놀이를 완성하면 각 섬에 사과·보석·꽃 장식이 차례로 생깁니다. 지도 위 🎁 상자를 눌러 걸어가면 섬 보물 4종을 모을 수 있습니다.

HTML/CSS/Canvas JavaScript로 제작했습니다. 서버, 계정, 결제, 광고가 없으며 게임은 외부 라이브러리 없이 작동합니다. 웹폰트만 인터넷 연결 시 불러오며, 오프라인에서는 시스템 글꼴을 사용합니다. 모바일에서는 캐릭터를 따라 지도가 이동합니다.

## 브라우저 검증

게임 실행에는 npm 설치가 필요 없습니다. 개발용 브라우저 테스트만 실행하려면 `npm install`과 `npx playwright install chromium`을 실행한 다음, 위 서버를 켜 둔 상태에서 `npm test`를 실행합니다. 기존 Chromium을 사용하려면 `CHROMIUM_PATH` 환경 변수에 실행 파일 경로를 지정할 수 있습니다.

테스트는 미완성 다리 통행 제한, 클릭/터치/드래그, 반대 방향 이동, 틀 밖 드롭, 합계 보존, 정답 사전 노출 방지, 숫자 입력/지우기, 빈 입력 및 오답 시 진행 차단, 세 모험의 이동 경로, 정원 편집, 새로고침 후 복원과 모바일 가로 넘침을 확인합니다. `tests/adventure.cjs`는 45개 문제 전부, 이전 저장 데이터 이관, 중복 지급 방지, 배지 앨범·특별 배지, 세 친구, 지도 직접 터치, 네 보물, 재접속 후 저장과 모바일 보상 화면 가시성도 검증합니다. 화면 캡처는 `test-artifacts/`에 남습니다.

`tests/math-link.cjs`는 9+4 예제의 식·블록 순서, 색별 개수 보존, 4=1+3 분해, 되돌리기, 정답 숨김 및 모바일 입력 버튼 가시성을 검증합니다.

## 햇살 모험 — 횡스크롤 수학 게임

실행 중인 서버에서 **http://localhost:4173/platformer/** 를 열거나 `platformer/index.html`을 브라우저에서 엽니다. 기존 블록섬의 상단과 시작 창에도 ‘햇살 모험’ 링크가 있습니다.

- 노란 옷의 선율이: 좌우 방향키 / A·D 이동, 스페이스 / ↑ / W 점프. 짧게 누르면 낮게, 길게 누르면 높게 뜁니다. 모바일은 화면 아래 이동·점프 버튼을 동시에 사용할 수 있습니다.
- 고정 시간 간격의 물리 계산, 중력, 바닥/발판의 상하좌우 충돌, 카메라 스크롤, 짧은 점프 입력 유예를 구현했습니다.
- 몬스터와 닿으면 세계가 멈추고 덧셈 문제가 열립니다. 키보드 또는 숫자판으로 답을 입력합니다. 15초 안에 제출한 정답에만 몬스터 정화와 100점을 지급하며, 오답은 남은 시간 안에서 재도전합니다. 문제 아래 블록을 클릭·터치·드래그해서 열 칸을 만들거나 되돌릴 수 있으며, 나중에 풀기도 가능합니다.
- 3개 테마에 각 3종씩, 총 9종의 블록 몬스터가 있습니다. 몬스터를 모두 잡지 않아도 깃발에 닿으면 다음 단계로 갑니다. 6개 맵을 무작위로 섞어 하나씩 탐험하며, 모두 방문하기 전에는 같은 맵이 반복되지 않습니다. 맵마다 지형의 높낮이·틈·발판·장식이 다르고 스테이지 번호와 점수는 이어집니다. 덧셈 문제는 매번 새로 뽑습니다.
- 햇살 수집 10점, 월드 완료 200점. 최고 점수, 종류별 누적 처치 수, 배지 진행과 남은 문제 묶음을 별도의 localStorage 키로 저장합니다. 현재 모험은 새로고침하면 처음부터 시작하며 기존 블록섬의 저장 기록에 영향을 주지 않습니다.
- 아래로 떨어지면 마지막으로 정화한 몬스터 뒤의 안전한 위치로 돌아갑니다. 창이 비활성화되면 자동 일시정지합니다. P / Esc 또는 상단 버튼으로 쉴 수 있습니다.
- 음원, 효과음, 음성, 외부 이미지 및 외부 실행 라이브러리 없이 작동합니다. 캐릭터·지형은 Canvas에 직접 그린 픽셀 그래픽입니다.

`npm run test:platformer`로 이동·점프·착지·일시정지·문제 중 세계 정지·중복 보상 방지·6개 맵 완주·최고점 저장·모바일 입력을 검증합니다. 기존 테스트처럼 실행 중인 4173 포트의 서버가 필요합니다.

### 블록 몬스터 친구들

- 초록빛 들판: 풀빛 좀비, 이끼 크리퍼, 말랑 슬라임
- 노을빛 버섯 숲: 달빛 스켈레톤, 루비 거미, 보랏빛 마녀
- 반짝이는 하늘 정원: 별빛 엔더맨, 노을 마그마 큐브, 구름 가스트

마인크래프트 몬스터의 특징을 참고해 직접 그린 픽셀 캐릭터입니다. `platformer/monsters.js`가 종류별 이름, 대사, 크기, 이동 속도와 공통 그리기를 관리합니다. 게임 화면·문제 창·월드별 도감에 같은 캐릭터를 표시합니다. 슬라임/마그마 큐브는 통통 튀는 모습, 거미는 다리 움직임, 가스트는 떠 있는 모습, 엔더맨은 보랏빛 입자로 구별됩니다. 몬스터마다 크기에 맞는 충돌 영역이 있으며, 문제를 맞힌 종류는 현재 월드 도감에서 정화 완료로 표시됩니다. 이번 단계의 정화 여부는 현재 모험에 적용되며, 종류별 누적 처치와 배지는 다음 모험에도 유지됩니다.

브라우저 테스트는 9종 전부 실제 이동으로 조우하고 정답을 제출한 뒤, 몬스터 이름·초상화·도감 정화 상태와 월드 완료를 확인합니다.

### 블록 옮기기와 전체화면

문제를 만나면 아래에 주황 블록(첫 번째 수), 파란 블록(두 번째 수)이 바로 나타납니다. 파란 블록을 누르거나 반대편 틀로 끌어 옮겨 왼쪽 열 칸을 채웁니다. 왼쪽 파란 블록을 다시 오른쪽으로 돌려놓거나 ‘블록 처음으로’로 복원할 수 있습니다. 틀 밖으로 놓으면 이동하지 않습니다. 블록의 전체 개수와 색은 유지되고, 정답을 직접 입력해야 몬스터가 정화됩니다.

상단 ‘⛶ 전체화면’ 또는 게임 점수 옆 ⛶ 버튼으로 게임 전용 화면에 들어갑니다. 소개·도감을 숨기고 게임, 점수, 일시정지와 터치 조작을 남깁니다. 지원 브라우저에서는 브라우저 전체화면으로도 전환하며, 지원하지 않는 모바일 환경에서는 현재 창을 채웁니다. 게임 우측 상단 ×로 나갈 수 있고, 브라우저 전체화면 해제 시 일반 화면으로 돌아갑니다. 전체화면 안에서도 문제 창과 블록 조작을 사용할 수 있습니다.

`npm run test:platformer-blocks`는 블록 개수 보존, 클릭·마우스/터치 드래그, 되돌리기·초기화, 잘못된 드롭, 열 칸 제한, 정답 판정, 전체화면 전환·해제, 네이티브 전체화면 미지원 대체 모드, 휴대폰 세로/가로 배치를 검증합니다.

### 누적 처치, 배지와 랜덤 문제

- 우측 상단의 누적 처치/배지 버튼에서 잡은 몬스터 합계와 획득한 배지 수를 확인합니다. 눌러서 여는 앨범에는 몬스터·수학·보물·탐험 분류, 획득/미획득 필터, 목표별 진행률이 표시됩니다. 전체화면에서도 열 수 있고 앨범을 보는 동안 게임은 멈춥니다.
- 종류마다 1·3·5·10·20마리 목표의 45개 배지와 수학·보물·탐험 업적 22개, 총 67개 배지를 모읍니다. 빠른 정답, 연속 승리, 열 칸 만들기, 보물 수집, 다양한 맵에서의 승리 등으로 획득합니다. 배지를 누르면 희귀도·조건·획득 날짜가 나오며 획득한 배지는 대표 배지로 장착할 수 있습니다. 기존 처치 기록과 배지는 유지됩니다.
- 두 수가 1~9이고 합이 10~18인 45개 식을 무작위로 섞어 순서대로 사용합니다. 한 묶음 내 중복 및 묶음 경계에서 같은 식의 연속 출제를 방지합니다. 문제 묶음은 새로고침 후에도 이어집니다. ‘나중에 풀기’ 후 다시 만나면 새 문제가 나오고, 오답을 다시 풀 때는 현재 문제를 유지합니다.
- 브라우저 저장소를 사용할 수 없으면 현재 페이지 안에서 집계와 무작위 출제를 계속합니다. 새로고침 후 기록 보존은 브라우저 저장소가 필요합니다.

`npm run test:platformer-rewards`는 45개 식의 범위와 중복, 67개 배지 조건과 6개 맵의 무작위 순서, 저장 복원, 새 문제와 오답 재시도, 처치 중복 방지, 몬스터를 남긴 상태의 깃발 통과, 다음 단계, 전체화면 앨범, 모바일 카운터를 검증합니다.

### 15초 몬스터 대결

- 몬스터를 만나 문제 창이 열리면 15초 카운트다운을 시작합니다. 상단에 남은 초와 줄어드는 막대를 표시하고 5초 이하에서 경고색으로 바뀝니다.
- 제한 시간 안에 정답을 제출한 경우만 승리로 처리합니다. 처치 수 +1, 100점, 해당 종류의 배지 진행이 한 번만 적용됩니다. 오답 제출이나 블록 이동은 시간을 초기화하지 않습니다.
- 시간이 끝나면 몬스터가 승리합니다. 정답 입력과 블록 조작이 잠기고 처치 수·점수·배지는 증가하지 않습니다. 몬스터는 지도에 남으며 ‘다시 도전하러 가기’로 돌아가 다시 만나면 새 문제와 새 15초를 받습니다.
- 다른 탭으로 이동해도 제한 시간은 지나갑니다. 프레임 수가 아닌 실제 경과 시간으로 판정하고, 제출 순간에도 마감 시각을 확인하므로 지연된 타이머로 늦은 정답이 인정되지 않습니다. 승리·패배·물러나기로 대결이 끝나면 해당 타이머를 정리합니다.

`npm run test:platformer-timer`는 제한 시간 초과, 5초 경고, 패배/늦은 정답의 보상 차단, 마감 직전 승리, 중복 제출 방지, 재도전 시간 초기화, 타이머 정리와 모바일 배치를 검증합니다.

### iPad 터치 조작

햇살 모험 페이지는 빠른 두 번 탭으로 화면이 확대되는 동작과, 길게 누를 때 글자 선택·복사 메뉴가 나타나는 동작을 막습니다. 숫자판 연속 입력(예: 1을 두 번 눌러 11 입력), 파란 블록 연속 이동, 블록 드래그와 이동/점프 동시 터치는 유지합니다. 배지 앨범 등 긴 창은 계속 스크롤할 수 있습니다. 변경 사항은 페이지를 새로고침하면 적용됩니다.

### 몬스터 보물과 배지 수집방

정답으로 몬스터를 잡으면 그 자리에 보물 상자가 튀어 오릅니다. 가까이 가서 주우면 보석 3~6개, 몬스터별 보물 9종 중 하나, 추가 점수 120~300점을 받습니다. 첫 시도 정답과 5초 이내 정답은 더 좋은 상자로 이어집니다. 시간 초과·물러나기에는 보물이 나오지 않으며, 같은 상자는 한 번만 지급됩니다.

`sun`의 보상 화면을 참고해 큰 보물 공개 화면과 새 배지를 하나씩 펼쳐 보는 축하 화면을 구성했습니다. 수집방에서 다음 목표·진행률·희귀도·몬스터별 보물을 확인하고 대표 배지를 선택합니다. 보석·보물·배지·대표 배지는 브라우저에 저장됩니다. 새로고침하면 현재 맵과 아직 줍지 않은 상자는 초기화되므로 상자를 주운 뒤 종료해 주세요.

맵은 햇살 계단 들판, 징검다리 강변, 커다란 버섯 골짜기, 달빛 성벽 유적, 반짝 수정 동굴, 구름다리 정원으로 구성됩니다. 깃발에 도착하면 남은 몬스터와 관계없이 다음 맵으로 넘어갑니다. 탐험 배지 진행은 해당 맵에서 한 번 이상 승리했을 때만 인정합니다.

수학 문제를 푸는 동안에는 스테이지의 3분 제한 시간이 멈춥니다.

### 큰 수 덧셈과 구구단 친구들

엔더드래곤·워든·닭을 추가해 엔더 확장 몬스터를 포함해 총 18종이 등장합니다. 엔더드래곤은 검은 날개·긴 꼬리·보라색 눈, 워든은 청록색 더듬이·가슴과 갈비뼈를 픽셀로 표현했습니다. 엔더드래곤과 가스트는 공중을 순찰하며 일반 점프로 만날 수 있는 높이까지 내려옵니다.

- 엔더드래곤·워든: 두 수 모두 두 자리인 덧셈, 합은 20~40입니다. 각 수를 여러 개의 10칸 틀에 표시하며, 블록을 양쪽으로 옮기고 되돌릴 수 있습니다.
- 돼지·닭·토끼: 처음에는 2단 × 1~3, 구구단 누적 5회 성공부터 2~3단 × 1~5, 12회 성공부터 2~5단 × 1~9로 넓어집니다. `3 × 4`는 블록 3개씩 4묶음으로 보여 주며 묶음을 누르면 센 묶음의 덧셈식과 합계를 표시하고, 모두 세면 답에 써 보도록 안내합니다. 같은 수를 반복해서 더하는 식도 표시합니다.
- 정답은 직접 입력하며, 구구단은 60초, 일반 덧셈은 15초, 엔더드래곤·워든·셜커·엔더 기사는 30초 제한입니다. 보상·저장 방식은 유지합니다. 새 몬스터도 전용 보물과 종류별 배지를 제공합니다.

`npm run test:platformer-advanced`는 문제 범위, 블록 수 보존, 곱셈 묶음, 정오답 판정과 비행을 데스크톱·휴대폰 세로·가로 화면에서 검증합니다.

### 30초 보스 대결과 여러 층 점프

- 스테이지마다 몬스터는 5~8마리가 무작위로 등장합니다.
- 엔더드래곤·워든·셜커·엔더 기사는 30초, 구구단 동물은 60초, 나머지 몬스터는 15초입니다. 남은 시간 막대와 시간 초과 안내도 대결 시간에 맞게 표시합니다. 빠른 정답 보상은 두 경우 모두 실제 5초 이내 승리에만 적용합니다.
- 12개 맵마다 3층 점프 코스와 2층 쉼터가 있습니다. 80픽셀씩 높아지는 발판을 연속 점프로 오르며, 맵에 따라 계단형·지그재그형으로 달라집니다. 각 층에서 햇살을 모을 수 있고 지상 길도 이용할 수 있습니다.
- `npm run test:platformer-climbing`은 대결 시간과 보상 계산, 실제 게임 물리에서 12개 맵의 60개 발판 착지를 확인합니다.

### 엔더 몬스터와 자동 무기 교체

- 셜커, 엔더마이트와 이 게임의 창작 몬스터인 엔더 기사가 등장합니다. 셜커·엔더 기사는 두 자리 덧셈(합 20~40)과 30초 대결을 사용하고, 엔더마이트는 일반 덧셈과 15초 대결을 사용합니다. 전용 배지와 보물도 수집할 수 있습니다.
- 한 스테이지에 서로 다른 몬스터 5~8마리가 무작위로 등장합니다.
- 엔더드래곤은 기존 크기의 1.5배이며, 좌우 최대 1,300픽셀을 순찰하고 높이도 바꾸며 날아옵니다. 그림자와 보라색 입자가 따라다닙니다. 맵 가장자리에서는 비행 범위가 줄어들며, 틈 위에서 승리해도 무기 상자와 체크포인트는 안전한 땅에 생깁니다.
- 정답을 맞히면 검·활·방패 표시가 붙은 무기 상자가 나옵니다. 직접 주우면 기존 장비를 새 장비로 자동 교체합니다. 보석·점수·도감 보물·배지도 계속 받을 수 있습니다.
- 검은 1초마다 휘두르고, 활은 1초마다 앞쪽으로 화살을 쏘며, 방패는 1초마다 앞으로 밀칩니다. 공격이 몬스터에 닿으면 수학 대결을 시작하고 정답으로 정화합니다. 화살은 벽에 막히며 화면 밖으로 날아가면 사라집니다.
- 문제·보상·일시정지 화면에서는 공격도 멈춥니다. 장비는 다음 스테이지와 같은 모험의 재도전에 유지되고, ‘다시 시작’이나 새로고침 시 초기화됩니다. 화면 아래에는 현재 장비의 아이콘과 이름만 표시됩니다.

`npm run test:platformer-weapons`는 출현 수, 새 몬스터 문제 범위, 무기 교체·공격 주기·충돌·일시정지·중복 보상 방지, 드래곤 비행과 틈 위 보상을 검증합니다.

### 높은 발판의 몬스터와 원거리 공격

- 스테이지당 5~8마리 중 지상형 두 마리를 3층 코스와 2층 쉼터 꼭대기에 배치합니다. 몬스터는 자신이 올라선 발판 안에서 순찰합니다.
- 스켈레톤은 화살, 마녀는 물약, 가스트는 화염구, 셜커는 추적탄, 드래곤은 보라색 화염구, 워든은 음파를 발사합니다. 0.65초 준비 모션 후 발사하며, 종류별로 3~4.6초 간격입니다. 공격 속도와 효과는 이 게임에 맞게 조정했습니다.
- 맞으면 약 137픽셀 뒤로 밀려나고 약 37픽셀 높이로 튀어 오르며 1.1초 동안 연속 피격을 막습니다. 밀려나는 동안 벽 충돌을 적용하고 약 0.35초 후 이동 조작이 돌아옵니다. 피격 안내 문구는 표시하지 않고 충격 입자로 표현합니다. 체력이나 점수 차감은 없습니다.
- 일반 투사체는 지형에 막히고 워든 음파는 지형을 통과합니다. 문제·보상·일시정지 중에는 공격도 멈추며, 수학 대결을 시작하면 남은 투사체를 지웁니다.
- 높은 발판에서 승리하면 무기 상자는 아래쪽 안전한 땅에 생깁니다.

공격 참고: [공식 셜커 소개](https://www.minecraft.net/en-us/article/shulker), [공식 워든 원거리 공격 설명](https://feedback.minecraft.net/hc/en-us/articles/5824867258509-Minecraft-Java-Edition-Snapshot-22w15a).

`npm run test:platformer-enemies`는 여섯 원거리 공격, 준비 모션, 지형 충돌, 위층 순찰, 좌우 밀림 거리, 벽 충돌, 일시정지, 위층 정답 보상을 검증합니다.

### 희귀 무기와 전설의 드래곤 보상

무기는 모든 보물에 들어 있지 않습니다. 모든 몬스터(드래곤 포함)의 정답 보상마다 독립적으로 35% 확률로 결정하고, 보물을 주웠을 때 장착합니다. 무기가 없는 상자는 현재 장비를 유지하며 보석·점수·수집 보물을 지급합니다.

엔더드래곤의 상자는 전설 등급이며 보석 30개, 추가 1,500점, 전설의 드래곤 알 1개를 확정 지급합니다. 기본 정답 100점과 별도입니다. 보라색·금색 전용 축하 화면에 엔더드래곤 트로피와 보상 목록을 표시하고, 모인 새 배지도 이어서 펼칩니다. 드래곤 알과 보석은 기존 수집 저장 방식으로 보존합니다. 무기 확률은 드래곤도 35%입니다.

### 누적 50마리: 브리즈와 바람 점프

- 저장된 누적 처치가 50마리에 도달하면 바람 모험과 해제 배지를 얻습니다. 기존에 50마리 이상 잡은 기록도 바로 적용되며 새로고침 후에도 유지됩니다.
- 해제 전에는 브리즈와 바람 발판이 나오지 않습니다. 해제 후에는 스테이지당 5~8마리 중 브리즈가 한 마리 포함됩니다. 브리즈는 매 스테이지 중·후반의 무작위 지상 위치에 등장합니다. 현재 맵에서는 중·후반에 남아 있는 지상 몬스터 중 무작위 한 마리가 브리즈로 바뀌며, 바꿀 몬스터가 없으면 다음 단계부터 등장합니다.
- 브리즈 근처 바람 발판에서 점프하거나 바람탄을 타면 5~7층 하늘길까지 솟아오릅니다. 화면은 높이를 따라 움직이며 각 층의 보너스 햇살 세 개는 각각 50점이고, 맵 안에서 한 번씩만 수집할 수 있습니다. 발판은 아래에서 통과하고 위에서 착지합니다.
- 브리즈는 바람탄을 발사합니다. 피할 수도 있고, 맞았을 때 위로 솟아오르는 힘을 이용할 수도 있습니다. 브리즈 문제는 기존 상위 일반 몬스터처럼 합 14~18의 덧셈과 15초 제한입니다.
- 모든 몬스터의 무기 드롭 확률은 35%입니다. 드래곤의 전설 보상은 유지됩니다.

`npm run test:platformer-wind`는 49/50마리 경계, 오답 미해제, 즉시 해제와 저장 복원, 등장 제한, 12개 맵의 일반 점프와 바람 점프 및 보너스 착지를 검증합니다.


### 후반 강적 5종과 30~50 덧셈

- 위더, 엘더 가디언, 소환사, 파괴수, 피글린 야수를 추가했습니다. 매 스테이지의 5~8마리 중 새 강적이 최소 한 마리 등장합니다. 기존 브리즈 등장 조건과 위치는 유지합니다.
- 새 5종은 두 자리 수끼리 더해 **정답이 30~50(양 끝 포함)**인 문제를 냅니다. 제한 시간은 큰 수 덧셈과 같은 **30초**입니다. 기존 몬스터의 문제 범위와 구구단 60초는 유지합니다.
- 블록은 한쪽에 최대 50개까지 옮길 수 있으며, 10개씩 틀을 나누어 큰 수 덧셈을 도와줍니다.
- 위더는 공중에서 해골탄, 엘더 가디언은 광선, 소환사는 마법탄을 사용합니다. 파괴수와 피글린 야수는 지상을 순찰합니다. 공격은 이 학습 게임에 맞춰 단순화했습니다.
- 5종 모두 도감 설명, 전용 보물, 종류별 배지 5단계를 지원하며 기존 저장 기록과 함께 보존합니다.
- `npm run test:platformer-elite`로 문제 범위, 무작위 배치, 모바일 화면, 50개 블록 이동, 정오답 및 보상 저장을 검증합니다.

몬스터 종류 참고: [Minecraft 공식 엔티티 목록](https://learn.microsoft.com/en-us/minecraft/creator/documents/introductiontoentityfamilies?view=minecraft-bedrock-stable).


### 눈으로 이해하는 구구단 먹이 교실

- 돼지는 사과, 토끼는 당근, 닭은 옥수수를 접시에 똑같이 나눕니다. 한 접시의 개수와 접시 수를 색과 글로 구분하고, 이야기·설명은 20~28px 큰 글씨로 보여 줍니다.
- 테두리가 진한 다음 접시 또는 ‘한 접시 더하기’를 누르면 ‘2개에 2개를 더하면 4개’와 누적 덧셈식을 보여 줍니다. 이미 센 접시를 다시 눌러도 중복해서 세지 않습니다.
- 모두 세면 ‘2개씩 3접시, 모두 6개! 그래서 2 × 3 = 6’처럼 먹이 그림과 덧셈·곱셈을 연결합니다. 답은 아이가 직접 입력합니다.
- ‘처음부터 같이 세기’로 같은 문제를 반복하거나, ‘2개씩 3접시로 연습’으로 쉬운 문제를 선택할 수 있습니다. 두 버튼 모두 기존 60초 제한 시간을 다시 늘리지 않습니다.
- 휴대폰에서도 글자를 작게 줄이지 않고 문제 창을 스크롤해 읽고 조작합니다. 넓은 화면은 그림과 답 입력을 나란히 배치합니다.
- 참고: [IES 수학 학습 지원 가이드](https://ies.ed.gov/ncee/wwc/practiceguide/26)의 시각적 표현과 수학적 언어를 연결하는 접근을 참고했습니다.
- `npm run test:platformer-multiply-lesson`: 동물별 먹이, 터치 순서, 중복 방지, 다시 세기, 쉬운 문제 전환, 제한 시간, 휴대폰 가로·세로 화면을 검증합니다.


### 레벨 1~3, 각 6개 스테이지와 승급 테스트

현재 모험은 아래 과정으로 진행합니다. 레벨의 문제 범위는 몬스터별 과거 범위보다 우선합니다.

| 레벨 | 학습 내용 | 등장 몬스터 |
| --- | --- | --- |
| 1 · 10 만들기 | 한 자리 덧셈, 합 6~18 | 좀비·크리퍼·슬라임·여우·엔더마이트 |
| 2 · 큰 수와 작은 묶음 | 두 자리 덧셈, 합 20~40 / 2~3단 × 1~5 | 스켈레톤·거미·마녀·엔더맨·마그마·가스트·셜커·구구단 동물 |
| 3 · 강적과 숫자 마법 | 두 자리 덧셈, 합 30~50 / 2~5단 × 1~9 | 위더·엘더 가디언·소환사·파괴수·피글린 야수·엔더드래곤·워든·엔더 기사·구구단 동물 |

- 각 레벨의 6개 스테이지를 진행하면 10분 TNT 타이머가 있는 10문제 테스트를 시작합니다. 합격은 **10분 안에 10문제 완료 + 7개 이상 정답(70% 이상)**입니다. 모든 레벨의 시험은 덧셈 10문제만 출제합니다.
- 문제를 제출한 뒤에는 답을 바꿀 수 없습니다. 시간 초과 또는 점수 미달이면 TNT 충격파·블록 파편·화면 흔들림을 보여 주고, 놓친 문제 연습과 재도전으로 이어집니다.
- 시험은 새로고침 후에도 같은 문제·제출 답·마감 시각으로 이어집니다. 재도전은 새 10문제와 새 10분입니다. 스테이지를 다시 모두 진행할 필요는 없습니다.
- 레벨 3 시험까지 통과하면 레벨 1로 돌아갑니다. 배지·보물·보석·점수·햇살·장비·슈퍼 점프 보상은 유지되며 저장됩니다. 잠금 해제한 브리즈와 바람길은 모든 레벨에서 사용할 수 있습니다.
- 수학 학습 연구와 넛지 적용 근거는 [학습 설계 문서](docs/math-learning-design.md)에 정리했습니다. 동작 줄이기 설정에서는 TNT 움직임을 생략합니다.
- `npm run test:platformer-campaign`: 레벨별 출현과 문제, 6개 스테이지의 승급 차단, 10/11개 경계, 시간 초과, 새로고침 복원, TNT, 연습, 모바일 화면과 마지막 레벨 순환·보상 보존을 검증합니다.

## 🛸 관리자 페이지 및 사용자별 접속 URL 서비스 (Vercel 배포)

`sun` 프로젝트를 기반으로 관리자 페이지(`/admin`)에서 아이별 고유 접속 URL을 발급하고 관리할 수 있는 Next.js 웹 서비스 구조를 구축했습니다.

### 1. 주요 기능
- **관리자 페이지 (`/admin`)**:
  - 비밀번호 인증 (`ADMIN_SECRET`)
  - 새 사용자 추가: 아이 이름 입력 시 고유 6자리 ID(`userId`) 자동 생성
  - 사용자별 독립 URL 발급 및 클립보드 원클릭 복사:
    - ☀️ **햇살 플랫포머 (기본 게임)**: `https://<domain>/<userId>`
    - 🏝️ **열칸 블록섬 (별도 게임)**: `https://<domain>/<userId>/island`
  - 사용자 삭제 시 해당 접속 링크 즉시 비활성화 (404)
- **사용자별 맞춤 게임 화면 & 한국어 조사 지원**:
  - 접속한 아이의 이름에 맞춰 "지우의 열칸 블록섬", "반가워, 지우야!" 등 이름과 조사가 자동 치환됩니다.
  - 브라우저 로컬 스토리지 키가 사용자 ID별로 분리(`_userId`)되어, 같은 기기에서 여러 아이가 플레이해도 점수, 배지, 레벨이 섞이지 않습니다.
- **데이터 저장소 (Vercel 배포 및 로컬 겸용)**:
  - Vercel 배포 시 Supabase (`kv_store` 테이블) 연동을 지원하여 영구 저장됩니다.
  - 로컬/개발 환경에서는 `users.json` 파일 기반으로 즉시 동작합니다.

### 2. 로컬 실행
```sh
npm run dev     # Next.js 개발 서버 (http://localhost:3000)
npm run build   # 정적 자산 동기화 및 Next.js 빌드
npm run start   # 프로덕션 모드 실행
npm run test:service # 관리자 인증/유저 추가/삭제/동적 페이지 서빙 검증 테스트
```

### 3. Vercel 배포 방법
1. 저장소를 GitHub에 푸시합니다.
2. Vercel 대시보드에서 `New Project`로 저장소를 가져옵니다. (`framework: Next.js` 자동 인식)
3. **Environment Variables** 설정:
   - `ADMIN_SECRET`: 관리자 로그인 비밀번호 (미설정 시 기본값: `block-admin-2024`)
   - `SUPABASE_URL`: Supabase 프로젝트 URL (선택, Vercel 서버리스 영구 저장용)
   - `SUPABASE_ANON_KEY`: Supabase anon key (선택, Vercel 서버리스 영구 저장용)
4. 배포 완료 후 `https://<your-vercel-domain>/admin`에 접속하여 아이들을 등록하고 링크를 공유합니다.


## 창의력 수학 — 크리퍼의 고장난 다리

`/creative`에서 계정 없이 체험하고, `/{userId}/creative`에서 등록된 아이의 모험을 진행합니다. 관리자 사용자 목록에 창의력 수학 링크와 복사 버튼이 있습니다. 개인 주소는 기존 사용자 조회를 사용하며 없는 사용자는 404입니다.

```sh
npm install
npm run dev
```

로컬 체험 주소: **http://localhost:3000/creative**. 포트를 바꾸려면 `npm run dev -- -p 4190`을 실행하세요. 정적 서버(`npm run serve`)에서는 **http://localhost:4173/creative/index.html**에서 체험할 수 있습니다. 개인별 주소와 관리자 기능은 Next.js 서버가 필요합니다.

- 팩토 키즈 기본 B의 규칙 학습에서 착안한 자체 제작 퍼즐 6개입니다. AB, AAB, ABC 반복, 중간 빈칸, 다른 재료로 표현한 같은 규칙을 다룹니다.
- 방향키/A·D 또는 화면의 좌우 버튼으로 크리퍼를 직접 움직입니다. 점프는 없습니다. 재료를 게임 속 다리나 아래 설계도의 빈칸에 드래그해 놓습니다. 마우스·터치·펜에 같은 포인터 조작을 사용하며, 블록은 드래그 앤 드롭으로만 배치합니다. 클릭·탭만으로는 칸이 채워지지 않습니다. 노란 가이드는 첫 빈칸을 따라갑니다. 색과 기호를 함께 사용합니다.
- 빈칸이나 틀린 블록을 밟으면 물에 빠지고 처음 출발점으로 돌아와 안내 모달을 엽니다. 틀린 블록을 밟은 경우 직접 놓은 블록과 되돌리기 기록을 모두 초기화하고 규칙을 다시 찾도록 안내합니다. 빈칸에 빠지면 놓은 블록을 유지합니다. 시간 제한 없이 힌트·되돌리기를 사용할 수 있습니다. 창 전환 시 자동으로 쉬기 화면을 열고, 이동 입력을 해제합니다.
- 친구 캐릭터를 직접 누르면 여러 대사 중 하나를 무작위로 보여주는 대화 모달이 열립니다. 같은 대사는 연속으로 나오지 않습니다. 대화 중에는 이동이 멈추며, 다리를 완성한 후에는 건너오라는 대사로 바뀝니다.
- 반대편 친구와 보물상자에 도착하면 큰 보상 화면이 열립니다. 다리별 고유 배지 6종과 첫 완주 보석 10개·100점을 지급하며, 마지막은 전설 배지와 보석 30개·300점입니다. 완료한 문제는 다시 출제하지 않습니다. 보물방에서 획득한 배지와 잠긴 배지를 확인할 수 있습니다. 보상 화면에서 새로고침해도 중복 지급되지 않습니다. 동작 줄이기 설정은 보상의 확대·회전 효과를 생략합니다.
- 완료한 다리, 현재 단계, 블록 배치·안전 위치, 시도·힌트·낙하 횟수, 보석·점수·대기 중인 보상을 브라우저 localStorage에 저장합니다. 키는 `block-creative-bridge-v1:{userId}`이며 체험판은 `guest`입니다. **기기 간 동기화는 없으며, 새로고침하면 저장된 블록과 안전 위치에서 이어집니다.** 모든 다리를 마치면 워든의 동물 공원으로 이어지고, 전체 완료 후에는 새로운 문제를 기다리는 화면을 보여줍니다.
- 원본 파일은 `creative/`이고 `npm run dev`와 `npm run build`가 `public/creative/`로 동기화합니다. Next.js 파일 추적 설정에 HTML을 포함하여 Vercel 서버에서도 개인 페이지를 제공합니다.

검증:

```sh
npm run build
npm run start -- -p 4190
# 별도 터미널
npm run test:creative
npm run test:creative-routes
npm run test:creative-ipad
npm run test:creative-warden
```

브라우저 검증은 기본적으로 4190 포트를 사용합니다(`CREATIVE_TEST_URL`로 변경 가능). Playwright Chromium 또는 macOS의 설치된 Chrome을 사용하며 `CHROMIUM_PATH`로 경로를 지정할 수 있습니다. 라우트 검증은 빌드 후 4191 포트에서 임시 저장소를 사용하여 실제 사용자 데이터와 분리됩니다. 데스크톱·모바일 캡처는 `test-artifacts/creative-*.png`에 생성됩니다.

창의력 게임의 ⛶ 전체화면 버튼은 iPad Safari에서 platformer와 같은 CSS 게임 전용 화면을 사용합니다. 전체화면에서는 게임 영역과 이동·재료 조작만 표시하고 설계도·보물방은 숨깁니다. 지원하는 다른 브라우저에서는 네이티브 전체화면도 시도합니다. 전체화면 종료 버튼 또는 Escape로 나올 수 있습니다. 아이패드 플레이 중 이중 탭·핀치 확대, 길게 눌러 텍스트 선택·메뉴 열기를 막습니다. iPad 검증은 Chromium의 Safari 환경 모의 테스트입니다.

### 워든의 동물 공원 — 문장 완성하기

크리퍼 다리 6개를 마치면 워든의 동물 공원 5개 미션으로 이어집니다. 둥근 타원 울타리 안과 밖에 배치한 돼지·스켈레톤·보랏빛 마녀를 세고, 종류별 수·위치별 수·전체 수를 숫자 드래그로 채웁니다. 1~3단계는 네 문장, 4~5단계는 종류별 수와 몇 마리 더 많거나 적은지를 비교하는 다섯 문장으로 구성합니다. 동물과 함께 푸는 워든은 platformer/monsters.js의 MonsterArt.portrait를 그대로 사용합니다. 워든은 울타리 장면 바깥의 대화 영역에 있으며, 누르면 조언하고 오답·정답에 반응합니다. 동물을 누르면 센 표시를 남길 수 있고, 숫자를 놓아도 그 표시를 유지합니다. 각 미션을 처음 완성하면 새 배지와 보석 15개·150점을 받으며, 보상 화면에서 새로고침해도 중복 지급되지 않습니다. 총 11개 배지를 모으면 ‘더 재미있는 문제가 준비되면 또 놀러 오세요’ 화면에서 마무리합니다. 완료한 문제는 건너뛰고, 기존 다리 완료 기록도 새 워든 게임으로 연결합니다.
