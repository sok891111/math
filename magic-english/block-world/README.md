# 블록 숲

마법영어 모험과 연결할 독립 3D 블록 건축 게임이다. 기존 포켓몬 모험과 저장은 분리한다. 사용자별 블록 보상 등록·자동 수령 API는 구현했으며, 원래 마법영어 퀘스트의 지급 호출은 아직 연결하지 않았다. [블록 보상 API 연동 문서](../docs/BLOCK-REWARD-API.md)를 따른다.

## 실행

프로젝트 폴더에서 다음을 실행한다. 별도 빌드는 필요하지 않다.

```sh
npm run dev:blocks
```

접속: http://localhost:4175/block-world/

`PORT=4176 npm run dev:blocks`로 포트를 바꿀 수 있다. 일반 정적 HTTP 서버에서도 `block-world/`를 제공하면 실행된다. ES 모듈을 사용하므로 HTML 파일을 직접 더블클릭하는 `file://` 실행은 지원하지 않는다. Three.js 0.160.1은 MIT 라이선스와 함께 `vendor/`에 포함되어 게임 실행 중 CDN에 접속하지 않는다. 블록 텍스처와 효과음은 자체 생성하며 Minecraft 원본 자산을 사용하지 않는다.

## 아이패드 쉬운 조작 (기본)

새 기본 화면은 방향키 + A/B + 점프로 조작한다. `?controls=easy`로 직접 열 수 있다. 시작 화면에서 이름을 입력할 필요 없이 ‘놀러 가기’를 누르면 된다.

| 화면 버튼 | 행동 |
|---|---|
| ▲ / ▼ | 바라보는 방향을 기준으로 앞 / 뒤로 부드럽게 걷기 |
| ◀ / ▶ | 시점은 그대로 두고 왼쪽 / 오른쪽으로 옆걸음 |
| A 치기 / 놓기 | 막대기를 들면 동물 치기, 블록을 들면 초록 테두리에 한 개 놓기 |
| B 블록 / 지우기 | 막대기를 들면 블록 고르기, 블록을 들면 바라보는 블록 한 개 지우기 |
| ↑ 점프 | 이동·시점 조작과 별도로 땅에서 점프. 공중 연속 점프·비행은 불가 |
| ↶ 되돌리기 | 방금 설치·제거한 작업 되돌리기 (현재 세션 최대 50회) |
| 블록 | 그림으로 골라 바로 게임으로 돌아오기 |
| ☰ | 쉬기·계속 놀기·처음 자리로 돌아가기 |

- 이동과 시점을 분리했다. 화면을 손가락으로 드래그하거나 마우스로 누른 채 드래그해 자유롭게 둘러본다. 트랙패드의 두 손가락 스크롤로도 시점을 움직일 수 있다.
- 방향키를 짧게 누르면 조금만 움직이고, 누르고 있으면 천천히 연속 이동한다. 손을 떼면 빠르게 멈추며 한 칸 이동·90도 회전·자동 카메라 복귀는 없다.
- 한 손으로 방향키를 누르면서 다른 손으로 화면을 드래그할 수 있다. 손가락을 떼거나 터치가 취소되면 해당 입력만 해제한다.
- 화면 가운데의 실제 블록 면을 조준하고, 초록 테두리에 A로 설치한다. 설치와 파괴는 시점을 바꾸지 않는다.
- 한 칸 높이는 자동으로 올라가고 내려간다. 높은 벽·큰 낭떠러지·물속으로는 걸어가지 않는다.
- A/B는 길게 눌러도 연속으로 설치·파괴하지 않는다. 이동 중 편집은 잠시 막는다.
- 새 시작은 모든 블록 0개다. NPC 대화로 나무 원목 1~2개, 조각으로 철 1개, Stage 완료로 나무·흙·철 각 5개를 받는다. 기존 저장 수량은 보존한다. 막대기 옆 핫바와 블록 선택 화면에 실제 남은 수량을 표시한다. 다른 종류는 마법영어 보상으로 받기 전까지 0개이며 선택할 수 없다. 기존 핫바 데이터는 보존한다.
- 설치 시 1개를 쓰고 직접 설치한 블록을 지우면 돌려받는다. 자연 지형을 파도 재료가 늘어나지는 않는다. 되돌리기는 블록 수량도 함께 복구한다.
- 현재 서 있는 높이에서 세 칸 위까지 설치할 수 있다. 더 높이 만들려면 낮은 블록을 계단처럼 쌓고 올라간다. 자기 몸이나 발밑을 편집해 끼이거나 추락하지 않도록 보호한다.
- 낮으로 시작하고 낮/밤 자동 진행은 끈다. 키보드 없이 시작·이동·건축·저장·재접속이 가능하다.
- 세계 이름·고급 설정·파일 백업·기존 조작 전환은 ‘어른 설정’에 모았다.
- 키보드가 있다면 방향키·Z(A)·X(B)·Space(점프)·U(되돌리기)도 사용할 수 있다.

비행은 모든 조작 모드에서 제거했다. 이전 비행 저장은 건축물을 그대로 유지한 채 안전한 지상 위치로 내려온다.

## 기존 조작

시작 화면의 ‘어른 설정’ 또는 메뉴의 ‘어른 설정 · 백업’에서 바꾼다. `?controls=classic`로 직접 열 수도 있다. 세계와 저장은 두 모드에서 공유한다.

| 입력 | 행동 |
|---|---|
| WASD / 마우스 | 이동 / 시점 |
| Space | 점프; 물속에서 수영 |
| Ctrl 또는 W 두 번 | 달리기 |
| Shift | 웅크리기·가장자리 보호 |
| 마우스 왼쪽 / 오른쪽 | 블록 파괴 / 설치; 누르고 있으면 반복 |
| 마우스 가운데 | 바라보는 블록을 핫바로 복사 |
| 1–9 / 마우스 휠 | 핫바 선택 |
| E | 블록 인벤토리; 검색·분류·선택 |
| Esc | 메뉴 / 계속하기 |

기존 터치 조이스틱·드래그 시점·점프·웅크리기도 이 모드에서 유지한다. Pointer Lock을 지원하지 않으면 마우스 드래그 시점을 사용한다. 브라우저/OS 제약에 따라 전체 화면 기능은 제공되지 않을 수 있다.

## 기본 세계와 동물

- 새 세계는 건물·산·호수 없이 높이가 같은 잔디 평지로 시작한다. 기존 세계의 지형과 건축 기록은 자동 변경하지 않는다. 기존 사용자가 평지를 원하면 메뉴의 어른 설정에서 새 세계를 만들면 된다. 교체 전 백업도 유지한다.
- 기본으로 돼지 4마리와 닭 4마리가 나타난다. 쉬거나 돌아다니고, 물과 벽·큰 높이 차이는 피한다. 동물은 플레이어를 공격하지 않는다.
- 새 시작과 이전 저장의 첫 이관에는 공격 막대기를 기본으로 든다. 막대기는 블록 ID와 분리된 도구이며 핫바에서 언제든 다시 들 수 있다. 저장한 도구/블록 선택은 재접속에도 유지한다.
- 막대기는 오른쪽에서 준비한 뒤 화면 왼쪽까지 크게 휘두르고, 잔상을 남기며 돌아온다. 공격 중에는 몸의 이동·시점을 바꾸지 않는다.
- 막대기는 닿는 거리 3.6블록 이내에서 화면 가운데의 동물만 공격한다. 벽 너머로는 공격하지 않는다. 한 번에 체력 1, 공격 간격 0.42초이며, 맞은 동물은 깜빡이고 뒤로 밀려 달아난다.
- 돼지는 체력 3, 닭은 체력 2다. 체력이 없어지면 잠시 사라지고 12초의 실제 플레이 후 돌아온다. 보상이나 아이템 파밍은 아직 없다.
- 동물 위치·체력·재등장 대기 시간은 세계 저장/파일 백업에 함께 보관한다. 메뉴에서는 동물과 재등장 시간이 멈춘다. 이전 파일에 동물 정보가 없으면 새로 추가하고 기존 블록/핫바는 보존한다.

## 현재 기능

- 씨앗으로 재현 가능한 128 × 128 × 64 블록 세계: 들판·숲·호수·작은 집 또는 평지.
- 노출 면만 생성하는 16 × 16 청크 렌더링, 수정한 청크와 인접 청크 갱신.
- 보상으로 받을 수 있는 32종 블록과 유한 수량 보관함. 바닥 기반암은 파괴·선택할 수 없다.
- 충돌·중력·점프·달리기·웅크리기·수영·설치 시 몸 끼임 방지.
- 9칸 핫바, 전체 블록 검색·분류, 설치·파괴 효과음과 파편.
- 시야각·감도·보기 거리·전체 화면·낮/밤 설정.
- 일시 정지, 시작 지점 복귀, 자동 저장, JSON 세계 파일 내보내기·가져오기.

크리에이티브 건축을 우선 구현했다. Minecraft 전체 기능과 동등한 완성본은 아니다. 현재 물은 흐르지 않는 정적 블록이며 물을 선택하면 조준·제거할 수 있다. 무한 지형·제작·생존·적대 몬스터·레드스톤·멀티플레이·문/계단 같은 특수 블록은 아직 구현하지 않았다. 발광석은 스스로 밝게 보이는 재질이며 주변 블록에 동적 조명을 비추지는 않는다.

## 마법영어 보상 API

`npm run dev:blocks` 서버는 `POST /api/block-world/rewards`, `GET /api/block-world/rewards?userId=...`, `GET /api/block-world/catalog`를 제공한다. 지급 POST에는 서버 환경의 `BLOCK_REWARD_API_KEY`가 필요하다. 게임은 같은 사용자 코드의 보상을 자동 조회하고, 보관함과 영수증을 함께 저장해 재접속·재요청 중복 지급을 막는다. [요청 형식·ID 목록·설정·예제·한도](../docs/BLOCK-REWARD-API.md)를 참고한다.

## 저장과 백업

- 같은 기기·브라우저·접속 출처에서 5초마다, 메뉴 진입과 페이지를 떠날 때 저장한다.
- 기본 키는 `magic-english-block-world-v1`이다. `?user=개인코드`를 붙이면 코드별 저장으로 분리한다. 이는 기기 내 구분이며 로그인·접근 통제가 아니다.
- 기본 지형은 씨앗으로 다시 만들고 변경한 블록·위치·핫바·시간만 저장한다.
- 새 세계나 가져오기로 현재 세계를 교체할 때 확인을 받고, 이전 저장을 `:before-replace` 키에 한 번 백업한다. 시작 화면 또는 메뉴의 ‘교체 전 세계 복원하기’로 돌아갈 수 있다. 장기 보관은 ‘세계 내보내기’를 사용한다.
- 파일 형식·크기·블록 ID·좌표·핫바를 검증하며 잘못된 파일은 기존 저장에 덮어쓰지 않는다.
- 저장 공간 부족/차단 시 실패를 표시하고 파일 내보내기를 안내한다. 브라우저 데이터를 지우면 저장은 사라지며 서버 동기화는 없다.
- 현재 한 개인코드당 활성 세계는 하나다. 여러 세계는 파일로 내보내 보관한다.

## 검증

```sh
npm run test:blocks
# 로컬 서버 실행 후
npm run test:blocks:browser
npm run test:blocks:easy
npm run test:blocks:animals
npm run test:blocks:rewards
```

브라우저 검증에는 Playwright와 Chrome, WebKit이 필요하다. 현재 환경에서는 인접 `block-island/node_modules/playwright`도 탐색한다. 다른 환경은 `npm install --no-save playwright` 후 `npx playwright install webkit`로 준비한다. Chromium을 직접 설치했다면 `BLOCK_BROWSER_CHANNEL=chromium` 또는 테스트 실행 환경에 맞게 채널을 지정한다.

`BLOCK_WORLD_URL`로 테스트 서버를 지정할 수 있다. 테스트는 격리된 브라우저와 테스트 개인코드만 사용하며 실제 개인 기록은 읽거나 쓰지 않는다. 스크린샷은 `test-artifacts/block-world/`, `test-artifacts/block-world-easy/`, `test-artifacts/block-animals/`에 생성한다. 쉬운 모드는 iPad 가로·세로(WebKit)와 휴대폰 크기에서 짧은 탭·연속 앞뒤/옆걸음·독립 드래그 시점·자동 턱 오르기·A/B·되돌리기·정밀 위치/시점 저장 복원·이전 비행 저장 이관을 검증한다. Chromium에서는 실제 다중 터치 이벤트로 이동과 시점 동시 조작 및 터치 취소도 확인한다. 점프 버튼의 상승·착지와 시점 유지도 검증한다. 터치 검증은 브라우저 에뮬레이션이며 실제 iPad/Android 기기 검증은 별도로 필요하다.

주요 파일: `world.js`(지형·블록·충돌·레이캐스트·파일 검증), `renderer.js`(자체 텍스처·청크·3D 효과), `app.js`(입력·UI·저장), `index.html`/`style.css`(기존 메뉴·핫바·터치 UI), `easy-controls.js`/`easy-ui.css`(별도 쉬운 조작·보조 UI), `animals.js`/`animal-state.js`/`animal-renderer.js`(동물 시뮬레이션·저장 계약·블록 모델).


### 모험과 세계 바로 이동

블록 세계에 들어오면 설정 화면 없이 저장된 세계를 자동으로 이어 엽니다. 첫 방문은 평지·기본 막대기·블록 0개로 시작합니다. 읽을 수 없는 저장은 자동으로 덮어쓰지 않습니다. 모험 ↔ 블록 세계 이동에는 짧은 화면 전환과 도착 페이드가 적용됩니다. 이동 전에 저장하며 저장 실패 시 이동하지 않습니다.

남은 모든 종류의 블록이 0개이면 화면 중앙에 큰 안내창을 띄우고 ‘모험으로 돌아가 블록 모으기’ 버튼을 함께 표시합니다. 처음 입장할 때는 보상 동기화를 잠시 기다립니다. ‘조금 더 둘러볼게요’를 누르면 같은 소진 상태에서 반복 팝업하지 않으며, 새 블록을 받아 다시 소진하면 재안내합니다. 블록 보상을 받거나 설치한 블록을 회수하면 안내가 사라집니다. 상시 모험 복귀 버튼은 상단 블록·메뉴와 같은 줄에 배치해 되돌리기 버튼과 겹치지 않습니다. 수량과 관계없이 사용할 수 있습니다. 새 세계 만들기·파일 복원 등 어른 설정은 기존 메뉴에서 유지합니다.

부분 변경 단위 검증: `node --test tests/world-travel.test.js`.
