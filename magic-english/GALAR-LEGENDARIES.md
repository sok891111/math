# 자마젠타·무한다이노 추가 (2026-10-25)

## 확인한 정체와 자료

- [포켓몬코리아 자마젠타 도감](https://pokemonkorea.co.kr/pokedex?word=889): 전국도감889, 가라르의 전설. 기본 모습인 역전의 용사는 격투 타입이며 방패왕은 격투/강철이다. 이번 추가는 **역전의 용사** 한 모습이다. [소드·실드 공식 소개](https://swordshield.pokemon.com/en-us/pokemon-galar-region/zamazenta/)도 확인했다.
- [포켓몬코리아 무한다이노 도감](https://pokemonkorea.co.kr/pokedex/view/1133): 전국도감890, 독/드래곤 타입의 거대포켓몬. 이번에는 일반 모습을 사용한다.
- 능력치/앞뒤 스프라이트/종 정보/기술 기록은 PokeAPI에서 확인해 `assets/additional-pokemon.json`과 PNG로 보관한다. URL과 확인일은 `assets/galar-legendaries-source.json`에 기록한다. 게임 실행/재생성 시 외부 API에 접속하지 않는다.

자마젠타 기본 능력치는 HP92/공격120/방어115/특공80/특방115/스피드138, 무한다이노는 HP140/공격85/방어95/특공145/특방95/스피드130이다. 자마젠타는 현재 PokeAPI의 기본 모습 능력치를 사용하며 소드·실드 당시의 공격130과 구별한다. 둘 다 성별 없음, 느린 경험치 성장을 적용한다.

## 게임 통합

전설 집합은 엔더드래곤·뮤·코라이돈·자마젠타·무한다이노의5종이다. 모든16개 야생 서식지의 아침/낮/밤에서 **각각0.5%**다. 전설 전체로는2.5%이며, 전설을 제외한 맵의 출현 가중 평균 레벨을 반올림하고10을 더한다(최대100). 기존3종의0.5%, 위더1%, 포켓몬60:확장40 및 거뚱이20%/메가플라이8%/자이언트플라이2%를 보존한다. 원본 포켓몬7슬롯의 상대비중도 유지한다.

`apply-challenge-policy.cjs`는 추가 포켓몬이2종이라는 가정을 제거하고 실제 슬롯 수에 따라 가중치를 계산한다. 재생성해도 확률/평균이 누적 변하지 않으며, 추가 포켓몬 데이터·도감·그림이 유지된다. 기존 개인 저장/동료/PC/관리자 지급 영수증을 초기화하지 않는다. 관리자 포켓몬 선택 목록에도 두 종이 자동 포함된다.

두 종도 전설/보스로 분류해 포획 문제는 항상 레벨5다. 이전 저장의 낮은 문제는 비용 없이 교체한다. 전투·수학 포획·경험치/레벨업·동료/PC·첫 포획 소개·도감과 저장 복원을 기존 공용 흐름으로 처리한다.

기술은 해당 종의 원본 레벨업 기술 중 현재 엔진에서 사용할 수 있는 부분집합을 사용한다. 메탈클로·아이언헤드·포이즌테일·크로스포이즌·베놈쇼크·용의파동·다이맥스포·무한다이빔을 추가하고 기존 기술 연출 그룹에 연결한다. 메탈클로 공격 증가, 깨물어부수기 방어 감소, 독 상태에서 베놈쇼크 강화, 포이즌테일/크로스포이즌의 급소/독, HP회복도 처리한다. 모든8세대 시스템을 이식한 것은 아니다. 방패왕 변신·다이맥스/무한다이맥스·특성은 지원하지 않는다. 맹독은 현재 엔진의 일반 독, 반동/능력 하락·재충전 등이 없는 일부 강한 기술은 기존 호환 기술과 같은 단순 피해 방식이다.

## 검증

`tralalerio/`에서:

```sh
node --test tests/galar-legendaries.test.js tests/legendary-encounters.test.js tests/additional-pokemon.test.js tests/gold-encounters.test.js tests/boss-math-policy.test.js
node tests/browser-legendary-capture.mjs
```

관련16개 테스트 통과. 16맵×3시간대의 가중치 경계 전체를 검사해5종 각각0.5%를 확인하고, 레벨/재생성/유일 도감 항목/앞뒤 이미지/레벨1~100 생성/기술 효과/기존 동료·관리자 영수증 및 PC 보존을 확인한다. Chrome 브라우저에서도5종 각각 몬스터볼 선택→레벨5 수학→맵 평균+10 레벨로 포획까지 확인한다.
