# 마법영어 배역 음성 계약

`character-voices.js`가 첫 대화·반복 대화·도감·말하기 가이드의 공통 배역 기준이다. 기기 기본 SpeechSynthesis 음성으로 대체하지 않는다.

| 배역 | 기존 ElevenLabs 배우 | 고정 재생 처리 |
|---|---|---|
| 에이미·말하기 가이드 | Fena | 원래 음성 |
| 링고 | Fena | 45Hz 진폭 변조·대역 필터로 일관된 로봇 질감 |
| 미스스펠 | Bill | 저음 강조·고정 재생 속도로 악당 질감 |
| 안내 직원·버스 기사·여행객·기장·심사관 | Bill | 원래 음성 |
| 카페 점원·꼬마 친구·활빈·길동 | Fena | 원래 음성 |

화면 대사에 말하는 인물 접두사가 있으면 공동 화자 이름보다 우선한다. 일반 대화는 `dialogueCharacter`, 듣기 버튼은 `clipCharacter`, 말하기 가이드는 에이미를 명시한다. 기존 MP3는 배우가 맞을 때만 재사용한다. 새 대사는 서버의 `POST /api/character-voice`에서 고정 배우·모델·설정으로 생성하고 `.block-world-data/voices/`에 캐시한다. 같은 대사·배역·설정은 재생 때마다 다시 생성하지 않는다. 브라우저는 voiceId나 음성 설정을 선택할 수 없고 서버 키도 받지 않는다.

음성 준비 실패 시 임의의 기기 음성으로 바꾸지 않고 재생을 마친다. 다음 페이지로 넘어가면 이전 음성 요청과 재생을 취소한다. iPad에서 첫 사용자 입력으로 연 AudioContext는 반복 대화에서도 재사용한다.

단위 검증: `node --test tests/character-voices.test.js`. 외부 API는 모의 응답으로 검증하며 실제 TTS 생성 비용을 발생시키지 않는다.
