# 연두마을 → 무궁시티 순수 웹 데모

ROM/Flash/WASM/CPU 에뮬레이터 없이 HTML, CSS, JavaScript, Canvas로 실행된다. 브라우저 요청은 같은 출처의 정적 웹 파일뿐이다.

## 로컬 실행

```sh
npm run dev
```

http://127.0.0.1:4173 에 접속한다. 실행에는 npm install이 필요 없다. 로컬 서버는 소스 응답에 no-store를 설정한다. 배포 파일의 버전 쿼리도 함께 갱신해 예전 코드와 새 맵이 섞이지 않도록 한다.

방향키/WASD: 이동. Z/Enter/Space: 대화·전투 선택. X/Esc: 메뉴·뒤로. 전투 중 방향키: 선택 이동, Z/Enter: 선택/다음. 화면 아래 터치 버튼과 전투 버튼 직접 클릭도 가능하다.

## 탐색

주인공 집 1·2층, 연두마을, 공박사 연구소, 이웃집, 공박사 집, 29번 도로, 무궁시티, 무궁 프렌들리숍·포켓몬센터 1층·주민 집 3곳: 총 13개 맵.

파트너 선택 후 연두마을 서쪽으로 나가면 29번 도로에 들어간다. 도로를 따라 서쪽으로 가면 무궁시티. 원본의 맵 연결과 오프셋, 타일 및 충돌 선언을 사용한다. 일방향 턱과 건물 왕복, 안내 할아버지·지도 카드, 도구 줍기, 상점 구매를 지원한다.

## 풀밭 야생 전투

29번 도로의 TALL_GRASS 타일을 성공적으로 걸을 때 원본의 25/256 조우 확률을 사용한다. 아침 04:00~09:59 / 낮 10:00~17:59 / 밤 18:00~03:59는 브라우저 시각 기준이다.

- 아침/낮: 구구, 꼬리선, 꼬렛. 밤: 부우부, 꼬렛. 레벨 2~4.
- 원본 7개 출현 슬롯 가중치 30/30/20/10/5/4/1.
- 첫 파트너 3종과 야생 4종: 총 7종. 해당 종의 원본 능력치·성장률·기술 습득표 및 기술 48개(발버둥 포함)를 추출했다.
- 기술 선택/PP, 스피드 및 전광석화 우선도, 2세대 타입별 물리·특수 분류, 명중/능력치 단계, 급소, 자속, 타입 상성, 정수 대미지와 217~255 난수 범위.
- 울음소리·째려보기 등 능력치 변화, 독·화상·마비·수면·혼란, 보조기와 공격 기술의 효과 처리.
- 야생 포켓몬의 무작위 기술 선택과 반격, 도망 시도, 상처약 HP 20 회복.
- 몬스터볼 포획: HP/포획률, 수면/얼음 +10, 원본의 화상·독·마비 보너스가 적용되지 않는 버그를 참고한 임계값. 포획은 경험치를 주지 않는다.
- 승리 경험치, 전투 참여자 분배, 노력치, 레벨업과 기술 습득. 기술 4개가 가득 차면 교체 또는 포기를 선택한다.
- 포획한 포켓몬은 최대 6마리 파티로 들어간다. 가득 차면 저장 데이터의 보관함에 보낸다. 보관함에서 꺼내는 PC UI는 아직 없다.
- 메뉴의 포켓몬 화면에서 HP/PP 확인, 상처약 사용, 선두 변경. 전투 중 교대와 기절 후 교체.
- 전멸하면 마지막으로 이용한 포켓몬센터 또는 집으로 돌아가며, 전원 HP/PP/상태를 회복하고 소지금의 절반을 잃는다.
- 엄마/포켓몬센터에서 실제 HP/PP/상태 회복.

전투를 시험하기 위한 변경: 파트너를 받은 기존/신규 저장에 연구소 지원품으로 몬스터볼 5개를 한 번 지급하며, 무궁시티 상점에서 처음부터 200원에 구입할 수 있다. 원작의 박사 심부름 이후 도구 해금 이벤트와 다르다. 전투 종료 후 풀밭 3걸음은 재조우를 쉬도록 구현했다.

## 저장

기존 v1 키 `yeondu-web-save-v1`을 유지한다. 기존 위치, 파트너, 돈과 도구는 보존하고 새 파티 상태를 마이그레이션한다. HP, PP, 경험치, 포획 파티, 보관함, 도구 수량 및 진행 중 전투를 JSON으로 저장한다. 조우, 턴 처리, 전투 종료 시 자동 저장하며 새로고침해도 전투를 복원한다. 원작 SRAM/에뮬레이터 세이브 파일과는 호환되지 않는다.

## 한계

원작 전체를 명령어 단위로 이식한 결과가 아니다. 초기 야생 전투를 위한 웹 재구현이며 위 규칙을 소스와 비교했다. 원작 ROM과 전 상태/난수/버그의 동등성을 입증하지는 않았다. 모든 전투 효과의 처리 순서나 복합 상호작용까지 동일함을 보장하지 않는다. 전투 잔여 상태 대미지는 턴 말에 처리한다. 날씨·지닌 도구·진화·통신·트레이너 전투, 원작의 전투 사운드, 풀밭 밖 독 대미지, PC 교환 UI는 미구현이다. 소수 기술의 특수 상황(강제 교체의 레벨 판정 등)은 단순화했다. 포켓몬은 레벨업해도 진화하지 않는다. 30·46번 도로는 포함하지 않는다.

## 코드와 빌드

- `dist/engine.js`: 탐색, 파티 상태, 야생 조우와 전투 진입/복귀, 저장 검증.
- `dist/battle.js`: 순수 JS 전투/능력치/대미지/경험치/포획 규칙.
- `dist/battle-view.js`: 전투 화면, 앞뒤 스프라이트, 기술/가방/파티/결과 UI.
- `dist/app.js`: Canvas 탐색 렌더러, 입력·대화·상점·회복·저장 연결.
- `dist/assets`: 웹용 PNG/JSON. ROM 비포함.
- `build_assets.py`: 탐색 자산 변환.
- `build_battle_assets.py`: 출현표·기술·능력치·전투 앞뒤 스프라이트 변환.

자산 변환만 Python Pillow가 필요하다. 사용자/배포 런타임에는 Python/Pillow가 필요 없다.

```sh
git clone https://github.com/Narishma-gb/pokegold-kr /private/tmp/pokemon-gold-kr-research
git -C /private/tmp/pokemon-gold-kr-research checkout c90f31dadef17f033a8f1bdada701b26cef18241
python3 build_assets.py /private/tmp/pokemon-gold-kr-research
python3 build_battle_assets.py /private/tmp/pokemon-gold-kr-research
```

## 검증

```sh
npm test
npm install
node tests/browser.mjs
node tests/browser-expansion.mjs
node tests/browser-battle.mjs
```

Node 테스트 40개. 브라우저 테스트는 macOS Chrome 경로를 기본 사용하며, 다른 환경에서는 executablePath를 바꾼다. 브라우저 테스트의 난수/시각 주입은 격리된 테스트 페이지에만 적용한다. 제품에는 강제 조우/디버그 전투 UI가 없다.

## 출처

맵·스프라이트·포켓몬 데이터와 한국어 대화 일부는 공개 [한국어판 역어셈블 프로젝트](https://github.com/Narishma-gb/pokegold-kr)의 위 커밋에서 변환했다. 지도 팔레트 일부는 근사치다. `dist/assets/provenance.json` 및 `battle-data.json`에 출처를 기록한다. 엔진과 한정된 데모 이벤트는 새 코드이며, 포켓몬 및 원본 게임 자산의 권리는 각 권리자에게 있다.

## 공격 애니메이션

원본 OAM 타일 배치, 반전, 팔레트와 프레임 길이를 해석해 20개 이펙트 프레임셋을 PNG/JSON으로 변환했다. 할퀴기의 세 줄 궤적, 째려보기의 눈빛 빔, 몸통박치기의 돌진, 울음소리 파동과 꼬리흔들기를 구분한다. 불·물·풀·바람·모래·방어·회복 계열도 패턴별로 재생한다. 할퀴기는 웹 배경에서 잘 보이도록 명암을 보정했다.

전투 계산과 표시 이벤트를 분리했다. 공격자와 기술, 이전/이후 HP를 담은 이벤트를 행동 순서대로 재생하며 타격 시점에 HP 바가 변한다. 연출 중 중복 입력은 차단하고, 새로고침은 이미 계산한 결과를 유지한 채 연출만 재생한다. 모션 줄이기 설정도 지원한다.

원본 애니메이션 VM 전체를 옮긴 것은 아니다. 원본 이펙트 그래픽/프레임을 사용하되 이동 궤적, 화면 효과, 전체 템포는 웹 화면에 맞춘 근사치다. 모든 기술의 프레임 단위 일치를 보장하지 않으며 사운드는 미구현이다.

재생성: `python3 build_animation_assets.py /private/tmp/pokemon-gold-kr-research`
브라우저 검증: `node tests/browser-animations.mjs`

## 야생 조우 화면 전환

`build_transition_assets.py`는 원본 `StartTrainerBattle_SpinToBlack`의 쐐기/사분면 표를 추출한다. 20×18 타일 화면을 시계 방향의 20단계로 덮으며 최종 360개 타일 전체를 암전한다. `dist/battle-transition.js`는 조우를 발생시킨 필드 화면을 160×144 Canvas로 캡처해 팔레트 변화 → 원본 순서의 회전 마스크 → 암전 → 전투 화면/포켓몬 슬라이드 진입으로 연결한다. 전환은 약 2.3초이며 팔레트 밝기와 템포는 웹에 맞춘 근사치다. 원작의 야외 전환 패턴을 사용하며 동굴/강한 상대의 다른 전환은 이번 범위에 없다.

전환은 표시 전용이다. 이미 만들어 저장한 조우를 보여 주므로 PP/HP/턴을 소비하지 않는다. 전환 중 입력은 막고, 새로고침하면 저장된 같은 전투로 바로 진입한다. 모션 줄이기 환경에서는 반복 밝기 변화나 회전/슬라이드를 생략하고 짧게 페이드한다. 전환 자산 로딩이 실패해도 전투로 계속 진입한다.

재생성: `python3 build_transition_assets.py /private/tmp/pokemon-gold-kr-research`
검증: `node tests/browser-transition.mjs`
