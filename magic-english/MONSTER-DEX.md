# 몬스터 도감

메뉴의 ‘몬스터 도감’에서 골드 신도감 순서 251종과 Minecraft 24종을 확인한다. 목록은 7칸씩 넘기며 전체/포획 목록을 전환한다. 미발견 이름·그림은 숨기고, 발견하면 모습·타입, 포획하면 설명·분류·키·몸무게를 공개한다. Minecraft에는 개별 특징과 대표 기술을 제공한다. 분포는 실제 현재 게임의 시간대별 조우표에서 계산한다. 도감 수록이 275종 모두의 야생 출현을 의미하지는 않는다.

처음 포획한 종류만 성공 연출과 보상 대사 뒤에 소개 화면을 표시한다. 잡은 개체의 레벨·최대 HP·공격·방어·특수공격·특수방어·스피드를 표시하고 이름 짓기는 생략한다. 같은 종류 재포획은 반복 소개하지 않는다. 소개 마커는 확인할 때 삭제하므로 새로고침 시에도 개체나 볼을 중복 처리하지 않는다.

개인 저장의 `monsterDex`는 발견·포획 종을 중복 없이 영구 기록한다. 기존 기록은 파티·보관함·현재 상대·완료 트레이너로 이관하며 신규 포획 소개를 소급하지 않는다. 보관·교환으로 파티를 떠나도 도감 기록은 남는다. 이전 저장에서 이미 사라진 야생 조우 기록은 복원할 수 없다.

원본: https://github.com/pret/pokegold/blob/master/engine/pokedex/pokedex.asm 의 7행 목록·발견/포획 구분·등록 흐름을 참고했다. 한국어 데이터·그림은 `assets/monster-dex.json`의 고정 커밋과 추출 파일을 따른다. 생성: `python3 tools/build_dex_assets.py <원본 경로>`. 원본 목록/상세 구조를 웹 터치 화면으로 재구성했으며 울음소리·인쇄·이름 짓기는 제공하지 않는다.

검증: `tests/monster-dex.test.js`, Chrome 및 iPad WebKit `tests/browser-monster-dex.mjs`, 기존 전투·저장 회귀 전체.
