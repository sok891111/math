# Stage 4 · 식당의 문과 D의 주문

원작: `english_book/book_2/마법영어_4화_스토리.md`와 4화 8개 양면 원본. 양면 그림을 16개 페이지로 나누어 대화에서 사용한다.

- C 완료 → 학교 복도 식당 출구 → D 식당 입구. 기존 C 완료 저장에서도 바로 연결한다.
- 식당 입구 / 학교 식당 / 문장 연습실 / 배식대, 각 맵 친근한 NPC 최소 3명. 데이지는 앞치마·머리 묶음·국자를 가진 별도 캐릭터다.
- Door, Drink, Delicious, Dish: 각 3회 대화. 정중한 부탁에는 please를 포함한다.
- 원작의 단어만 외치는 실수와 미스스펠의 어순 마법 → 문장 기차 세 대의 낱말 순서 조합·전체 문장 말하기 → 미스스펠 3단계 대결.
- 마지막 성공 시 미스스펠 퇴장, 황금 D 배지 1회 획득. 보스 라운드와 조합 선택은 저장되어 재접속 시 이어진다.
- 식탁의 맛 표현·감사 인사 3회 → D 완료 → Egg/Eat/Enjoy 후식 예고. 핵심 경로 총 21회 발화.
- 13개 일상 대화 프로필: 방문별 3~5회 대화, 중간 재개·완료 후 주제 순환. A와 동일한 서버 서명 발화 보상. 하트는 기존 50% 감소 기준을 유지한다.
- D 조각 보상은 D 전용 보스 3개 발화와 필수 단어 발화를 서버 원장에서 확인한다. 완료 보상은 조각 영수증과 식사 3개 발화가 추가로 필요하다. 영수증 ID로 재시도 중복 지급을 막는다.
- 개인 URL·저장 키·중앙 동기화는 기존 방식 그대로다. D 전용 로컬 테스트는 `/magic-english/test/stage4`, 별도 테스트 저장·건축 프로필이며 운영 빌드에서는 404다.
- 고정 ElevenLabs 배역: 데이지 Fena, 조리사/교사 Bill, 링고 robot, 미스스펠 villain. 정적 203개 배역/문장 매핑을 준비했다.

검증: `npm run test:magic-english-stage4`, `npm run test:magic-english-stage4:browser`, 서버/API 통합 테스트 및 C 연결 회귀. 브라우저 자동 검증은 음성 인식을 모의한다. 실제 아동 발화·iPad 마이크는 실기 확인 대상이다.
