# 너도밤나무숲·금빛시티·레귤러배지

기준은 한국어 골드 역어셈블 `Narishma-gb/pokegold-kr` 고정 커밋 `c90f31dadef17f033a8f1bdada701b26cef18241`이다. 하트골드/소울실버의 두 마리 파오리 퍼즐이나 관장 파티를 사용하지 않는다.

## 원본 진행과 구현

1. 고동마을 서쪽 라이벌을 지난 뒤 기존 게이트에서 너도밤나무숲으로 들어간다. 호일의 인섹트배지가 있어야 풀베기로 숲 북쪽 길을 연다.
2. [IlexForest.asm](https://github.com/Narishma-gb/pokegold-kr/blob/c90f31dadef17f033a8f1bdada701b26cef18241/maps/IlexForest.asm)의 파오리 한 마리, 10개 원본 위치와 접근 방향별 분기를 따른다. 파오리를 주인에게 돌려보내면 숯 장인이 등장하고 HM01을 한 번 지급한다. 퍼즐 진행 위치·완료·선물은 저장된다.
3. 원본 작은 나무 (8,25)를 마주 보고 조사하면 길이 열리고 그래픽과 충돌이 함께 바뀐다. 북서쪽 출구 → 숲·34번 도로 게이트 → 34번 도로 → 금빛시티로 이동한다. 기존 상호작용 체계에 맞춰 인섹트배지+HM01 소지만으로 필드 풀베기를 허용한다. 원작의 기술 가르치기/호환성 메뉴와 맵 재진입 시 나무 재생성은 구현하지 않는다.
4. 34번 도로와 금빛 체육관의 원본 트레이너 파티·좌표·시야를 추출한다. 경찰관은 낮에는 원본 낮 대화를 하고 밤에만 도전한다. 새 서식지인 숲·34번 도로는 골드의 시간대별 원본 7슬롯과 상대 가중치를 보존하며, 기존 정책대로 포켓몬60:확장40, 뮤·코라이돈 및 보스의 조우 비율을 적용한다.
5. [GoldenrodGym.asm](https://github.com/Narishma-gb/pokegold-kr/blob/c90f31dadef17f033a8f1bdada701b26cef18241/maps/GoldenrodGym.asm)과 [parties.asm](https://github.com/Narishma-gb/pokegold-kr/blob/c90f31dadef17f033a8f1bdada701b26cef18241/data/trainers/parties.asm)의 꼭두: 삐삐18(연속뺨치기/흉내내기/앵콜/손가락흔들기), 밀탱크20(구르기/헤롱헤롱/짓밟기/우유마시기). 상금2000은 전투 정산 때 한 번 지급한다. 기존 수학 정책대로 두 상대 모두 마지막 타격에 레벨5 정답이 필요하다.
6. 승리만으로 배지를 지급하지 않는다. 꼭두가 울고 → 아래 (8,5)로 내려가 트레이너 이야기를 듣거나 바로 아래 트레이너에게 말하고 → 꼭두에게 다시 말하면 레귤러배지+TM45를 한 번 받는다. 중간 상태도 복원되며 재대결/중복 상금을 막는다.
7. 꽃집에서 레귤러배지를 보여 주면 꼬부기물뿌리개를 한 번 받는다. 35·36번 도로/꼬지모/인주시티는 다음 장으로 남긴다.

밀탱크의 구르기는 연속 명중마다 위력이 두 배, 최대5회, 빗나감/행동 불능/교체 시 해제, 연속 중 기술 고정과 최초 사용만 PP 소모를 처리한다. 웅크리기 사용 후 구르기 강화도 반영한다. 우유마시기는 최대HP 절반을 회복하며 잠들지 않는다. 헤롱헤롱은 원본 Attack DV 성별 조건과 교체 해제를 적용한다. 앵콜의 임시 기술 고정, 흉내내기의 전투 중 기술 복사와 종료 복구, 현재 기술 데이터 안에서의 손가락흔들기도 지원한다. 전체 2세대 기술·성별·AI의 완전한 동등성을 뜻하지는 않는다.

## 범위와 저장

맵58개(+12), 트레이너65명(+15), 육상 서식지16개(+2)다. 금빛 포켓몬센터의 기존 회복 연출·PC·전멸 복귀, 백화점1~2층의 기존 상점, 자전거 가게의 자전거 지급, 라디오타워1층의 원본5문제(예/예/아니요/예/아니요)와 라디오카드 지급, 게이트 TM12, 숲 TM02, 숯 굽는 집의 목탄을 지원한다. 새 맵도 원본 악보 기반 음악과 마을 지도 위치에 연결한다.

추가된 지도: IlexForest, Route34IlexForestGate, Route34, GoldenrodCity, GoldenrodGym, GoldenrodPokecenter1F, GoldenrodBikeShop, GoldenrodFlowerShop, GoldenrodDeptStore1F, GoldenrodDeptStore2F, RadioTower1F, DayCare.

자전거는 중요 도구 지급까지이며 탑승 기능은 없다. 키우미집은 방문/안내만 가능하고 맡기기·번식은 지원하지 않는다. 라디오카드는 퀴즈 보상 기록이며 방송 튜닝/추첨은 없다. 백화점3층 이상·엘리베이터, 지하통로, 게임코너, 리니어역 등 추가 시설의 출입구는 기존 미구현 경계 정책대로 막는다. 맵 그림은 기존 정적 변환기를 사용하며 원작 ROM 화면과 모든 팔레트·타일 표현이 동일하다고 주장하지 않는다.

새 `third-badge.js`가 이벤트를 처리한다. 기존 개인별 저장 키와 동료/도구/박스/관리자 지급 영수증을 유지하며 과거 세이브 초기화가 필요 없다. 확장 종·추가 몬스터 자산을 재생성 파이프라인에서 보존한다. 관리자 지급 기능은 이 장의 센터 PC에서도 그대로 이용한다.
