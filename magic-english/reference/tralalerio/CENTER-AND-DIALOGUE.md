# 센터 회복과 생각 탐험 대화

## 원본 확인

기준은 한국어 골드 역어셈블 소스 커밋 `c90f31dadef17f033a8f1bdada701b26cef18241`이다.

- `engine/events/std_scripts.asm`: 간호사의 치료 여부 질문, 왼쪽 방향 전환, 파티 회복, 연출 후 인사
- `engine/events/heal_machine_anim.asm`: 기계 타일 2개와 볼 6개까지의 OAM 좌표, 한 마리마다 30프레임 대기, 10프레임 간격의 팔레트 회전 8회
- `gfx/overworld/heal_machine.png`, `.pal`: 실제 회복 기계의 표시등·볼 타일과 네 가지 팔레트 상태
- `audio/music/healpokemon.asm`: 템포 144, 원본 3트랙의 음표·쉼표·피치 슬라이드
- `audio/sfx.asm`: 볼이 놓일 때의 `Sfx_SecondPartOfItemfinder`

`tools/build_healing_assets.py`가 타일 4장과 출처·배치·시간 JSON, 회복곡 WAV를 생성한다. 기계는 별도의 대형 화면으로 바꾸지 않고 기존 센터 맵 위에 원본 OAM 간격으로 그린다. 화면 카메라에 맞춘 기계의 월드 좌표는 `source.json`에 기록한다.

간호사가 왼쪽으로 돌아서고, 실제 파티 수만큼 볼이 하나씩 올라간 뒤, 회복곡과 기계 색 변화가 재생된다. 마지막에 간호사가 돌아서 인사하고 치료가 끝났음을 알려 준다. 원본 음표를 바탕으로 Web Audio용 파형·엔벌로프를 합성했으며 Game Boy 하드웨어 오디오를 에뮬레이션한 녹음은 아니다. 공공 원본의 그래픽·순서·프레임을 사용하고 웹 카메라와 오디오 환경에 맞춰 표시한다.

회복 시작 시 원본처럼 파티 전체의 HP·PP·상태 이상을 회복하고 `state.healing`을 저장한다. 새로고침하면 같은 파티 수의 표시 연출을 재개하며 돈·볼·파티를 바꾸지 않는다. 연출 중 이동·메뉴·불러오기·재시작 입력을 막는다. 저장은 회복 마커까지 함께 보관한다. 기기에 소리가 허용되지 않아도 회복은 완료되며 소리 끄기 버튼도 있다. 모션 줄이기에서는 팔레트 점멸 없이 짧은 순서 표시를 사용한다.

## 7살을 위한 대화

게임을 완성해야 공부하는 구조 대신, 마을에서 작은 것을 발견하고 같이 생각하도록 구성했다. 진행과 무관한 일반 주민은 `npc-dialogue.js`의 짧은 한국어 대화를 사용한다. 스토리·도구·배틀·회복·상점·교환 역할이 있는 NPC는 `chapter.js`와 `functional-npc.js`, 전용 서비스 처리기로 먼저 처리하며 원래 기능을 유지한다. 개인 링크의 아이 이름을 계속 사용하므로 선율이의 링크에서는 선율이라고 부른다.

기본 구조는 발견 → 제안 → 선택한 생각 놀이 → 방법 힌트 → 다시 탐험이다. 한 대화는 짧은 2쪽으로 나누고, `같이 생각해 볼래요` 또는 `모험하러 갈래요`를 고를 수 있다. 놀이를 틀려도 벌점·HP 감소·아이템 소모가 없고, 힌트를 보고 다시 해보거나 바로 모험으로 돌아갈 수 있다. 칭찬은 “똑똑하다”보다 “묶음을 찾았네”, “하나씩 세었네”처럼 실제 시도에 맞춘다.

- 엄마: 틀려도 다시 생각해 볼 수 있다는 안내와 탐험 이야기 나누기
- 공박사·연구원: 첫 동료와 생각의 힘으로 기술을 쓰는 방법
- 마을 선생님: AB 반복·분류·색과 모양 비교
- 길과 물가의 친구: 보석을 지나는 길·하나씩 세기·주변의 무늬
- 집 안 주민: 도형 회전·빈 수 찾기·다른 풀이 방법
- 센터 주민: 휴식·거울 대칭·풀이 방법 말하기
- 가게: 실제 물건과 가격을 살펴보고 필요한 것을 선택하기

길 안내, 파트너 선택, 지도 카드, 도구 구매와 회복 등의 게임 진행 기능은 유지한다. NPC 대화가 전투의 수학 문제를 대신 풀거나 정답 보상을 자동 지급하지 않는다.

## 검증

`tests/healing.test.js`: 원본 OAM/대기 시간/음악, 1~6마리 표시 순서, HP·PP·상태 회복, 저장 검증과 이동 잠금, NPC 전체의 짧은 대화 및 생각 놀이 연결.

`tests/browser-healing.mjs`: 선율 이름의 실제 간호사 대화, 1·3·6마리 회복, 기계 색 변화 8회, 중간 새로고침, 모바일/모션 줄이기, 선택형 NPC 놀이의 무벌점 재도전.

기존 탐색·구매 테스트도 새 확인 대화와 회복 완료를 실제로 거치도록 갱신했다. 실행은 루트 `npm run test:tralalerio`, 서버 실행 후 `npm run test:tralalerio-browser`다.
