# 피카츄와 첫 윙배지

## 시작과 저장

새 사용자·첫 동료가 없는 구형 기록·메뉴의 처음부터 다시는 `Game.startAdventure()`를 통해 공박사 연구소(ElmsLab)의 원본 좌표 (4,6)에서 피카츄 Lv.5, 몬스터볼 5개로 시작한다. 원작 골드는 공박사 연구소이며 오박사는 포켓몬 할아버지 집에 등장한다. 기존 동료나 전투가 있는 저장 기록은 강제로 초기화하지 않는다. 개인별 저장 키는 유지한다.

## 원본 기준

원본 소스 `Narishma-gb/pokegold-kr`의 `c90f31dadef17f033a8f1bdada701b26cef18241`에서 맵 블록, 타일, 충돌, 연결 방향·오프셋, 출입구, NPC·도구 좌표, 기술, 종족값, 출현표 및 트레이너 파티를 추출했다. ROM이나 원본 게임 전체의 스크립트를 실행하는 구현은 아니다.

31개 맵:
- 기존 13개: 연두마을·집·연구소, 29번 도로, 무궁시티와 건물.
- 추가 18개: 29·46 게이트, 46번 도로, 30번 도로와 두 집, 31번 도로와 도라지 게이트, 도라지시티·숍·센터·체육관·포켓몬 학원·주민 집 두 곳, 모다피탑 1~3층, 어둠의 동굴 도라지 입구.

원본 진행을 짧은 안내로 연결한다: 연구실 → 무궁시티 → 30번 도로 포켓몬 할아버지(알·도감, 회복) → 돌아오는 라이벌 대결 → 연구실에 알 전달 → 30번 도로 북행 → 31번 도로 → 도라지시티 → 비상. 30번 도로의 처음 대결 중인 NPC는 알 전달 후 사라진다. 모다피탑은 원본 골드처럼 체육관 전 필수 조건으로 강제하지 않는다.

도라지 관장 비상은 원본대로 구구 Lv.7(몸통박치기·진흙뿌리기), 피죤 Lv.9(몸통박치기·진흙뿌리기·바람일으키기)을 쓴다. 17명의 현지 트레이너와 초반 라이벌 1회, 총 18개 파티를 등록했다. 트레이너의 포켓몬을 포획하거나 트레이너에게서 도망칠 수 없다. 각 상대를 쓰러뜨릴 때 경험치를 받고 다음 포켓몬을 내보내며, 마지막 상대를 이겨야 승리 처리한다. 비상 승리 후 상금 900원·윙배지·TM31을 한 번 지급하고 체육관 트레이너의 완료 상태를 저장한다. 모다피탑 장로 승리 시 HM05를 보관한다.

도라지 센터에서도 기존 회복 애니메이션을 사용하고, 마지막 회복 센터를 전멸 복귀 지점으로 저장한다. 야생 포켓몬은 각 지역 원본 시간대·레벨 슬롯을 40%, 기존 마인크래프트 24종을 60%로 합친다. 초기 챕터 전체는 초급 수학을 유지한다. 정답 공격 후 성공 대사, 오답 점프 후 실패 대사와 상대 행동도 유지한다.

## 웹 입력

게임 문서 전체에 `touch-action: manipulation`, `user-select: none`, iOS touch callout 및 이미지 드래그 해제를 적용한다. dblclick·contextmenu·selectstart·dragstart·Safari gesture 이벤트를 취소한다. 터치 버튼·퍼즐 드래그·페이지 스크롤과 키보드 조작은 유지한다.

## 범위와 차이

첫 체육관 구간의 지도와 파티 구성을 원본 기준으로 확장한 것이다. 기존의 피카츄 시작·마인크래프트 조우·수학 공격·아이용 대화는 의도된 변경이다. 원본 전체와 완전히 동일하다고 주장하지 않는다. 원본 스크립트 인터프리터, 전화·통신·NPC 이동 스케줄·알 부화·진화·기술머신 사용 UI 등 모든 세부 시스템을 재현한 것은 아니다. 도라지 이후 32·36번 도로, 검은먹 쪽 동굴 출구와 센터 2층 통신실은 이번 범위 밖이다. 지도 팔레트와 일부 전투 효과는 기존 웹 엔진의 근사 표현을 사용한다.

## 재생성 및 검증

`build_assets.py`는 31개 맵을 생성한다. 기존 전투 생성기와 Minecraft 생성기를 실행한 다음 `build_first_badge.py`가 종·기술·출현표·트레이너와 도구 메타데이터를 추가한다. `rebuild-assets.cjs`가 이 순서를 보장한다. 공개 파일은 `scripts/sync-public.cjs`로 복사한다.

`tests/first-badge.test.js`: 새 시작·구형 저장, 도보 연결·알 진행, 원본 관장 파티, 포획/도주 차단, 여러 상대·교대 저장, 중복 없는 상금·배지, 도라지 회복 복귀, 모든 조우 60:40.
`tests/browser.mjs`: 실제 새 접속·모바일 시작과 브라우저 제스처 차단.
`tests/browser-first-badge.mjs`: 실제 키보드로 연구소부터 비상까지 이동하고 두 상대·중간 재접속·배지를 검증한다. 전투 테스트의 고레벨 파티와 난수 주입은 격리된 테스트 저장에만 사용한다.

## 트레이너 발견 연출

`SeenByTrainerScript`와 `TrainerWalkToPlayer`를 확인해 시야 진입 → 원본 16×16 느낌표 30프레임 → 인접 칸까지 걸어오기 → 플레이어가 마주보기 → 도전 대사 → 배틀 전환을 적용했다. 플레이어가 먼저 말을 걸면 원작처럼 발견 느낌표 없이 도전 대사로 시작한다. 벽·다른 NPC 너머는 감지하지 않고, 이미 이긴 트레이너는 자동으로 재도전하지 않는다. 접근 중 `trainerEncounter`를 저장하며 새로고침해도 같은 연출을 재개하고 턴·PP는 소비하지 않는다. 스토리 개편의 별도 검토안은 `STAR-PATH-STORY-REVIEW.md`에 정리했다.

알 전달 입장 이벤트·기능 NPC 우선 처리·롱스톤 교환은 `FUNCTIONAL-NPCS.md`를 따른다. 별빛길 스토리 개편은 현재 적용하지 않고 원본 미션을 유지한다.

무궁시티 라이벌은 원본 `CherrygroveRivalSceneNorth/South`의 플레이어 느낌표 15프레임·대기 15프레임 뒤, (39,6/7)에서 왼쪽 5칸 이동해 (34,6/7)에 멈춘다. 접근 중 저장 마커는 일반 트레이너와 같은 경로로 검증·복원하고, 기존 라이벌 대사 뒤에 배틀을 시작한다.

트레이너 도전 대사는 각 원본 맵의 SeenText를 introPages로 추출한다. 시야 조우와 직접 대화에서 같은 원본 대사를 사용하며, 여러 페이지도 전투 전에 모두 표시한다.
