# 공개 교재 자료와 게임 문제 유형

2026-10-17 확인. 팩토는 매스티안의 **키즈 기본 B**, 원리셈은 2023년 개정 **초등 1학년 1권**을 기준으로 했다. 전체 유료 본문을 열람한 것은 아니며, 공개 교재 소개·목차·출판사 평가자료로 확인 가능한 범위를 분석했다. 아래 문제는 학습 개념을 바탕으로 새로 생성하며 책의 문항·삽화·페이지를 복제하지 않는다.

## 팩토 기본 B

- 출판사: https://www.mathtian.com/book/book_content.aspx?idx=6
- 영역 설명: https://www.mathtian.com/book/book_math.aspx
- 개정판 목차: https://m.yes24.com/goods/detail/128120996

| 학습 영역 | 현재 방식으로 풀 수 있는 유형 | 반영 |
| --- | --- | --- |
| 규칙 | 반복과 관계 파악, 공통 속성 선택, 줄과 칸의 변화 예측 | 기존 pattern·classify·analogy·sequence + 신규 array_rule |
| 기하 | 동일 도형 식별, 부분 그림 완성, 거울과 대칭, 도형 조작 | 기존 mirror·rotate + 신규 shape_match·shape_complete |
| 문제해결 | 조건 읽기, 조각을 실제로 놓아 보기, 표로 수량 정리, 경로 탐색 | 기존 logic·bond·path + 신규 table_count |

새 기하 문제는 3×3 칸 그림을 비교하거나 직접 칸을 켜서 푼다. 배열은 2×2/3×3 규칙 격자, 표 읽기는 장소별 물건 수량의 행·열 합으로 구현했다. 책의 모든 도형 퍼즐·직접 조작 활동을 그대로 재현한 것은 아니다.

## 원리셈 초등 1학년 1권

- 목차와 개정판 확인: https://m.yes24.com/goods/detail/64390269
- 출판사 공개 평가자료: 1000math.com의 「원리셈 1학년 1권 총괄 테스트」 1·2면(공개 다운로드 검색 결과에서 확인).
- 범위: 받아올림/받아내림 없이 두 자리 수를 다루는 덧셈·뺄셈. 6주 구성으로 한 자리/몇십 연산에서 두 자리 연산으로 나아가고 덧셈과 뺄셈 각각 연습 단계를 둔다.
- 공개 평가에서 수 모형, 가로·세로 계산, 계산 규칙, 빠진 수, 틀린 계산 고치기, 상황에 맞는 합·차 문제를 확인했다.

| 게임 유형 | 구성과 풀이 |
| --- | --- |
| place_value | 십 막대·일 점을 세어 숫자 조각 배치 |
| add_single | 두 자리와 한 자리 덧셈, 받아올림 유무 혼합 |
| add_tens | 10 단위의 묶음끼리 더하기 |
| add_two | 두 자리끼리 덧셈, 받아올림 유무 혼합 |
| add_carry_single / add_carry_two | 반드시 받아올림이 생기는 한 자리/두 자리 덧셈 |
| add_story | 보석을 합치는 이야기 덧셈 |
| calc_puzzle | 빈 연산항, 일정한 수만큼 변하는 계산 경로, 계산 오류 수정, 짧은 보석·열매 문장제 중 무작위 |

초급은 십 막대·일 점으로 수량을 보여 주고, 2단계는 숫자 중심으로 풀게 한다. 사용자 요청에 따라 교재의 원래 범위에서 확장해 받아올림 덧셈을 포함하며 뺄셈은 출제하지 않는다. 답은 두 난이도 모두 0~99이며 힌트에서 낱개 10개를 십 묶음 하나로 바꾸는 과정을 설명한다. 세로셈 전용 UI는 따로 만들지 않았으며 가로식과 수 모형으로 푼다.

## 게임 계약

기존 12종 + 신규 12종 = 총 24종을 동일 무작위 풀에서 선택하고 직전 유형은 제외한다. 난이도는 초급/2단계 50:50, 공격 시 문제 등장 확률은 기존 50%를 유지한다. 정답은 기존 강력한 공격, 오답·넘기기는 기존 턴 소모를 유지한다. 생성 시드·난이도·답 배치·힌트는 사용자별 저장에 포함된다.
