# 7세~초1 추론 연산과 덧셈 범위 (2026-10-25)

## 자료 확인과 적용 범위

[KEDI 수학 영재성 검사도구 소개](https://ged.kedi.re.kr/intro/gedinfo/intro4_3.do)는 교육과정을 벗어난 선행 지식보다 조건의 규칙 추론, 가역적 사고, 수학적 문제해결 전략을 강조한다. 이 페이지의 공개 문항은 중1 예시이므로 이를 7세 기출로 사용하거나 그렇게 소개하지 않는다. 국내 영재교육원의 공개된 7세~초1 기출 묶음을 확인한 것은 아니다.

연령별 실제 과제는 Cambridge NRICH의 [Addition and Subtraction: Age 5–7](https://nrich.maths.org/curriculum/addition-and-subtraction-age-5-7)을 확인했다. 이 자료에는 빠진 숫자, 같은 양의 식, 목표 합의 짝, 연산 경로, 수 배열/조건 추론 등이 제시된다. [What Could It Be?](https://nrich.maths.org/problems/what-could-it-be)는 덧셈식의 가려진 숫자, [Heads and Feet](https://nrich.maths.org/problems/heads-and-feet)는 동물 수와 다리 수의 두 조건, [What Was in the Box?](https://nrich.maths.org/problems/what-was-box)는 입출력 규칙 추론을 다룬다. [Find the Difference](https://nrich.maths.org/problems/find-difference)는 아래 두 수의 관계로 위 칸을 만드는 수 배열 과제다.

문항 문구/그림/정답을 복사하지 않고 이 학습 개념과 연령 범위를 바탕으로 자체 난수 생성기를 만들었다. 수 피라미드는 이웃한 아래 두 수의 합이라는 규칙을 명시한 별도 문제다. 다음 유형이 특정 국내 영재원의 실제 입학 기출이라는 의미는 아니다. 레벨3~5는 게임 내 상대 난이도로, 큰 숫자를 쓰기보다 조건 연결/역산 단계 수를 늘린다.

## 추가6유형

| id | 표시 이름 | 레벨 | 요구하는 연산과 추론 |
|---|---|---|---|
| equal_sum | 같은 합의 빈 수 찾기 | 3/4/5 | 등호 양쪽 비교, 빈 수 역산.5에서는 △+△로 △를 찾은 뒤 □+△의 식에 대입해 □를 구함 |
| sum_pyramid | 수 피라미드의 빈 수 | 3/4/5 | 아래 이웃한 두 수를 더해 윗수 만들기.3은 꼭대기,4는 아래 끝,5는 아래 가운데를 역산 |
| reverse_steps | 처음을 찾는 거꾸로 연산 | 3/4/5 | 넣고 꺼낸 행동을 역순/반대 연산으로 되짚기.2→3→4단계 |
| digit_sum | 덧셈식의 숨은 숫자 | 3/4/5 | 일/십의 자리, 받아올림과 전체 식 검산 |

단일 수를 고르는 기존 선택/드래그/교체/초기화/힌트/채점 UI를 사용한다. 피라미드와 연산 경로는 전용 그림을 추가했다. 피라미드의 …는 스스로 계산할 중간 칸, ?는 답으로 고를 한 칸이다. 힌트는 풀이 방향만 안내하며 실제 답·중간 합을 공개하지 않는다. 일반전 최대4, 관장/전설5 정책을 보존하며 target_pairs는5를 지원하지 않아 보스 문제 풀에서 제외된다.

## 덧셈 상한

세 자리 합이 나오지 않도록 **합99 이하**로 제한한다. 기존 덧셈/받아올림/문장제/계산 퍼즐/표 합계와 신규 연산의 명시적 덧셈 단계 모두를 검사한다. 세 수를 더하는 문제도 중간 합과 최종 합을 함께 제한한다. 계산 실수 찾기의 틀린 식에도100이 표시되지 않게 한다. 보기 숫자도99 이하로 제한한다.

`addition-policy.js`가 additionChecks/ADDITION_MAX=99로 출제 직전 검사하고, 범위를 벗어나는 문제는 같은 시드 난수 흐름에서 결정적으로 다시 생성한다. 상한을 맞추기 위해 정답만 잘라내거나 식과 정답을 다르게 만들지 않는다. 기존 저장된 덧셈 문제는 additionVersion=2로 비용 없이 한 번 교체하며 다른 유형은 이 정책 때문에 초기화하지 않는다. 별도의 전체 난이도 버전 변경 없이 적용한다.

문제 개발실도 같은 생성기/판정을 사용하며 실제 모험 기록에 접근하지 않는다. 활성 유형은32→38개다.

## 검증

루트에서 `npm run test:tralalerio-early`:

- 신규6유형/각 레벨1000개를 독립 계산식으로 검산, 유일한 정답 보기4개/정답 교체/시드 재현/음수 없는 연산 단계 확인.
- 기존/신규 덧셈 전 유형 각 레벨1000개에 대해 합99 이하와 표시 식의 범위를 확인.
- 일반/전설 공격·포획 문제 풀에 실제 포함, 정답 후 저장 복원/제출, 이전 저장 문제의 무료 이관과 중복 이관 방지 확인.
- 기존 문제 정답 무결성과 보스 출제 정책까지 관련11개 테스트 통과.

`node tralalerio/tests/browser-early-arithmetic.mjs`: Chrome/WebKit의390px·768px 터치 화면에서6유형의 낮은/높은 레벨, 그림/연산 경로, 힌트·초기화·오답선택 후 정답 교체·실제 제출, 가로 넘침 방지 및 모험 저장 보존을 확인했다. 이번 작업에서는 전체 게임 테스트를 실행하지 않는다.

개발실: `/tralalerio/math-lab.html?type=equal_sum&grade=3&seed=12345`. 유형 선택에서6종을 고르고, 레벨과 시드를 바꾸어 재현할 수 있다. 예: `?type=sum_pyramid&grade=5&seed=12345`, `?type=heads_feet&grade=5&seed=12345`.

2026-10-25: 대화로 숨은 수 찾기와 숫자 카드 조건 세기에 레벨5를 추가했다. 대화는 범위·홀짝·자리 숫자의 합을 결합하며 유일해를 보장한다. 카드 문제는 두 친구의 선택 규칙을 따로 적용한 뒤 겹치는 카드를 한 번만 세는 문제다. 같은 합의 빈 수5는 두 식의 연결 추론으로 보강했으며 equalSumVersion=2로 기존 저장 문제를 비용 없이 교체한다. 세 유형 모두 개발실 grade=5 및 보스 공격/포획 풀에서 사용할 수 있다.
