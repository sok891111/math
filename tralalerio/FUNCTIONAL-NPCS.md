# 원본 미션과 기능 NPC

사용자의 후속 요청에 따라 원본 알 전달 진행을 유지한다. 수학 이야기를 일반 주민에게 적용하면서 미션·게임 기능까지 덮어쓰지 않도록 `storyInteraction` → 기능 처리 → 일반 주민의 선택형 수학 대화 순서로 처리한다.

## 30번 도로의 인물들

원본 `Route30.asm`의 `YoungsterJoey_ImportantBattleScript`는 두 트레이너와 두 꼬렛이 서로 대결하는 장면이다. 이 장면의 NPC는 플레이어를 향한 시야 배틀 대상이 아니다. 말을 걸면 몸통박치기 대결과 오른쪽 길 안내를 보여준다. 알을 공박사에게 전달하면 `EVENT_ROUTE_30_BATTLE` 장면의 NPC가 사라지고, 별도 `TrainerYoungsterJoey`(오성)가 일반 트레이너로 나타난다. 강제 해제나 수학 정답 플래그로 우회하지 않는다.

## 미션 흐름

1. 30번 도로에서 오른쪽 길을 따라 북동쪽 포켓몬 할아버지 집에 들어간다.
2. 최초 입장 시 알 지급·오박사 도감 지급·회복 이벤트를 자동 실행한다. `items.MYSTERY_EGG=1` 및 진행 플래그를 저장한다. 오박사에게 직접 말을 걸어도 일반 수학 대화가 나오지 않는다.
3. 집을 나와 30번 도로로 돌아오면 공박사의 도난 사건 전화가 나온다.
4. 돌아오는 무궁시티 길목에서 라이벌과 대결한다. 패배하더라도 원본 흐름처럼 연구소에서 이야기를 이어갈 수 있다.
5. 연구소로 돌아오면 경찰관의 사건 확인 대사가 나오고, 공박사에게 말을 걸어 알을 전달한다.
6. 중요한 물건에서 알을 제거하고 `eggDelivered`를 저장한다. 30번 도로의 대결 장면이 사라지고 일반 트레이너가 나타난다. 도라지시티로 향할 수 있다.

구형 저장에서 알을 받은 플래그만 있고 물건 기록이 없으면 실제 중요한 물건 기록을 복구한다. 이미 전달한 알은 다시 만들지 않는다. 새로고침으로 알·도구가 중복 지급되지 않는다.

## 기능 구분

| 역할 | 처리 |
| --- | --- |
| 공박사·할아버지·오박사·경찰 | 알·도감·도난 사건·전달 및 다음 목적지 안내 |
| 트레이너·관장 | 원래 파티로 배틀, 승리 상태·배지·상금 |
| 간호사·점원·엄마 | 기존 회복·구매·집 회복 기능 유지 |
| 연구소 조수 | 상처약 1회, 알 전달 후 몬스터볼 5개 1회 |
| 열매 집 주민·열매나무 | 실제 열매 지급, 나무는 하루 한 번 수확 |
| 교환하는 집의 Kyle | 파티의 모다피와 같은 레벨의 롱스톤 교환, 중복 교환 방지 |
| 학원·체육관 안내·포획 안내 선배 | 게임 규칙과 타입·포획 설명 |
| 회복 장치 | 파티 HP·PP·상태 회복 |
| 일반 주민 | 선택형 창의력 수학 대화 |

현재 지원 지역에서 기존 전용 기능은 우선 유지하고, 기능 NPC의 처리되지 않은 분기는 원본 맵의 대사나 게임 안내로 처리한다. 그 분기를 수학 퀴즈로 대체하지 않는다. 원본 ROM의 모든 이동·음악·전화 UI를 에뮬레이션하는 변경은 아니며, 미션 진행 이벤트와 기능을 웹 엔진에 연결했다. 피카츄 자동 시작과 기존 수학 공격 규칙은 유지한다.

## 검증

- `story-mission.test.js`: 알·도감·전화·경찰·전달·배치 변경, 구형 저장과 중복 방지, 서비스 NPC 분리, 열매·교환.
- `browser-egg-mission.mjs`: 스크린샷의 대결 중인 NPC에서 시작해 실제 키보드로 오른쪽 길·집 자동 이벤트·라이벌·공박사 전달·30번 도로 해제를 끝까지 진행한다.
- 기존 회복·상점·포획·수학 공격·관장·트레이너 접근 검증을 유지한다.
