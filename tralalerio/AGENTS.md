# 뜨랠레리오 개발 기준

이 게임은 `yeondu-town-web`의 후속 개발본이다. 작업 전에 `README.md`와 `../docs/tralalerio-continuation.md`에서 현재 범위와 원본 이력을 확인한다. 원본 기준은 `upstream/baseline.json`, 당시 원본 설명은 `upstream/README.md`다.

- 실행 소스는 이 폴더의 JS/HTML/CSS 및 `assets/`다. `public/tralalerio/`는 생성본이므로 직접 수정하지 않는다.
- 원본의 탐색·전투 규칙, 기술별 공격 연출, 회전 조우 전환과 저장 복원 흐름을 이어서 개발한다. ROM/에뮬레이터 실행으로 교체하지 않는다.
- 마인크래프트 24종과 기존 포켓몬의 조우 비율 60:40, 동일한 포획·파티·성장 규칙, 개인코드별 저장을 보존한다.
- 전투 계산과 표시 이벤트를 분리한다. 연출 중 입력 중복 및 새로고침에 따른 중복 턴·중복 포획을 방지한다.
- 개인 경로에서도 자산은 `/tralalerio/`를 기준으로 로드한다. 저장 키는 `tralalerio-save-v1[:개인코드]`다.
- 기본 회귀 검증: 저장소 루트에서 `npm run test:tralalerio`. UI/연출 변경은 로컬 서버를 실행하고 `npm run test:tralalerio-browser`로 검증한다.
- 자산 전체 재생성은 `node tralalerio/tools/rebuild-assets.cjs <역어셈블 저장소 경로>`를 사용한다. 원본 전투 자산 생성기만 실행하면 마인크래프트 데이터가 사라지므로 반드시 확장을 다시 적용한다.
- 외부 원본 업데이트는 `node tralalerio/tools/check-upstream.cjs`로 확인 후 변경을 검토해 반영한다. 원본 `dist/`로 이 폴더를 통째로 덮어쓰지 않는다.

- 공격 기술 선택 시 50%는 즉시 공격, 50%는 수학 치명타 도전이다. 정답은 치명타, 오답·넘기기는 내 공격 없이 상대 턴이다. 보조 기술은 즉시 실행한다. 초급은 제외하고 중급(2단계) 80%·고급(3단계) 20%로 무작위 출제되며 27종 문제와 저장 복원을 유지한다. 상세 계약은 `MATH-BATTLE.md`를 따른다.

- 스토리·게임 기능 NPC는 원본 역할과 진행 조건을 유지한다. `chapter.js`와 `functional-npc.js`에서 먼저 처리하고, 진행과 무관한 일반 주민만 `npc-dialogue.js`의 선택형 생각 놀이를 사용한다. 알 배달이나 도구 지급을 수학 대화로 대체하지 않는다. 회복은 `state.healing` 마커를 저장해 재개하며, 표시 중 이동·메뉴·재시작을 막는다. 근거와 정책은 `CENTER-AND-DIALOGUE.md`를 따른다.

- 첫 배지 범위는 `FIRST-BADGE.md`를 따른다. 새 시작은 `Game.startAdventure()`이며 기존 동료/전투 저장은 강제 초기화하지 않는다. 맵 생성 → 기존 전투 → Minecraft → `build_first_badge.py` 순서를 보존한다. 트레이너 상대 큐·배지·상금은 저장 후 한 번만 처리한다.

- 사용자 요청 우선 정책: 포획은 항상 수학 문제 정답으로 결정한다. HP·상태 기반 포획 확률은 사용하지 않는다. 정답은 반드시 포획, 오답·넘기기는 볼 1개와 턴을 소비한다. 변환 규칙은 최소 2단계, `place_value`와 `classify`는 출제 제외다. 새 문제 힌트는 `learning-hints.js`에서 실제 숫자·그림에 맞춰 작성한다.
- 알을 받은 뒤 집을 나오는 공박사 전화는 `phone-call.js`의 착신·통화·종료 단계를 저장하고 완료 후에만 `labCall`을 설정한다. 연출 중 이동·메뉴를 잠근다. 원본 근거는 `PHONE-CALL.md`를 따른다.

- 모든 문제 힌트는 풀이 방향만 안내한다. 정답 숫자·중간 합·정답 조각/좌표·완성 순서·정답 경로를 적지 않는다. 공용 Creative 힌트의 정답 공개 단계를 사용하지 말고 로컬 `puzzleHintSteps`를 따른다. 치명타 성공에서는 저항 안내 대사만 생략하고 상성 피해 계산은 유지한다.
- 야생 서식지·시간대별 원본 목록은 `WILD-ENCOUNTERS.md`를 따른다. 골드/실버 조건부 표를 함께 파싱해 30·31번 도로를 누락하지 않는다. 원본 포켓몬 슬롯의 상대 비중을 보존하면서 Minecraft 60%를 추가한다.
- 센터 PC는 `PC` 충돌 타일 상호작용이며 `pc.js`/`pc-ui.js`를 따른다. flat storage와 박스 assignments를 함께 변경하고 마지막 건강한 동료·정원·메일·중요 도구를 보호한다. 기존 초과 보관 몬스터를 버리지 않는다. 수학 개발실은 프로덕션 문제 UI·판정을 재사용하되 모험 localStorage를 읽거나 쓰지 않는다. `PC-AND-MATH-LAB.md`를 따른다.

- 엔더드래곤·위더의 새 야생 조우는 최소 레벨 10, 각 조우당 1%다. 두 종의 공격·포획 문제는 항상 3단계다. `assets/challenge-policy.json`과 `tools/apply-challenge-policy.cjs`를 통해 60:40 총비율을 유지하며 생성한다. 이전 초급 문제는 표시 전에 최소 2단계(특별 종 3단계)로 이관하고 자원·턴을 소모하지 않는다.

코라이돈·뮤의 조우/자산/2세대 기술 적용 범위는 [추가 포켓몬](ADDITIONAL-POKEMON.md)을 따른다.

길찾기(`path`), 블록세기(`tower`), 모양완성(`shape_complete`)은 출제에서 제외한다. 도형회전은 회전 버튼 없이 방향·각도 설명을 읽고 네 그림 중 예상 결과를 고른다. 저장된 제외 문제와 이전 회전 문제는 자원 소비 없이 새 문제로 이관한다.

한 자리 뺄셈(`subtract_single`), Minecraft 이야기 한 자리 뺄셈(`subtract_story`), 구구단 2~6단 × 1~9(`times_table`)을 기존 무작위 출제에 함께 포함한다. 뺄셈은 두 수 모두 한 자리, 음수 없이 0도 정답으로 나오며 힌트에는 계산 결과를 적지 않는다. 문제만 변경할 때는 사용자 요청에 따라 전체 테스트를 실행하지 않는다.

현재 난이도는 1~5 레벨로 재분류하며 체육관 마지막 타격 규칙과 출제 정책은 [MATH-LEVELS.md](MATH-LEVELS.md)를 우선 따른다. 관장은 레벨 4, 엔더드래곤·위더는 레벨 5다.

현재 모험 범위는 [고동마을·인섹트배지](SECOND-BADGE.md)까지다. 전체 수학 문제는 최소 레벨 3이며 1~2는 게임과 개발실에서 출제하지 않는다. 한 자리 뺄셈은 빈 빼는 수를 역으로 찾는 레벨 3 문제로 유지한다. 이전 1~2 문제는 난이도 버전 4로 이관한다.
