# 뜨랠레리오

`yeondu-town-web`의 후속 개발본이다. 원본의 고동마을 두 번째 체육관까지 탐색, 야생 전투·포획·성장, 기술별 공격 연출, 회전 암전 조우 전환을 이어받고 마인크래프트 몬스터 28종을 추가했다.

- 전체 분석과 개발 위치: [후속 개발 분석](../docs/tralalerio-continuation.md)
- 이전 프로젝트 설명: [원본 README](upstream/README.md)
- 원본 기준: `upstream/baseline.json` (`d39ea95`)
- 풀숲 조우 비중: 포켓몬 60%, 마인크래프트 40%. 29번 도로는 기본 레벨 2~4(엔더드래곤·위더는 최소 10), 다른 지역은 원본 골드의 해당 지역 레벨을 따른다.
- 실행: 저장소 루트에서 `npm run dev`, http://localhost:3000/tralalerio
- 회귀 테스트: 루트에서 `npm run test:tralalerio`
- 브라우저 테스트: 서버 실행 후 루트에서 `npm run test:tralalerio-browser`
- 원본 변경 확인: `node tralalerio/tools/check-upstream.cjs`

이 폴더를 편집한다. `public/tralalerio/`는 `scripts/sync-public.cjs`가 만드는 실행 자산 복사본이다. 자산 생성기 실행 시 마인크래프트 확장을 유지하는 방법과 원본 미구현 범위는 분석 문서를 따른다.

마인크래프트 24종의 전용 공격·연출·저장 호환성은 [전용 기술 목록](MINECRAFT-SKILLS.md)에 정리했습니다.

개인 접속 시 트레이너 표시·메뉴·NPC 대화·집 표지판은 아이 이름을 사용합니다. 개인 정보가 없는 체험 경로는 “모험가”로 표시합니다. 이동은 칸 사이를 보간하고 좌우 발을 번갈아 내딛으며, 정지 시 기본 자세로 돌아갑니다. 이름·걷기·접속 경로 통합 검증: 루트에서 `node tests/tralalerio-player.cjs` (격리된 임시 로컬 서버 사용).

포획·첫 등장·교대의 원본 확인 내용과 저장/연출 처리, 담 넘기 모션은 [포획과 등장 연출](CAPTURE-AND-ENTRY.md)에 정리했습니다.

공격 기술 선택 시 50%는 바로 공격하고, 50%는 창의력·연산 27유형의 치명타 도전이 나옵니다. 정답이면 치명타, 오답·넘기기는 내 공격 없이 상대 차례입니다. 현재 초급은 제외하고 중급(2단계) 80%·고급(3단계) 20%로 출제합니다. 엔더드래곤·위더는 각 야생 조우당 1%, 최소 레벨 10이며 공격·포획 문제가 항상 3단계입니다. [수학 전투 통합](MATH-BATTLE.md)을 참고하세요.

센터 회복은 원본 기계 타일·볼 배치·점멸·회복곡을 재현하고, NPC는 7살을 위한 선택형 생각 놀이 대화로 바꿨습니다. [회복과 대화](CENTER-AND-DIALOGUE.md)에 출처와 동작을 정리했습니다.

새 모험은 연구실에서 피카츄와 바로 시작합니다. 첫 체육관까지의 진행·지도·트레이너·저장 정책과 원본과의 차이는 [첫 윙배지](FIRST-BADGE.md)를 참고하세요.

트레이너 시야 진입 시 원본 느낌표·접근·마주보기·도전 대사·배틀 전환을 재현합니다. 알 배달 대신 하나의 큰 지도 퍼즐로 진행하는 방안은 [별빛길 스토리 검토](STAR-PATH-STORY-REVIEW.md)에 정리했습니다.

원본 알 전달 미션과 기능 NPC의 우선 처리 규칙은 [원본 미션과 기능 NPC](FUNCTIONAL-NPCS.md)를 따릅니다. 필수 NPC를 일반 주민용 수학 대화로 대체하지 않습니다.

개인 메인 페이지 `/<개인코드>`에서 뜨랠레리오를 선택하면 `/<개인코드>/tralalerio`로 접속한다. 위치·동료·전투·도구·스토리 진행은 같은 브라우저의 `localStorage` 키 `tralalerio-save-v1:<개인코드>`에 자동 저장된다. 체험 경로 `/tralalerio`는 별도 키 `tralalerio-save-v1`을 사용한다. 사용자 코드별로 기록은 분리되지만 서버 백업이나 기기 간 동기화는 지원하지 않으므로, 같은 기기·브라우저에서 개인 주소로 이어서 접속해야 한다. 브라우저 사이트 데이터를 지우면 저장 기록도 삭제된다.

iPad Safari의 본문·버튼 길게 누르기는 `touch-guard.js`에서 네이티브 선택 제스처 시작을 취소한다. 방향키와 문제 조각의 포인터 입력은 유지하고, 텍스트 위의 손가락 스크롤과 버튼 탭은 별도로 전달한다. WebKit·Chromium iPad 터치 회귀 검증은 `tralalerio`에서 `node tests/browser-ipad-touch.mjs`로 실행한다. 실제 기기의 Safari 돋보기 UI 자체는 데스크톱 자동화에서 직접 관찰할 수 없으므로 기기에서도 확인한다.

팩토 기본 B·원리셈 초등 1학년 1권의 공개 자료 분석과 현재 출제하는 11유형은 [문제 유형 분석](WORKBOOK-TYPES.md)을 참고한다. 전체 27유형이 전투 문제 풀에 포함된다. 미구현 맵 출입구·맵 경계는 대화창 없이 이동만 막는다.

[마인크래프트 문장제](MINECRAFT-STORIES.md) 6유형을 전체 문제 풀에 포함한다. 정답 공격 뒤에는 문제 해결을 칭찬하는 8가지 보상 대사를 표시한다.

공격 후에는 `100 - 60 = 40. 현재 체력이 40 남았다!`처럼 실제 체력 감소를 뺄셈으로 보여 준다. 기존 피해량 계산과 턴 구조는 유지하며 내 동료와 상대 모두에 적용한다.

몬스터볼 사용은 항상 수학 포획 문제를 연다. 정답이면 반드시 잡고, 오답·넘기기는 볼을 하나 쓰고 상대에게 차례를 넘긴다. 수학 보상 대사(2초)를 체력 뺄셈(2초)보다 먼저 표시한다. 쉬운 십 묶음 세기는 제외하고 변환 규칙은 색·모양이 함께 바뀌는 2단계 이상으로 올렸다. 문제별 실제 숫자에 맞춰 새 문제의 힌트를 개선했다.

알을 받은 뒤 집을 나오면 착신 표시 두 차례 → 공박사 통화 → 끊는 소리·말줄임표 순으로 진행한다. 중간 저장 복원을 포함한 원본 확인 내용은 [전화 이벤트](PHONE-CALL.md)를 따른다.

원본 골드의 현재 구현된 7개 야생 서식지와 시간대별 목록은 [야생 조우](WILD-ENCOUNTERS.md)를 따른다. 분류(`classify`)도 출제에서 제거했으며, 모든 유형의 힌트는 정답·완성 배치·정답 경로를 공개하지 않는다. 체력 대사를 다시 읽을 때도 해당 공격 시점의 HP를 표시한다. 치명타 성공에서는 “효과가 별로인 듯하다…”를 생략한다.

메뉴의 **몬스터 도감**에서 전체 276종과 잡은 몬스터를 확인할 수 있습니다. 처음 잡은 종류는 포획 성공 뒤 모습·설명·실제 능력치를 소개합니다. 이름 짓기는 없습니다. 저장 이관과 원본 출처는 [몬스터 도감](MONSTER-DEX.md)을 참고하세요.

포켓몬센터 PC에서 동료·14개 박스·도구·메일을 관리하고 도감 평가를 받을 수 있습니다. 개발자는 [수학 문제 개발실](http://localhost:3000/tralalerio/math-lab.html)에서 문제 유형·난이도·시드와 힌트·정답 판정을 별도로 테스트할 수 있습니다. [PC와 개발실 구현 기준](PC-AND-MATH-LAB.md)을 참고하세요.

아이의 세밀한 조작을 위해 방향 버튼은 화면에 따라 44~64px(아주 작은 화면 42px), 한 칸 걷기는 260ms로 조정했습니다. 키보드·방향 버튼을 누르면 첫 칸은 즉시 움직이고, 450ms 이상 누를 때부터 300ms마다 반복합니다. 짧게 누르면 한 칸씩 이동합니다.

코라이돈·뮤의 조우/자산/2세대 기술 적용 범위는 [추가 포켓몬](ADDITIONAL-POKEMON.md)을 따른다.

길찾기(`path`), 블록세기(`tower`), 모양완성(`shape_complete`)은 출제에서 제외한다. 도형회전은 회전 버튼 없이 방향·각도 설명을 읽고 네 그림 중 예상 결과를 고른다. 저장된 제외 문제와 이전 회전 문제는 자원 소비 없이 새 문제로 이관한다.

한 자리 뺄셈(`subtract_single`), Minecraft 이야기 한 자리 뺄셈(`subtract_story`), 구구단 2~6단 × 1~9(`times_table`)을 기존 무작위 출제에 함께 포함한다. 뺄셈은 두 수 모두 한 자리, 음수 없이 0도 정답으로 나오며 힌트에는 계산 결과를 적지 않는다. 문제만 변경할 때는 사용자 요청에 따라 전체 테스트를 실행하지 않는다.

현재 난이도는 1~5 레벨로 재분류하며 체육관 마지막 타격 규칙과 출제 정책은 [MATH-LEVELS.md](MATH-LEVELS.md)를 우선 따른다. 관장은 레벨 4, 엔더드래곤·위더는 레벨 5다.

현재 모험 범위는 [고동마을·인섹트배지](SECOND-BADGE.md)까지다. 전체 수학 문제는 최소 레벨 3이며 1~2는 게임과 개발실에서 출제하지 않는다. 한 자리 뺄셈은 빈 빼는 수를 역으로 찾는 레벨 3 문제로 유지한다. 이전 1~2 문제는 난이도 버전 4로 이관한다.

야생 몬스터를 쓰러뜨리면 `max(40, 레벨 × 20)`원의 상금을 즉시 받는다. 포획·도주·패배는 지급하지 않는다. 전투의 `wildPrize`와 소지금을 함께 저장해 재접속이나 종료 처리로 중복 지급되지 않는다. 이전 미정산 야생 승리는 모험으로 돌아갈 때 한 번 정산한다.

도라지시티 테스트 시작: `/tralalerio/?start=violet`. 기존 동료·아이템·스토리 기록을 유지하고 포켓몬센터 바로 앞(31,26)으로 한 번만 이동한다. 새로고침으로 반복 이동하지 않으며 진행 중인 전투·회복·등장 연출은 중단하지 않는다. 해당 연출을 마친 후 주소를 다시 열면 이동한다. 일반 주소의 새 모험 시작은 기존 연구실이다.

마인크래프트 추가 4종: 블레이즈(화염구·화상), 철 골렘(강철 강타), 눈 골렘(눈덩이), 늑대(덮치기). 모든 기존 육상 서식지·시간대에 등장하며, 수학 포획·성장·첫 포획 소개·도감·PC를 공유한다. `tools/add-minecraft.cjs`가 자체 제작한 앞/뒤 블록 그래픽과 종·전용 기술을 재생성하며 전체 재생성에도 포함된다. 현재 포켓몬60:마인크래프트40 정책은 이전 문서의 60% Minecraft보다 우선한다.

Violet 테스트 URL은 별도 `:violet-test` 저장을 사용한다. 처음에는 기존 모험을 복사하고 테스트 결과는 일반 모험 저장에 덮어쓰지 않는다. 안전한 필드 상태에서 피카츄99·완전회복·전기쇼크/몸통박치기를 설정하며 공격 명중시 상성에 관계없이 남은HP 전부를 깎는다. 수학 오답·체육관 마지막타격 정답 요구는 유지한다. 테스트 이동은90ms보간/120ms길게누름/100ms반복이며 일반모드는 기존속도를 유지한다.

골드 악보 기반 사운드30곡: 맵46개의 원본 음악 배치, 트레이너 직업별 조우·야생 낮/밤·트레이너·라이벌·로켓단·관장·승리 음악을 전환한다. 첫 터치/키 입력 후 재생하며 화면 아래에서 음소거·음량을 조절한다. 생성 근거와 실기 음색과의 차이, 검증 방법은 [SOUND.md](SOUND.md)를 따른다.

메뉴 → 지도 보기에서 원본 성도·관동 지도를 볼 수 있다. 현재 위치와 선택 지점 이름을 표시하며, 건물·동굴 안에서도 원본 지역에 연결한다. 원본 자산과 웹 조작 범위는 [TOWN-MAP.md](TOWN-MAP.md)를 따른다.

사용자 제공 이미지 몬스터: 거뚱이(물/강철), 메가 플라이·자이언트 플라이(비행/강철)를 확장 계열에 추가했다. 도라지 주변 30·31·32번 도로와 어둠의 동굴에서 각각20%/8%/2%로 만나며, 메가 플라이는36레벨에 자연 진화한다. 제공 그림을 추출해 사용하고 별도 새 그림을 생성하지 않는다. 재생성·공격·분포 정책은 [GADDOONGI.md](GADDOONGI.md)를 따른다.
