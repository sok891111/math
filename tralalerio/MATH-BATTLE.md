# 뜨랠레리오 × Creative 수학

뜨랠레리오의 맵·스토리·포켓몬/마인크래프트 몬스터·기술·포획·교대·성장과 저장을 기반으로, 플레이어가 기술을 사용하기 전에 Creative 몬스터 원정대의 사고력 문제를 풀도록 연결했다.

## 플레이 흐름

공격 기술을 선택하면 50% 확률로 즉시 기존 공격을 실행하고, 50% 확률로 치명타 도전을 연다. 보조 기술은 바로 실행한다. 정답은 원본 2세대 치명타 공식을 강제 적용한다(정답 보상 공격은 명중 보장, 기존 상태·상성 규칙 유지). 즉시 공격 경로의 원본 자연 치명타 확률도 유지한다.

오답 제출 또는 ‘공격 넘기기’(Escape 포함)는 내 공격과 PP 소비 없이 턴을 소비하고 상대가 행동한다. 상대 행동 뒤 상태 데미지도 기존 규칙대로 적용된다. 힌트·초기화·풀이 중에는 턴을 소비하지 않으며 시간 제한이 없다. 출제된 문제는 저장되므로 새로고침해도 다시 추첨하지 않는다. 정답/오답/넘기기는 계산 결과를 먼저 저장해 재접속 시 중복 실행을 막는다.

## 문제 은행과 난이도

교재 공개 자료 분석은 `WORKBOOK-TYPES.md`를 따른다. 사용자의 최종 요청으로 추가 연산 문제는 덧셈만 출제하며 받아올림이 생기는 문제를 포함한다. 받아올림 전용 유형에서는 일의 자리 합이 항상 10 이상이다. 답은 0~99이며, 힌트에서 낱개 10개를 십 묶음 하나로 바꾸는 과정을 설명한다.

기존 `creative/battle-model.js`의 반복 규칙·거울 대칭·길 찾기·논리 배치 4종, `creative/facto-puzzles.js`의 수열·분류·변환 규칙·회전·블록 세기·수 모으기·저울·숫자 격자 8종을 재사용한다. 여기에 `learning-puzzles.js`의 기하·배열·표 읽기·두 자리 연산 12종을 더해 문장제 6종을 포함한 전체 30종에서 무작위로 뽑는다. 직전 해결 유형은 다음 선택에서 제외한다.

현재 첫 배지까지 포함된 31개 맵은 초급(1단계)과 한 단계 높은 2단계를 50:50으로 무작위 출제한다. 몬스터나 플레이어의 레벨이 올라도 이 구간의 기본 난이도는 초급으로 유지한다. 초급은 AB 규칙, 2×2 대칭, 3×3 짧은 길 찾기, 직접 위치 단서, 작은 수의 조작 등 원정대의 기존 초급 생성 규칙을 따른다.

미래 맵의 기본 난이도는 적 레벨에 따라 최대 3단계까지 설정할 수 있지만, 현재 초반 구간에는 적용되지 않는다. 이전 다리/워든 레거시 게임 자체의 화면을 추가하는 변경은 아니며, 기존 원정대 12유형과 공개 교재 학습목표를 바탕으로 새로 생성하는 12유형을 합친 것이다.

## 저장과 입력

`battle.mathChallenge`에 유형·생성 시드·난이도·선택 기술·배치한 답·시도 수·힌트 단계를 저장한다. 같은 시드에서 같은 문제를 복원하므로 새로고침해도 문제가 바뀌지 않는다. 문제창을 닫아 공격을 다시 추첨할 수 없으며 넘기기는 턴을 소비한다. 가방·교대·도망으로 다른 행동을 실행하면 대기 문제를 해제한다. 기존 저장에는 문제 필드가 없어도 호환된다.

UI는 원정대의 Facto UI와 단계별 힌트를 재사용하며 기존 4유형은 같은 조작을 밝은 색의 전투 대화창에 연결했다. 클릭·터치·키보드 버튼 입력과 조각 드래그를 지원한다. 문제창이 열리면 게임 이동키가 문제창의 입력을 가로채지 않는다.

## 개발·검증

- `math-challenge.js`: 무작위 유형·시드·난이도·정답 검증·공격 실행 연결
- `math-puzzle-ui.js`, `math-puzzle.css`: 문제창과 조작
- `battle-view.js`: 기술 선택 및 저장된 문제 복원
- `battle.js`: 대기 문제를 건너뛰는 공격 차단과 저장 유효성 검사
- `tests/math-challenge.test.js`: 30유형 × 2난이도 × 100시드의 정답 검증, 50% 분기·강제 치명타·오답 턴 소비, 저장 복원, 위조 데이터 거부
- `tests/browser-math.mjs`: 30유형 실제 모바일 DOM 풀이, 기술 선택·오답·힌트·중단·새로고침·공격 연결

루트에서 `npm run test:tralalerio`, 로컬 서버 실행 후 `npm run test:tralalerio-browser`를 실행한다. 기존 Creative 게임은 `/creative`에서 그대로 실행할 수 있으며, 두 게임이 문제 생성기와 힌트 코드를 공유한다.

화면 명칭은 “강력한 공격 도전!”이다. 정답 공격 연출 후 전투 대사는 “강력한 공격에 성공했다!”, 오답·넘기기는 “공격에 실패했다. 다음문제는 꼭 풀어보자!”를 표시한다. 내부 데미지는 기존 치명타 공식을 유지한다.

결과 표시 순서: 정답은 플레이어 공격 연출이 끝난 뒤 성공 대사를 표시한다. 오답·넘기기는 저장된 `math-fail` 이벤트로 제자리 점프 1회 → 실패 대사 → 상대 행동 순서다. 점프는 HP·PP를 바꾸지 않으며 새로고침은 저장된 연출만 재생한다.

정답 보상은 실제 `damage(..., {critical:true})` 계산을 적용하고 원본 급소 연출을 사용한다. 명중률 하락·상대 회피 상승으로 보상 공격이 빗나가지 않는다. 일반 공격과 상대 공격의 명중·치명타 확률은 그대로이며 보상은 해당 플레이어 공격에만 적용한다. 화면 문구·버튼·대화 순서는 변경하지 않는다.

2026-10-17: 각 지역 기본 난이도와 한 단계 높은 난이도를 50:50으로 섞어 출제한다(최대 3단계). 초반도 1·2단계를 혼합한다. 난이도는 문제 생성 시 저장하며, 진행 중인 기존 초급 문제와 새 2단계 문제 모두 새로고침 후 동일하게 복원한다. 공격 시 문제 등장 확률 50%는 유지한다.

문장제 6종과 수학 정답 보상 대사 8종의 출제·저장·표시 정책은 `MINECRAFT-STORIES.md`를 따른다. 보상 대사는 기존처럼 실제 공격 애니메이션 후 표시하며 직전 문구를 피해서 선택한다.
