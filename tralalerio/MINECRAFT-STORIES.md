# 마인크래프트 덧셈 문장제와 문제 해결 보상

## 확인한 학습 구조

사용자 예시는 기준 수와 차이를 알고 더 큰 수를 찾는 비교 덧셈이다. 물건을 가진 두 사람의 전체 합을 묻는 문제와 구별해야 한다. 덧셈 상황을 합치기와 수량 증가로 구분하는 공개 교육 자료도 참고했다.

- NCETM, The Bar Model: https://www.ncetm.org.uk/classroom-resources/ca-the-bar-model/
- NCETM, Additive structures (augmentation): https://www.ncetm.org.uk/classroom-resources/primm-106-additive-structures-introduction-to-augmentation-and-reduction/

유료 문제집에서 추가 문항을 가져온 것이 아니라, 사용자가 제시한 구조와 공개 교육 자료의 덧셈 개념을 바탕으로 마인크래프트 이야기를 새로 생성한다.

| 유형 | 이야기와 구할 수 | 계산 |
| --- | --- | --- |
| story_compare | 한 친구보다 더 많이 모은 다른 친구의 수 | 기준 수 + 더 모은 수 |
| story_combine | 두 친구가 다른 장소에서 모은 전체 수 | 첫 수 + 둘째 수 |
| story_receive | 가지고 있던 것에 선물을 받은 뒤의 수 | 처음 수 + 받은 수 |
| story_three | 세 장소에서 모은 전체 수 | 세 수의 합 |
| story_chain | 둘째는 첫째보다 더, 셋째는 둘째보다 더 모았을 때 셋째의 수 | 기준 수 + 두 차이 |
| story_distance | 다리까지의 길과 마을까지 이어지는 길 | 두 거리의 합 |

스티브·알렉스·피글린·엔더맨·주민·마녀·스켈레톤·좀비·크리퍼·워든·브리즈·엔더기사를 사용하고, 다이아몬드·에메랄드·철괴·당근·횃불·사과·블록·씨앗과 장소·수를 섞는다. 기초와 2단계 모두 덧셈만 사용하고 합은 99 이하이며 받아올림 유무가 섞인다.

문장제는 처음부터 계산식이나 수 모형을 보여 주지 않고 이야기와 답 조각으로 푼다. 힌트는 구하려는 대상 → 수 사이의 관계 → 계산과 받아올림 순서로 돕는다. 기존 add_story 및 calc_puzzle의 이야기 변형도 수와 선택지는 유지한 채 마인크래프트 문장으로 표시한다.

## 출제와 저장

기존 22종에 새 문장제 6종을 더한 28종 전체에서 기존과 같은 방식으로 유형을 무작위 선택한다. 직전 유형 제외, 공격 시 50% 문제 등장, 초급/2단계 50:50은 유지한다. 문제 시드·입력·힌트와 생성 문장은 새로고침 후 동일하게 복원된다.

## 보상 대사

`math-rewards.js`의 8가지 대사는 모두 수학 문제·정답·문제 해결을 강력한 공격의 원인으로 표현한다. 실제 플레이어 치명타가 성공한 뒤 표시하며, 일반 치명타나 오답에는 표시하지 않는다. 직전 보상과 같은 대사는 피한다. 문제 시드로 문구를 선택하므로 전투 난수를 추가로 소비하지 않는다. 문구는 전투 로그에 저장하고 2초 동안 읽을 시간을 준다. 이전 저장의 보상 문구도 같은 표시 시간을 유지한다.
