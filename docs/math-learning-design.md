# 레벨 테스트와 재도전 학습 설계

2026-10-05 구현 기준. 아래의 넛지는 연구에서 다룬 원칙을 이 게임에 적용한 설계 판단이다. 이 게임이나 TNT 연출 자체의 학습 효과가 검증된 것은 아니다.

## 넛지를 실제 동작으로 연결하기

- **목표를 눈에 보이게:** 15문제 진행 칸과 목표 7개를 표시한다. 15문제의 70%는 10.5개이므로 최소 통과 개수는 7개다.
- **자기 기록과 비교:** 같은 레벨의 이전 시도보다 정답이 늘었을 때만 증가량을 안내한다. 다른 아이와 비교하거나 순위를 매기지 않는다.
- **재도전의 수고를 줄이기:** 결과 위쪽에 재도전 버튼을 배치한다. 실패하면 6개 스테이지를 다시 걷지 않고, 바로 새로운 15문제와 10분으로 재도전할 수 있다.
- **작은 성공을 선택할 수 있게:** 시험 밖에서 놓친 문제 하나를 힌트와 함께 풀 수 있다. 연습은 무제한 시간이며 시험 점수에 합산되지 않는다.
- **모험 자산을 보호:** 실패·재도전·레벨 3 완주 후에도 배지, 보물, 보석, 점수, 햇살, 장비와 슈퍼 점프 충전을 보존한다.
- **TNT를 재도전의 장면으로 사용:** 약 1.8초 동안 블록 파편, 충격파와 화면 흔들림을 연출한 뒤 학습 결과를 보여 준다. 자동으로 시험을 시작하지 않고 아이가 버튼을 누른다. 운영체제의 동작 줄이기 설정에서는 움직임을 생략한다.

## 판정과 시간의 의미

- 레벨은 1~3, 레벨마다 6개 스테이지다. 스테이지 6의 깃발을 통과하면 다음 레벨 대신 시험에 진입한다.
- 레벨 1: 합 6~18의 한 자리 덧셈. 시험은 덧셈 10문제다.
- 레벨 2: 합 20~40의 두 자리 덧셈과 2~3단 × 1~5. 시험은 덧셈 10문제다.
- 레벨 3: 합 30~50의 두 자리 덧셈과 2~5단 × 1~9. 시험은 덧셈 10문제다.
- 시험은 문제별 시간이 아닌 전체 10분이다. 제출한 답은 바꿀 수 없으며, 제출 후에만 정답 피드백을 제공한다.
- 10분 안에 10문제를 모두 제출하고 7개 이상 맞혀야 통과한다. 시간 초과는 7개를 이미 맞혔더라도 미완료이므로 재도전한다.
- 타이머와 답은 별도로 저장한다. 새로고침하거나 화면을 떠나도 마감 시각은 늘어나지 않는다. 시험을 통과하기 전에는 다음 레벨로 진입하지 않는다.
- 레벨 3 통과 후 레벨 1의 첫 스테이지부터 다음 바퀴를 시작한다. 보상 저장소는 초기화하지 않는다.

## 실제 학습을 확인할 때

재도전 횟수나 애니메이션에 대한 반응만으로 수학 이해가 좋아졌다고 해석하지 않는다. 보호자는 ‘9에는 하나만 더 있으면 10이니까 5에서 하나를 가져왔어’ 같은 풀이 설명, 필요한 도움의 변화, 실제 정답 변화를 함께 살펴보는 것이 좋다.
