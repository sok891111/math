# 마법영어 통합 및 Vercel 배포

> **2026-10-30 운영 변경:** 마법영어만 운영한다. 마인크래프트 이동·하트·블록·무기·코인 지급은 종료했다. 아래 건축/보상 절은 이전 구현 이력이며 현재 동작을 뜻하지 않는다. 기존 저장 데이터는 삭제하지 않는다.



## 실행과 게이트

- 게임 이름/폴더: `magic-english` / `magic-english/`.
- 개인 게이트 `/<개인코드>`의 **마법영어** → `/<개인코드>/magic-english`.
- 체험: `/magic-english`.
- 기존 건축 주소는 개인 마법영어 모험으로 리다이렉트한다. 마인크래프트 실행 자산은 운영 배포에서 제외한다.
- 로컬은 저장소 루트에서 `npm run dev`, 배포 빌드는 `npm run build`다. 기존 Vercel Next.js 프로젝트에 함께 포함된다. 별도의 Vercel 프로젝트나 정적 서버가 필요하지 않다.
- `magic-english/`를 수정하고 `scripts/sync-public.cjs`로 공개 자산을 생성한다. `public/magic-english/`는 직접 수정하지 않는다.

## Vercel 환경변수

Vercel 프로젝트 Settings → Environment Variables에 설정하고 재배포한다. 키 값을 브라우저 코드에 넣지 않는다.

| 변수 | 설정 |
|---|---|
| `ELEVENLABS_API_KEY` | **필수 신규 설정**. 서버 전용. Production/Preview 등 사용할 환경을 선택한다. |
| `SUPABASE_URL` | 기존 block-island의 Supabase URL. |
| `SUPABASE_SERVICE_ROLE_KEY` 또는 `SUPABASE_ANON_KEY` | 기존 `kv_store`를 읽고 쓸 서버용 키. 기존 플랫폼과 같은 테이블을 사용한다. |
| `MAGIC_ENGLISH_SIGNING_SECRET` | 선택. 지속적인 보상 서명 키. 미설정이면 ElevenLabs 키를 기반으로 서명한다. 키 변경 시 기존 미전달 음성 확인 토큰의 호환성에 유의한다. |
| `MAGIC_ENGLISH_STT_KEYTERMS` | 기본 활성. `false`이면 단어 문맥 힌트를 끈다. 공급자의 추가 요금이 적용될 수 있다. |
| `BLOCK_REWARD_API_KEY` | 선택. 다른 게임 서버가 블록 지급 API를 호출할 때만 설정한다. 브라우저에는 전달하지 않는다. |

`NEXT_PUBLIC_ELEVENLABS_API_KEY`는 만들지 않는다. 다른 프로젝트의 환경 파일이나 개인 문서에서 키를 찾는 코드는 통합 실행 경로에서 사용하지 않는다. `.env.example`의 신규 값은 비어 있으며 사용자가 직접 설정한다.

## 서버 기능

`pages/api/magic-english/[...action].js`가 아래 경로를 제공한다.

- `GET/POST /api/magic-english/assess-pronunciation`: 설정 상태와 Scribe v2 음성 인식.
- `POST /api/magic-english/character-voice`, `/welcome-voice`: 고정 배역의 신규 음성 준비.
- `POST /api/magic-english/rewards`: 서명된 발화 확인과 조각/Stage 보상을 등록.
- `GET /api/magic-english/block-world/rewards?userId=...`: 건축 게임 자동 수령.
- `GET /api/magic-english/block-world/catalog`: 블록 목록.
- `POST /api/magic-english/block-world/rewards`: 선택적 서버 인증 지급.

보상은 `kv_store`의 `magic-english:reward:...` 개별 행으로 저장한다. 동일 보상 ID는 한 번만 발행하고 내용이 다르면 거절한다. 기존 사용자의 플랫폼/다른 게임 기록과 키가 겹치지 않는다. 새 동적 음성 캐시는 `magic-english:voice:...`에 저장한다. Vercel에서는 로컬 파일이나 프로세스 메모리를 영구 저장소로 쓰지 않으며 Supabase 미설정 시 지급을 실패 처리한다. 로컬 개발에는 `.magic-english-data/` 파일 어댑터가 있다.

기존 플랫폼과 마찬가지로 개인 코드는 접속 식별자이며 별도 로그인 인증은 아니다. 보상 등록은 음성 확인 서명을 검증하고 사용자가 블록 수량을 지정할 수 없다.

## 음성 지연·Bus·Speak 수정

- 현재 대사 141개를 ElevenLabs 고정 배역의 MP3로 준비했다. 배포 빌드에서 TTS 생성하지 않는다.
- 음성 파일을 백그라운드로 받아 두고 실제 대화의 다음 페이지를 미리 디코딩한다. 시작할 때 모든 음성을 동시 디코딩하지 않는다.
- 에이미는 Fena 원음을 유지한다. 링고는 고정 로봇 처리, 미스스펠은 Bill/저음 처리를 유지한다. 기기 기본 음성으로 전환하지 않는다.
- 피크 제한과 짧은 재생/종료 페이드를 적용해 큰 피크와 갑작스러운 잘림을 줄인다.
- 짧은 Bus 발화는 긴 무음을 포함한 전체 평균 음량으로 거절하지 않는다. 30ms 구간의 음량으로 감지하고 앞뒤 여유를 남겨 무음을 정리한다.
- 문장 안의 `bus/buss/buzz/버스` 인식 변형과 축약형을 처리한다. 최신 문장 정책에 따라 단어 하나만 말해서 문장 퀘스트를 통과할 수는 없다.
- 마이크 준비·녹음·분석 상태를 구분하고 중복 입력을 막는다. 대화를 닫으면 이전 세션을 취소하며 이전 결과가 새 대화에 반영되지 않는다. 오류 후에는 바쁜 상태가 해제된다.
- 마이크는 HTTPS 또는 localhost에서 실행해야 한다. 실제 아동 발음·iPad 권한은 기기에서 확인해야 한다.

단어 문맥 힌트 계약은 [ElevenLabs 공식 문서](https://elevenlabs.io/docs/eleven-api/guides/how-to/speech-to-text/batch/keyterm-prompting)를 따른다. 마이크 녹음 원본은 Supabase에 저장하지 않는다.

## Stage 2와 이동

기존 원작/최신 변경의 Bus·Bag·Big 단서, 오해 삼총사, 버스 기사, 간판 복구, 보스의 짐칸 봉인, 보따리·활빈당 표식·B 조각, 다음 C 모험 예고를 보존했다. `advanceStage2`로 실제 성공 콜백과 체크리스트의 진행 상태를 함께 갱신한다.

공항 출구·버스 문·하차문·이전 정류장·다음 출발 게이트는 준비 조건을 충족한 뒤 해당 타일로 걸어가면 이동한다. 마지막 정류장에서 이전 정류장으로 돌아갈 수 있다. 도착 위치를 입구 바깥에 두어 왕복 이동이 반복되지 않게 했다. 단어 조사와 대화는 기존 A/Space 조작을 유지한다.

건축 첫 입장은 평지·블록 0개이며 기존 세계가 있으면 이어 연다. 모험 ↔ 건축 전환, 큰 블록 소진 안내창, 복귀 버튼, 나무 1~2개·조각 철 1개·Stage 나무/흙/철 각 5개 보상을 유지한다.

## 이관 범위와 저장

이전 실행 코드·전체 assets·Three.js vendor/라이선스·Stage 1/2 이야기·반복 대화·지도/NPC·원작 이미지·도감·건축·문서·생성 도구·관련 단위 테스트를 가져왔다. 원본 코드 이력과 reference도 소스 폴더에 보존한다. `MIGRATION-MANIFEST.json`에 파일별 원본/이관 해시와 제외 범위를 기록한다. 공개 자산은 실행 JS/HTML/CSS와 assets, creative, block-world의 허용 파일만 복사한다.

API 키, `.env*`, `.block-world-data`의 개인 보상/서명 키, node_modules, 테스트 산출물은 공개 자산에 포함하지 않는다. 기존 브라우저 모험/건축 저장 키와 개인 코드 분리는 유지한다. **localhost와 실제 서비스는 브라우저 저장소 출처가 다르므로 기존 로컬 플레이 기록이 자동으로 옮겨지지는 않는다.** 원본 저장을 초기화하지 않으며 다른 게임 저장도 건드리지 않는다. 건축 파일 내보내기/가져오기는 유지한다.

## 크리퍼·좀비·무기 보상 / A 입력

- 새 세계에 기존 돼지 4·닭 4와 크리퍼 2·좀비 2가 등장한다. 기존 저장에는 새 몬스터만 한 번 추가하고 건축·기존 동물을 유지한다.
- 좀비·크리퍼는 가까운 플레이어를 향해 이동한다. 크리퍼는 가까이 머무르면 점멸 후 연기 효과로 사라졌다가 다시 등장한다. 이 효과는 세계의 블록을 변경하지 않는다.
- 문장 전체가 일치해 `quality=complete`로 인식되면 기존 나무 2개와 함께 검 1개를 지급한다. 한 단어·부분 답변·실패에는 검이 지급되지 않는다.
- 검은 나무 45% / 돌 30% / 철 20% / 다이아몬드 5%, 공격력은 각각 2/3/4/6이다. 기본 막대기는 1이다. 무기는 공격할 때 소모되지 않는다.
- 검 종류는 서버가 발화 ID와 서명 키를 바탕으로 정하고 서명된 확인 토큰에 담는다. 클라이언트가 무기 종류를 지정할 수 없다. 재시도 시 동일한 검이 한 번만 지급된다. 이전 보상 영수증 형식은 유지한다.
- 보상 API의 선택적 `items: [{itemId:'iron_sword',quantity:1}]`가 무기 보상이다. 건축 보관함에는 `inventory.weapons`에 저장한다. B 블록/무기 선택 창에서 고르고 A로 공격한다. 핫바에는 가장 강한 보유 검의 빠른 선택 칸이 표시된다.
- A는 일반 대사·구출 연출·보스 대사·조각 획득 대화 모두 다음으로 넘긴다. 말하기는 A로 녹음 시작/완료하며 분석 중에는 기다린다. 성공을 건너뛰지 않는다. 선택 대화는 방향키로 선택하고 A로 확인한다. 기존 다음 버튼도 같은 함수를 호출한다.
- 단위 확인: `node --test magic-english/tests/magic-weapons-monsters.test.js magic-english/tests/block-animals.test.js magic-english/tests/block-inventory.test.js tests/magic-english-integration-unit.cjs`.

## 생활 문장·보스 문제·낮밤·닭 아이템 (최신)

말하기 대상은 `magic-english-practice.js`에서 공유한다. 단서 조사·반복 NPC·Stage 1/2 보스의 표시 문장, 가이드 음성, 서버 정답 판정이 같은 정책을 사용한다. 이전 단어만 따라 하는 설명보다 이 정책이 우선한다.

| 대상 | 연습 문장 |
|---|---|
| Airplane | I see an airplane. |
| Apple | I want an apple. |
| Ask | Can I ask you? |
| Bus | Here is the bus. |
| Bag | This is my bag. |
| Big | It is a big bus. |

A 보스는 Airplane → Apple → Ask 문장으로 세 번의 마법을 푼다. B 보스는 Big/Bus 문장 → Bag 문장으로 짐칸 봉인을 푼다. 핵심 단어를 문장 순서로 말하면 부분 성공(나무 1개), 전체 문장은 완전 성공(나무 2개+검 1개)이다. 관사 생략은 부분 성공으로 인정한다. 무음·단어 하나·뒤섞인 단어는 성공 처리하지 않는다. 기존 진행 저장은 초기화하지 않는다.

낮밤은 360초 한 주기(낮 50%, 밤 50%)이며 게임이 활성 상태일 때 흐른다. 크리퍼·좀비는 밤에만 보이고 공격할 수 있다. 낮에는 돼지·닭만 보인다. 낮과 밤은 각각 180초다. 기존 쉬운 모드에도 낮밤 순환을 한 번 활성화하고, 이후 보호자 설정의 순환 해제는 유지한다. 시간과 동물 상태는 저장된다.

닭을 잡으면 생닭고기 1개와 깃털 0~2개를 자동으로 획득한다. `inventory.loot`에 보관하고 블록/무기 선택 창에서 수량을 확인한다. 현재 음식 섭취·제작·배고픔 기능은 없다.

## 모험 하트와 몹 드롭 (최신)

- 새 저장/이전 하트 없는 저장은 하트 0개다. 기존 보상 영수증을 다시 수령해 무료 하트를 만들지 않는다. 새로 수령한 모험 보상에서 블록 총수량과 같은 하트를 지급한다: 대화 1~2, 조각 1, Stage 완료 15. 기존 건축과 블록은 보존한다.
- 하트는 `inventory.hearts`, 다음 소모까지 누적 시간은 `inventory.heartElapsed`로 저장한다. 블록 배치/회수/드롭으로는 하트를 지급하지 않는다. 지급 영수증은 하트와 블록을 함께 한 번만 적용한다.
- 실제 플레이 중 20초마다 하트 1개를 소모한다. 메뉴·안내창·백그라운드에서는 멈춘다. 남은 시간은 새로고침 후에도 복원한다. 하트 0개이면 이동·건축·공격을 멈추고 닫을 수 없는 모험 복귀 안내를 표시한다. 새 보상을 받으면 해제한다.
- 좀비 근접 공격은 하트 1개, 전역 2초 재공격 대기다. 크리퍼 폭발은 하트 2개이며 블록은 파괴하지 않는다. 벽 너머나 다른 높이에서는 공격하지 않는다. 밤에만 등장한다.
- 현재 성체 4종의 일반 플레이어 처치/약탈 인챈트 없는 Java 기본 드롭을 사용한다: 돼지 생돼지고기 1~3, 닭 생닭고기 1+깃털 0~2, 좀비 썩은 살점 0~2+2.5% 확률로 철괴/당근/감자 중 하나 1개, 크리퍼 화약 0~2. 자폭 크리퍼는 아이템을 주지 않는다.
- 드롭은 즉시 `inventory.loot`에 수집된다. 현재 화염·약탈·장비 착용 몹·스켈레톤 처치/충전 크리퍼 조건은 구현하지 않아 익힌 음식·장비·음반·머리의 조건부 드롭은 발생하지 않는다. 음식 섭취/하트 회복도 없다.
- 기준 자료: [좀비](https://minecraft.wiki/w/Zombie), [크리퍼](https://minecraft.wiki/w/Creeper), [돼지](https://minecraft.wiki/w/Pig), [닭](https://minecraft.wiki/w/Chicken).
- 관련 단위 테스트: `heart-energy.test.js`, `mob-loot.test.js`. 전체/브라우저 테스트는 실행하지 않는다.

## NPC 연결 대화: 플레이어 Speak 2~5회

`magic-english-conversations.js`가 단서·첫 NPC 대화·반복 NPC 대화의 한 번뿐인 Speak를 상황별 2~5회로 확장한다. 카페 주문(5회), 가방 찾기/자기소개(4회), 비행기/사과/버스/도움 요청(3회), 아침 인사/감사/큰 버스(2회)를 사용한다. NPC의 반응·다음 질문과 플레이어 답변을 번갈아 표시하고 말하기 차례를 `현재/전체`로 안내한다. 기존 직원 실전 대화 2회·A 보스 3회·B 보스 2회는 원래 순서대로 유지한다. 말하기 없는 스토리 연출에 질문을 끼워 넣지 않는다.

한 번뿐이던 원래 퀘스트 `onPass`는 연결된 대화의 마지막 Speak에만 실행한다. 중간에 닫기/실패하면 퀘스트는 완료하지 않으며 다음 대화 시 처음부터 다시 연습한다. 매번 성공한 발화의 기존 블록·하트·완전한 문장 검 보상은 유지한다. 이전 완료 저장은 초기화하지 않는다.

추가 답변은 브라우저와 서버가 공유하는 `CONVERSATION_TARGETS`에 등록된다. 순서에 맞는 핵심 문장을 요구하고 단어 하나로 통과시키지 않는다. 일반 인사도 하나의 단어가 아닌 표현 전체를 요구한다. 가이드·한국어 뜻은 유지하며 Let's/I'd/I've 같은 축약형을 인정한다.

NPC 음성은 기존 고정 배역으로 미리 불러오고 추가 응답 가이드는 에이미가 읽는다. 정적 음성 생성기는 추가 문장을 포함한다. 로컬에서 `ELEVENLABS_API_KEY`가 설정되지 않으면 동적 음성과 신규 정적 음성 생성은 503으로 실패하며, 기기 기본 음성으로 바꾸지 않는다.

단위 검증: `conversation-turns.test.js`와 API 통합 단위 테스트에서 2~5회 분포, NPC 반응 순서, 마지막 성공 콜백, 새 목표 문장 판정, 단어만 제출한 오답을 확인한다.

## 최신 대화 보상: 무기 20%·랜덤 블록

완전한 문장 성공 시 검 지급 확률은 20%다(부분 성공/실패 0%). 검에 당첨된 경우에만 기존 등급 비중 나무45:돌30:철20:다이아몬드5를 적용한다. 기존 ‘완벽한 문장마다 검’ 설명보다 이 정책이 우선한다.

성공한 대화는 건축 가능한 모든 고체 블록 중 한 종류를 균등 선택해 부분 성공 1개/완전 성공 2개를 지급한다. 물·기반암은 제외하며 나무·돌·유리·벽돌·색 양털·책장·발광석·철 블록 등이 포함된다. 하트는 동일하게 1~2개다. 조각/Stage 완료의 기존 고정 보상은 유지한다.

서버가 사용자+발화 ID+서명 키의 HMAC으로 무기 당첨·무기 등급·블록 종류를 각각 결정하고 `rewardVersion:2` 토큰에 서명한다. 실제 지급 시 토큰에서 다시 계산하며 클라이언트가 보낸 종류·수량은 사용하지 않는다. 같은 발화를 재요청하면 같은 보상이고 중복 지급하지 않는다. 기존 대기 토큰에는 이전 보상 정책을 적용해 이미 약속한 보상과 저장 영수증을 유지한다.

신규 정책은 `block-world/speech-rewards.js`, 운영 API는 `lib/magicEnglishApi.cjs`다. 정적 이력의 독립 서버용 도구는 운영 배포 경로가 아니다. 단위 검증은 `speech-rewards.test.js`와 `magic-english-integration-unit.cjs`다.

## NPC 마무리 인사 다양화

반복 대화의 공통 Thanks for stopping by를 제거했다. `magic-english-farewells.js`에 11개 역할별 4개, 총 44개의 영어/한국어 인사를 등록했다. 역할에 맞는 인사를 무작위로 고르고 각 NPC/전체의 직전 인사를 `learning.farewells`에 저장해 연속 중복을 피한다. 대화를 열 때 한 번 고르므로 다시 렌더링해도 인사가 바뀌지 않는다. 최초 퀘스트의 이야기 진행 대사는 유지한다. 화면 영어와 음성 요청 문장이 같고 기존 배역을 사용한다. 새 음성은 ElevenLabs 설정이 필요한 기존 경로로 제공하며 음성 생성기에도 추가했다. 단위 테스트는 `npc-farewells.test.js`다.

## 안내 데스크 가이드 속도·깨짐 완화

Stage 1 안내 데스크 실전 대화의 Speak 가이드는 자동 재생/다시 듣기 모두 재생 배율 0.85다. 두 번째 가이드는 화면의 `My friend. Help, please!`와 동일한 정적 음성을 사용하며 질문 시작 문장까지 중복해서 읽던 이전 클립을 사용하지 않는다.

일반 배역은 브라우저 미디어 재생으로 음높이 보존을 켜고 볼륨 0.8로 재생한다. 브라우저 자동 재생이 차단되면 기존 Web Audio 경로로 복귀하며, 일반 음성에는 컴프레서를 적용하지 않는다. 이 복귀 경로의 느린 재생은 음높이도 함께 낮아질 수 있다. 링고/악당의 효과와 고정 배역은 유지한다. 중복 재생 취소·오류 정리와 기기 기본 음성 미사용 정책을 유지한다. 원본 음성 파일 자체의 왜곡과 실제 iPad 스피커 품질은 단위 테스트로 확인할 수 없다. 관련 검증은 `guide-playback.test.js`다.

## 바닥 드롭·음식·하트 칸·피격 연출 (최신)

처치한 몹은 아이템을 `animals.groundDrops`에 떨어뜨린다. 아이템은 월드에 떠 있는 모양으로 표시되며 플레이어가 1.3블록 안으로 접근하면 0.6초 대기 후 줍는다. 벽 너머·다른 높이에서는 줍지 않는다. 바닥 아이템과 수량/위치/유지 시간을 저장하고, 가까운 같은 아이템은 합치며 활성 플레이 5분 후 사라진다. 즉시 보관함에 지급하던 이전 드롭 정책을 대체한다.

먹을 수 있는 아이템은 하단 슬롯에 자동으로 추가된다. 선택 → A(클래식은 사용 버튼)로 1개를 먹고 하트를 회복한다. 생돼지고기 2칸, 생닭고기/썩은 살점/당근/감자 1칸이다. 이는 배고픔 시스템이 없는 현재 게임의 간단한 음식 규칙이다. 최대 하트는 최소 10칸이며 보상으로 이를 넘기면 확장하고 최대 칸 수를 저장한다. 가득 찬 상태나 하트 0으로 플레이가 잠긴 상태에서는 먹을 수 없다. 시간 소모/몬스터 피해는 동일하게 유지된다.

하트 HUD는 숫자·소모 타이머 대신 채워진 하트/빈 하트를 표시한다. 몬스터에게 실제 피해를 받으면 가장자리 붉은 효과(0.5초), 짧은 카메라 흔들림/기울기, 피격음, 하트 밝기 변화와 충돌을 고려한 작은 밀림을 함께 적용한다. 카메라 연출은 저장된 시점 각도를 변경하지 않는다. 동작 줄이기 설정에서는 카메라 흔들림을 생략한다. 시간에 의한 하트 감소에는 피격 연출을 적용하지 않는다.

## NPC 음성 중 다음 잠금·발화 재시도

NPC 음성이 준비/재생 중인 현재 페이지는 A·다음·선택 버튼으로 넘기지 못한다. 종료되면 풀리고, 음성 로드 실패에도 잠금을 해제한다. 화면에 ‘듣는 중…’을 표시한다. 녹음 가이드와 실제 Speak 시작/완료 입력은 기존 동작을 유지한다.

인식된 단어가 있는 오답은 같은 차례에서 추가 2회, 총 3회 시도한다. 오답에는 보상/퀘스트 콜백을 실행하지 않는다. 세 번째 오답 후에는 자연스럽게 대화를 종료하며 다시 말을 걸어 연습할 수 있다. 서버의 원본 `recognizedText`로 단어 존재 여부를 구분하고, 단어가 전혀 없을 때만 ‘목소리가 들리지 않았다’고 안내한다. 인식된 오답은 연속 무음 카운터를 초기화해 마이크 점검 대사로 잘못 연결하지 않는다. 녹음/연결 오류는 별도 안내하며 오답 기회를 차감하지 않는다. 상태 문구는 textContent로 표시한다.

관련 단위 테스트는 `ground-food.test.js`, `hurt-feedback.test.js`, `speech-retries.test.js`다.

## 최신 블록 5종·보상 자동 슬롯

신규 대화의 블록 풀은 잔디(1)·흙(2)·돌(3)·참나무 원목(5)·참나무 판자(6)만 사용한다. 부분/완전 문장 수량 1/2, 하트, 무기 확률 20%는 유지한다. 신규 조각 보상은 돌 1개, Stage 완료는 원목/흙/돌 각 5개다. 기존 철/장식 블록 보유량과 이미 원장에 확정된 보상은 변경하지 않는다.

정책 버전은 3이다. 이미 발급한 버전 2 음성 토큰은 이전 블록 풀로 해석해 대기 보상과 영수증을 보존한다. 마일스톤 재요청 시 기존 원장에 보상이 있으면 그 약속된 내용을 반환한다.

`block-world/reward-hotbar.js`가 세계 로드/보상 수령 시 보유한 기본 5종을 터치로 접근 가능한 앞쪽 5개 건축 슬롯에 자동 배치한다. 빈 슬롯을 우선 사용하고 필요하면 예전 장식 블록 슬롯을 교체하며 보관함 수량은 건드리지 않는다. 저장 실패 시 보상 보관함과 슬롯을 함께 되돌린다. 슬롯에 수량을 표시하고, 보유하지 않은 빈 슬롯은 숨긴다. 기존 음식 선택/먹기와 검 선택/공격도 같은 하단 슬롯에서 유지한다.

단위 검증은 `reward-hotbar.test.js`, `speech-rewards.test.js`, API 통합 단위 테스트다.

## 고기 회복량 조정 (최신)

생돼지고기와 생닭고기는 1개당 하트 0.5칸만 회복한다. 이전 고기 회복량 설명보다 우선한다. 하트는 0.5 단위로 저장/검증하며 HUD에 반 칸을 표시한다. 보상·20초 소모·몬스터 피해·최대 하트·0칸 잠금 규칙은 유지한다. 관련 검증은 `ground-food.test.js`의 반 칸 저장/회복/보상/소모 테스트다.

## Stage 3 · C — 학교와 코코 구출

Stage 2 마지막 북쪽 게이트에서 올바른 버스에 타면 `SchoolYard`로 이어진다. 이미 B를 완료한 저장도 같은 게이트로 학교에 진입한다. 원작 3화의 학교 앞·복도·교실·준비실, Class/Cat/Come, 토미와 화해, 사일런트 섀도의 3라운드, 코코 구출·C 조각·첫 자기소개와 D 식당 예고를 구현했다. D 식당 내부 플레이는 아직 제공하지 않는다.

학교 탐색과 대화를 통해 필수 발화 21회를 진행한다. C 대화는 한 번 성공한 차례를 저장하며 중간에 닫거나 새로고침하면 남은 차례부터 이어진다. 보스 라운드는 각각 저장하고 마지막 `Come here, Coco!`에는 Coco 이름까지 필요하다. 실제 음량이 작다는 이유로 벌점을 주지 않으며 판정은 기존 서버 STT 기반 문장 확인이다.

실행 코드는 `magic-english-stage3.js`, `magic-english-stage3-controller.js`, 공유 학습 대상은 `magic-english-stage3-learning.js`다. 기존 A/B 컨트롤러에 맵·포털·목표·도감·보스·배지 표시를 연결하고 개인 저장 키에 `stage3` 필드만 추가했다. 중앙 저장 설정·10분 주기·재연결 전송은 그대로 적용된다.

새 배역은 teacher(선생님), tommy(토미), shadow(사일런트 섀도)다. `assets/audio/stage3/manifest.js`의 정적 ElevenLabs 음성과 원작에서 변환한 `assets/stage3/page01.jpg`~`page16.jpg`를 사용한다. 음성 재생성 도구는 `tools/prepare-stage3-audio.mjs`이며 실행 중인 로컬 서버의 키로 필요한 새 음성만 준비한다. 빌드 중 유료 음성 API를 호출하지 않는다.

### 로컬에서 C 바로 시작하기

`npm run dev` 후 **http://localhost:3000/magic-english/test/stage3**.

### C 맵·NPC 표현 개선

학교 외관을 시계탑·벽돌·창문·유리 현관·조경·스쿨버스로, 복도를 사물함·교실 문·식당 문·게시판·음수대로 구성했다. 교실에는 칠판·교탁·공책과 연필이 있는 책걸상·고양이 그림 이젤·창문·준비실 문이 있으며, 준비실에는 책장·미술 도구·코코 바구니·물그릇·장난감이 있다. 코코는 귀·수염·줄무늬·흰 가슴·긴 꼬리를 가진 픽셀 고양이로 표현한다.

기존 NPC에 더해 맵마다 3명 이상을 추가하여 학교 앞 4명, 복도 5명, 교실 7명(코코·보스 제외), 준비실 3명으로 구성했다. 추가 인물에게 장소에 맞는 대사와 고정 ElevenLabs 음성을 연결했다. 선택 대화이며 필수 말하기 21회 조건은 유지한다.

`magic-english-stage3-layout.js`가 건물·가구의 이동 충돌을, `magic-english-stage3-renderer.js`가 장소별 그림을 관리한다. 현관 진입 타일은 학교 앞 `(10,5)`이며 학교에서 나올 때 `(10,6)`에 선다. 기존 저장에서 새 가구와 겹친 위치는 기존 복원 처리로 안전한 칸에 옮기며 학습 진행은 보존한다. 활빈이 문·조사 대상을 가리지 않게 상호작용 우선순위와 동행 위치를 조정했다.

### CLASS 안내판과 일상 대화

CLASS 조사 대상은 교실 문에서 분리해 복도 중앙 `(10,5)`의 독립 안내판으로 옮겼다. 받침대가 `(9~11,5)`를 막아 중앙 보도를 따라 걸으면 `(10,6)`에서 멈춘다. 이 자리에서 A로 조사할 수 있다. 교실 출입문은 `(16,6)`에 유지하고 ROOM C로 표시한다.

C의 일반 NPC·주요 인물·활빈·구출 후 코코까지 20개 대화 상대에 일상 문답을 연결했다. 대화마다 플레이어 발화는 3~5회이며 학교 생활·책·미술·준비물·친구·기분·코코 돌보기 등을 다룬다. 완료 후 다시 방문하면 다른 주제로 바뀌고, 중간에 닫거나 새로고침하면 같은 주제의 다음 차례에서 이어진다. 진행 차례는 전체 대화를 기준으로 표시한다. 필수 이야기·보스 진행과는 별도이며 필수 경로의 발화 21회와 기존 완료 조건은 유지한다.

각 성공 발화는 Stage 1과 같은 서버 서명 토큰·보상 대기열·원장을 사용한다. 부분 성공은 기본 블록 5종 중 1개와 하트 1개, 완전 성공은 2개와 하트 2개이며 완전 성공에만 기존 20% 무기 추첨을 적용한다. 재요청·재수령으로 같은 발화가 중복 적립되지 않는다. 일상 대화 전용 target은 `s3_daily_`로 시작하여 이야기 조각·완료의 필수 원장을 대신 충족하지 않는다.

NPC 질문은 실제 배역의 ElevenLabs 음성으로, 플레이어 문장 가이드는 기존 에이미 배역으로 재생한다. 선생님·관리인·기사는 Bill 계열, 아이·에이미·토미·활빈은 기존 Fena 계열, 링고는 기존 로봇 배역을 유지한다. `assets/audio/stage3/manifest.js`는 231개 배역·문장 조합을 가리키며, 목소리 설정과 문장이 같은 경우 하나의 음원을 공유한다.

```sh
npm run test:magic-english-stage3:daily-browser
```

일상 대화 브라우저 검증은 20개 대화 상대의 3~5차례 문답, 보상 요청·재시도, 새로고침 후 남은 차례, CLASS 안내판 앞 정지를 확인한다. 테스트 음성·서명 응답·보상 전송은 mock이며 실제 사용자 기록을 수정하지 않는다.

## 하트 획득량 50% 조정 (최신)

모든 신규 보상 수령 시 하트 지급량을 블록 총수량의 절반으로 조정했다. 대화 부분 성공은 하트 0.5개, 완전 성공은 1개, 알파벳 조각은 0.5개, Stage 완료는 7.5개다. 기존 보유 하트·보상 영수증·블록 수량·무기 확률은 유지한다. 기존 영수증을 다시 조회해도 하트가 재지급되거나 기존 하트가 줄어들지 않는다. 음식 회복과 시간·피격 소모 규칙은 변경하지 않는다. 게임의 보상 안내에도 같은 수량을 표시한다.

## Stage 4 · D 식당

C 완료 후 학교 복도의 식당 출구에서 D로 이어진다. `magic-english-stage4*.js`가 식당 4개 맵, Door/Drink/Delicious/Dish, 3개 문장 기차, 미스스펠 3단계 대결, 황금 D 배지와 식사 완료를 담당한다. 기존 개인 저장 안에 `stage4`를 추가하며 A/B/C 기록과 건축·영수증을 유지한다. 13개 일상 대화 프로필은 3~5회 발화와 중간 재개를 지원한다. 서버는 D 전용 대결 발화와 식사 기록을 확인하고 조각·완료 보상을 각각 한 번 지급한다. 하트 보상은 기존 50% 기준이다.

로컬 전용 `/magic-english/test/stage4`는 `magic-english-stage4-test-v1`과 `stage4-test-UUID` 건축 프로필로 분리된다. 운영에서는 접근할 수 없다. 원작 4화 그림 16쪽과 고정 ElevenLabs 203개 음성 매핑을 포함한다. 구현/검증 상세는 `magic-english/STAGE-4-PLAN.md`를 따른다.

## iPad 가로 조작과 하트 메뉴

터치 기기의 가로 화면(폭 768px 이상)에서 마법영어는 왼쪽 방향 패드 / 원래 10:9 비율의 게임 화면 / 오른쪽 A·B 버튼을 한 화면에 배치한다. 화면 높이는 `dvh`와 안전 영역을 따른다. 세로 화면은 기존 배치를 유지한다.

메뉴의 **모은 하트 확인**은 현재 사용자 건축 세계에 저장된 잔액과 서버의 미수령 보상을 영수증으로 중복 제거하여 합산한다. 확인 화면에서는 건축 저장이나 영수증을 수정하지 않는다. 오프라인에서는 마지막 저장 잔액임을 표시한다.

블록 세계는 핀치·더블탭·Ctrl/Command 확대 입력을 차단하고, 시야각을 75도로 고정한다. 과거의 좁은 시야각 설정도 진입 시 교정한다. 입력 필드의 글자를 16px로 설정하여 iOS 자동 초점 확대를 방지한다. OS 자체 확대와 사용자가 브라우저 메뉴로 강제한 확대는 웹 페이지에서 제어할 수 없다.

검증: `npm run test:magic-english-hearts-menu`, 로컬 서버에서 `npm run test:magic-english-ipad`. 1024×768, 1180×820, 1366×1024 가로 배치·원본 화면 비율, 하트 잔액·미수령·오프라인, 확대 이벤트와 과거 FOV 교정을 확인한다. 실제 iPad Safari의 제스처는 기기 확인이 필요하다.

## 개인 월드 바로 이어가기와 C의 NPC 퀘스트

블록 세계의 생성 폼과 새 세계 버튼을 제거했다. 개인 URL의 사용자 코드로 저장된 세계를 자동 복원하고, 저장이 없는 첫 방문에만 빈 평지 세계를 자동 준비한다. 손상된 저장은 자동 교체하지 않고 복구 안내를 표시한다. 공용 `demo` 보상 원장으로 대체하지 않는다. 체험 접속은 브라우저별 `magic-guest-UUID`를 사용한다. 개인 저장·블록·하트·영수증은 유지하며 기존 demo 기록을 복사하지 않는다. 백업 가져오기·복구는 어른 설정에서 유지한다.

C는 에이미(Class), 미술 선생님/코코(Cat), 선생님(발표 사건·CLASS 복원), 링고(Come·COME 복원), 토미(화해), 미술 선생님(CAT 복원), 사일런트 섀도(대결), 선생님(자기소개) 순서로 진행한다. 기존 발표 자리나 간판을 조사할 필요가 없다. 핵심 21회 발화·C 배지·D 연결·중간 저장은 유지한다.

검증: `npm run test:magic-english-world-entry`, `npm run test:magic-english-stage3:browser`, `npm run test:magic-english-stage3:daily-browser`. 자동 말하기 검증은 모의 인식을 사용하며 실제 아동 음성은 기기 확인 대상이다.

## 몬스터 친구의 Speak 대화

블록 세계에서 좀비·크리퍼·돼지·닭을 처치하면 종류별 일상 대화 3~5턴을 끝내야 다시 플레이할 수 있다. 크리퍼의 자연 폭발도 같은 대화로 연결한다. 기본 인사 4개와 종류별 상황극 8개, 총 12개 이야기다. 졸린 좀비의 등교/독서, 수줍은 크리퍼의 부탁/그림 발표, 돼지 카페/소풍, 닭의 숙제/첫 발표를 다룬다.

`mob-conversations.js`는 기존 C/D 일상 대화 기록과 신규 `learning.practicedTargets`에서 연습한 표현을 찾아 우선 선택하고 주제를 순환한다. 대화 기록이 없는 기존 저장에는 쉬운 3턴 인사를 제공한다. 답변 표현과 서버 말하기 판정은 기존 마법영어를 공유한다. 새 하트·블록 보상을 추가하지 않으며 원래 드롭은 월드에 유지한다.

진행도는 기존 월드 저장 안의 `mobLearning`에 포함한다. 각 성공 발화를 저장하고, 새로고침·모험 왕복 후에도 남은 차례부터 이어진다. 대화 중 이동·공격·동물 이동·피해·밤낮 시간·하트 소모를 멈춘다. Escape/메뉴/인벤토리로 플레이를 재개할 수 없다. 마이크·네트워크 오류와 오답은 같은 차례에서 다시 시도한다. 완료 후에만 플레이를 재개한다. 여러 크리퍼가 같은 프레임에 폭발하면 대화를 순서대로 보관한다. 손상된 대화 저장은 세계 저장 검증에서 거절하며 자동 초기화하지 않는다.

배역은 `mob_zombie`(졸린 Bill), `mob_creeper`(robot Fena), `mob_pig`(유쾌한 Bill), `mob_chicken`(활기찬 Fena)로 고정한다. 84개 배역/대사 매핑을 정적 ElevenLabs MP3로 준비했다. 녹음 입력은 기존 16kHz WAV → 서버 → Scribe v2 판정을 재사용한다. 건축 화면에서도 정적 음성 경로를 마법영어 모듈 기준으로 해석한다.

검증: `npm run test:magic-english-mob-talk` 및 서버 실행 후 `npm run test:magic-english-mob-talk:browser`. 브라우저 테스트는 실제 전투 입력으로 네 종류를 처치하고, 발화는 모의한다. 실제 iPad 마이크 발화는 기기 확인이 필요하다.


## 마법영어 단독 운영 (2026-10-30)

- 메뉴·상단 탐색·사이드바·알파벳 도감·A 엔딩·직접 호출 진단 훅에서 건축 이동 기능을 제거했다. 하트 확인 메뉴와 자원/무기 보상 안내도 제거했다. `?view=block-world`는 제거하고 영어 모험을 이어간다.
- 말하기 API는 발화 판정만 반환하며 자원 수량·보상 토큰·블록·무기 추첨을 생성하지 않는다. `/api/magic-english/rewards`와 모든 `block-world/*` API는 410으로 종료한다. 예전 대기열은 읽어 전송하지 않는다.
- 말하기와 퀘스트 완료는 학습 체크포인트/알파벳 배지만 기록한다. A 완료도 코인·건축 블록·장식을 지급하지 않는다. 기존 `rewardReceipts` ID는 저장된 모험의 문 열림/구출 판정을 위해 유지한다.
- 원본 `magic-english/block-world/`와 관련 보관 코드는 그대로 남긴다. 공개 자산 동기화에서 블록 세계 폴더·구형 건축/하트 UI·몬스터 음성 자산을 제외한다. 예전 블록 세계 페이지는 마법영어로 돌려보내고 정적 실행 주소는 제공하지 않는다.
- 기존 월드·보유 아이템·영수증·학습 이력을 지우거나 초기화하지 않는다. 중앙 저장 키도 유지한다. 새 모험의 호환용 `blockWorld` 필드는 자원 0개로 둔다.
- 현재 검증 명령: `npm run test:magic-english`, `npm run test:magic-english-only:browser`, C/D 브라우저 검증. 과거 Minecraft/하트/몬스터 대화 브라우저 도구는 보관용이며 현재 운영 검증에 포함하지 않는다.
