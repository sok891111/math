# Creative 수학 — 몬스터 원정대

## 조사한 자료와 범위

2026-10-11에 공개된 목차, 출판사 설명과 매스티안 자료실을 확인했다. 교재 전체를 검토한 것은 아니며, 특정 문항의 그림이나 지문을 옮기지 않았다. 공개된 문제 유형을 게임용 퍼즐로 새롭게 구성했다.

- [매스티안 공식 교재 소개](https://www.mathtian.com/book/book_main.aspx): 키즈 기본/응용과 수준별 팩토 체계.
- [매스티안 공식 형성평가 자료실](https://www.mathtian.com/data/formative_down.aspx): 기본 B의 규칙·기하·문제해결력, 기본 C의 연산·공간·논리추론 구분.
- [키즈 팩토 기본 A — 출판사 제공 목차](https://www.yes24.com/product/goods/128120668): 길 찾기 퍼즐, 수 배치 퍼즐 등.
- [키즈 팩토 기본 B — 출판사 제공 목차](https://www.yes24.com/product/goods/128120996): 여러 가지 규칙, 배열 규칙, 대칭 모양과 거울에 비친 모양, 길 찾기 등.
- [키즈 팩토 기본 C — 출판사 제공 목차](https://www.yes24.com/product/goods/128121399): 위치와 방향, 배치하기 등.
- [매스티안 키즈 응용 C 공식 정답·풀이 PDF](https://www.mathtian.com/UploadPath/NewAnswer/%5B%EC%A0%95%EB%8B%B5%5D%ED%8C%A9%ED%86%A0%ED%82%A4%EC%A6%88%20%EC%9D%91%EC%9A%A9C_OUT.pdf): 공개 검색 결과에서 조건에 맞게 배치하는 유형과 풀이 흐름 확인.

7세~초1 키즈의 시각적 사고력 유형을 출발점으로 선택했다. 게임의 1~5성은 자체 난이도이며 팩토의 공식 레벨과 대응하지 않는다.

## 몰입을 위한 변화

이전 화면은 정적인 배틀 아래 객관식 문제를 푸는 흐름이었다. 이번에는 지도의 지역을 선택하고, 지역마다 몬스터의 행동을 해석해 대응하는 조작을 한다. 퍼즐을 완성하는 것이 전투 기술을 준비하는 행동이다. 지문을 읽고 정답 숫자를 선택하는 방식 대신 속성 연결, 방패 점등, 경로 연결, 룬 배치를 사용한다.

| 교재에서 확인한 유형 | 게임 상황 | 직접 하는 행동 | 성공 시 기술 |
| --- | --- | --- | --- |
| 반복·배열 규칙 | 메아리 숲 몬스터의 공격 리듬 | 두 번 반복된 리듬을 보고 다음 2~3개 속성을 연결 | 리듬 브레이크 |
| 거울 대칭 | 거울 동굴의 마법 공격 | 대칭축 반대편의 빛나는 방패 칸을 켜고 끄기 | 미러 카운터 |
| 길 찾기·위치와 방향 | 돌진 유적의 장애물과 보석 | 이웃한 칸을 연결해 보석을 모두 지나 이동 에너지 안에 도착 | 루트 대시 |
| 조건에 맞게 배치 | 엔더 신전의 보호막 | 위치·상대 순서·이웃한 수의 합 단서로 룬 배치 | 룬 봉인 |

문제 수가 많아지는 것뿐 아니라 규칙 묶음 길이, 대칭 격자와 축, 보석 수, 논리 조건이 달라진다. 퍼즐은 매 턴 새로 생성된다. 길 찾기는 생성 단계에서 해답 경로를 확보하고, 룬 배치는 해답의 유일성을 확인한다.

## 게임 흐름

지도 → 지역/카드 등급 선택 → 등장 연출 → 퍼즐 조작 → 기술/적 반격 → 다음 턴 → HP 0 → 큐브볼 투척 → 카드 발견 또는 탈출 → 같은 지역 탐험/지도.

- 정답 기술의 기본 피해는 25. 힌트 없이 첫 시도로 연속 성공하면 2연속부터 35 피해.
- 오답은 적 반격으로 연결되며 보호막 3개 중 하나를 사용한다. 같은 퍼즐을 수정할 수 있다. 보호막이 모두 소진되면 다음 탐험으로 넘어간다.
- 풀이에는 시간 제한이 없다. 힌트와 초기화가 있고, 연결 완료 전에는 반격 버튼을 잠근다.
- 동료 카드는 도감에서 선택할 수 있다. 실제로 수집한 동료와 함께하면 포획 성공률 +3%.
- 포획 기본 확률은 1~5성 각각 80/68/56/43/30%. 연속 성공 보너스 최대 +6%, 정확한 투척 +10%. 최종 확률 상한 94%.
- 포획 판정은 투척 시 한 번만 한다. 연출 도중 중복 투척할 수 없다.
- 동작 감소 설정에서는 연출을 줄이고 투척 타이밍을 황금 구간 중앙에 둔다.
- 지도로 돌아가는 배틀 중 이탈은 확인 대화상자를 사용한다. 애니메이션 중 이탈은 잠근다. 이전 배틀의 지연 콜백은 새 배틀에 적용되지 않는다.

## 캐릭터와 저장

Craft Runner의 `MonsterArt`를 사용한다. 24종 모두 1~5성으로 등장해 120장 도감을 완성할 수 있다. Runner의 창작 캐릭터인 엔더 기사도 기존 카탈로그에 포함돼 있다.

기존 `creative-monster-cards-v1:<사용자 ID>` 저장 키와 카드 횟수를 유지한다. 기기에 카드 수집, 동료, 지역, 난이도를 저장한다. 다른 기기로 도감이 자동 동기화되지는 않는다. 배틀 중간 상태는 저장하지 않는다.

기존 다리/워든 게임은 `creative/legacy.html`에 남겨 두었고, 기존 배지 데이터는 그대로 유지된다. 새로운 카드 도감은 Creative 화면 안의 도감에서 확인한다.

## 검증

- `node tests/creative-battle-model.cjs`: 등급별 4유형 × 120 시드, 총 2,400개 퍼즐. 유일한 논리 해답, 정상 경로, 보석, 오답/미완성 입력, 24종 배치, 포획 확률과 보너스 검증.
- `node tests/creative-battle.cjs`: 실제 버튼/타일 조작으로 네 유형 전투, 적 반격, 힌트, 포획 성공/실패, 보호막 소진, 저장 복원, 동료 선택, 이탈 확인 및 모바일 화면 검증. 기본 대상은 로컬 Next 서버 `http://localhost:3000`.
- `BATTLE_TEST_URL`로 브라우저 테스트 서버 변경 가능. `CHROMIUM_PATH`로 Chrome 경로 변경 가능.

## 보행 및 드래그 업데이트 (현재 동작)

기본 플레이 흐름은 지역 이동 → 마을·길·풀숲 걷기 → 랜덤 만남 → 드래그/클릭 퍼즐 → 반격 → 확률 포획 → 걸었던 위치로 돌아오기이다. 위의 초기 버전 설명 중 1~5성 선택과 120장 도감은 이 업데이트로 변경되었다.

- 네 지역에 서로 다른 마을 이름, 건물 배치, 지형 색, 수정·기둥·별빛 장식을 사용한다. 마을과 길에서는 몬스터가 나타나지 않는다.
- 방향키/WASD, 누르고 있는 터치 방향 버튼, 맵 클릭 후 경로 이동을 지원한다. 나무·건물·물은 통과할 수 없다.
- 풀숲에서 한 칸 움직일 때 만남 확률은 17%. 14번 연속 풀숲 이동 시 만남을 보장한다. 등장 등급은 1성 55%, 2성 30%, 3성 15%다. 등급 선택은 없다.
- 배틀 후 현재 위치로 돌아오고 6칸의 재만남 유예를 둔다. 서 있거나 도감을 보는 동안에는 만남이 발생하지 않는다.
- 24종 × 1~3성으로 현재 수집 목표는 72장이다. 기존에 모은 4~5성 카드는 삭제하지 않고 이전 등급 필터에서 열람할 수 있다.
- 속성·룬·빛 조각의 드래그 앤 드롭, 돌진 경로의 연속 드래그를 Pointer Events로 처리한다. 마우스와 터치를 지원하고 클릭/탭 입력도 유지한다.
- 잘못된 위치에 놓으면 입력을 바꾸지 않는다. 포인터 취소 시 드래그 표시를 정리하고, 취소된 경로 드래그는 시작 전 상태로 복구한다.
- 규칙 배열은 한 줄의 순서를 유지한다. 긴 배열이 좁은 화면보다 길면 배열 안에서 가로로 넘겨 볼 수 있다. 번호와 답안 자리의 겹침을 방지한다.
- `tests/creative-world.cjs`: 안전 지역, 충돌, 풀숲 접근, 무작위 등급, 나쁜 운이 지속될 때의 만남 보장.
- `tests/creative-battle.cjs`: 실제 보행 후 1/2/3성 만남, 네 유형의 마우스 드래그 풀이, 모바일 터치 드래그/방향 버튼, 320/390/768/1024/1400px에서 4유형 레이아웃 검증.
- `tests/creative-drag-edge.cjs`: 연속 터치 경로 그리기, 취소된 드래그 정리, 첨부 화면의 12개 기호 배열을 다섯 화면 폭에서 재현해 한 줄 유지와 답안 영역 겹침 여부 검증.

## 부드러운 이동·넓은 탐험·몬스터별 공격 업데이트

- 이동 한 칸(155ms)의 시작/끝 좌표 사이를 매 requestAnimationFrame에서 보간한다. 이동 입력은 유지되고, 만남 판정은 실제로 해당 칸에 도착한 뒤 배틀로 연결한다.
- 카메라는 캐릭터의 렌더링 좌표를 시간 기반으로 부드럽게 따라간다. 보행 중 다리가 번갈아 움직이며, 맵 클릭으로 지정한 경로에서도 같은 이동을 사용한다.
- 지역마다 96×24칸 지도를 사용한다. 동서 길, 강과 다리, 네 개의 먼 탐험 지점, 지역별 쉼터·제단·전망대·차원문이 있다. 풀숲은 연속 사각형 대신 빈 공간이 섞인 구역으로 배치한다.
- 화면에 보이는 타일만 그려 넓어진 맵의 렌더링 부담을 줄인다.
- `combat-art.js`가 24종의 서로 다른 공격 스타일과 몸의 자세를 관리한다. 동료의 정답 공격과 야생 몬스터의 반격 모두 해당 캐릭터의 연출을 사용한다.
- 파동, 할퀴기, 점프, 화살, 거미줄, 물약, 순간이동, 용암, 화염탄, 해골탄, 광선, 송곳니, 돌진, 도끼, 회오리, 추적 구슬, 땅속 습격, 검격, 브레스, 음파, 깃털, 돼지 돌진, 토끼 킥, 여우 덮치기를 구분한다.
- `tests/creative-motion-combat.cjs`: 연속 프레임의 중간 좌표, 실제 48칸까지의 횡이동과 카메라 추적, 96칸 맵 연결성, 24개 공격 스타일, 숲의 워든 동료가 음파를 사용하는 배틀 검증.

## 가독성과 오답 안내

게임 화면은 화면의 남은 세로 공간을 채운다. 데스크톱 문제 제목은 24px, 단서는 18px, 설명은 16px이며 모바일에서는 각각 17~18px, 13~14px, 12~13px로 조정한다. 화면이 짧을 때는 내용을 잘라내지 않고 스크롤할 수 있다.

오답은 적의 공격 연출 뒤 문제 입력을 초기화하고, 해당 몬스터 이름과 “처음부터 다시 풀어보자” 안내창을 표시한다. 안내창을 닫기 전에는 문제를 조작할 수 없다. 문제 자체와 몬스터 HP는 유지하며 보호막은 기존 규칙대로 하나 줄어든다. 보호막이 소진된 경우에도 안내 후 새 배틀로 재도전할 수 있다. `tests/creative-retry-layout.cjs`에서 네 유형의 초기화·안내·재개와 화면 크기별 가독성을 검증한다.

## 등급 능력치와 12유형 출제

추가 조사에서는 키즈 기본 A/B/C, 팩토 원리 1B의 출판사 제공 목차와 [매스티안 공식 형성평가](https://www.mathtian.com/data/formative_down.aspx)의 A/B/C PDF를 확인했다. 공식 PDF에서는 수 조건 추론, 모양의 일부 완성, 도형 조각 조합, 그림 기호의 연산 관계 등을 살펴봤다. 문항과 그림을 전재하지 않고 해당 사고력 영역을 게임용 생성 퍼즐로 구성했다. 추가 자료: [키즈 기본 A](https://www.yes24.com/product/goods/128120668), [키즈 기본 C](https://www.yes24.com/product/goods/128121399), [팩토 원리 1B](https://www.yes24.com/Product/Goods/84806366), [팩토 레벨 1 탐구 목차](https://www.yes24.com/product/goods/23809489).

| 등급 | 기본 공격력 | 동료 최대 체력 | 야생 몬스터 체력 |
| --- | --- | --- | --- |
| 1성 | 25 | 150 | 50 |
| 2성 | 40 | 180 | 100 |
| 3성 | 60 | 225 | 180 |

연속 정답 2회부터 피해 +10. 같은 3성 적을 상대로 1/2/3성 동료의 필요 정답 수는 연속 정답 기준 6/4/3회다. 적 반격의 피해에도 등급별 공격력을 사용한다. 안내창과 입력 초기화는 유지되며, 이전의 보호막 개수 대신 동료 HP가 실제 피해만큼 감소한다.

동료 선택은 캐릭터와 카드 등급을 함께 저장한다. 이전 저장에 등급이 없으면 해당 캐릭터의 실제 보유 카드 중 가장 높은 등급으로 복구한다. 도감에서 같은 캐릭터의 낮은/높은 등급을 각각 선택할 수 있다. 배틀 중 동료를 바꿔도 현재 HP를 회복시키지는 않는다. 새 배틀을 시작하면 선택한 동료의 최대 HP로 회복한다. 이전 4/5성 수집 카드는 공격력 75/90, 체력 250/280으로 보존된다.

기존 4유형에 8유형을 추가했다.

| 지역 | 출제 유형 |
| --- | --- |
| 숲 | 공격 패턴, 수 규칙, 속성 분류, 유비 추론 |
| 동굴 | 거울 대칭, 회전 방패, 블록 탑 세기, 유비 추론 |
| 유적 | 길 찾기, 수 모으기, 균형 저울, 수 규칙 |
| 신전 | 조건 배치, 수 배치 격자, 균형 저울, 속성 분류 |

각 지역의 최근 두 유형은 바로 재출제하지 않고, 덜 나온 유형을 우선한다. 최근 24개 문제의 내용도 기록해 같은 문제를 피하며, 출제 이력은 기기에 저장된다. 드래그, 클릭, 오답 안내, 입력 초기화를 모든 유형에 적용한다. 수 모으기는 정해진 조각 수와 합을 만족하면 여러 해답을 인정한다. 수 배치 격자는 각 행의 빈칸을 한 개 이하로 생성해 결정 가능한 해답을 확보한다.

검증: `tests/creative-facto-model.cjs`의 신규 2,880문제와 기존 모델의 2,400문제, `tests/creative-facto.cjs`의 등급별 실제 피해·선택 등급 저장·8유형 드래그 풀이·오답 초기화·24개 화면 크기 검사·자연 출제 순환·포획을 확인한다.

## 상세 힌트

12유형 모두 관찰 → 규칙 찾기 → 현재 문제에 적용하는 3단계 힌트를 안내창에서 제공한다. 다음 단계 버튼으로 필요한 만큼 열 수 있고, 마지막 단계는 구체적인 답 또는 가능한 해답 하나를 보여 준다. 현재 입력은 유지된다.

변환 문제는 세 가지 색·모양이 모두 등장하는 예시 3개를 제공하고, 색과 모양이 독립적인 같은 규칙을 따른다고 명시한다. 힌트는 실제 생성된 문제의 색 순환, 모양 순환, 현재 조각의 변환 결과를 각각 설명한다. `tests/creative-hints.cjs`에서 첨부된 파란 마름모 → 주황 동그라미 사례, 전 유형 힌트, 예시의 색 범위, 단계별 안내창과 입력 보존을 검증한다.

## 선율의 학습 기준: 7살

사용자가 선율이 7살이며 270도 같은 각도 개념을 모른다고 알려 주었다. 키즈~초1 유형을 참고해 만든 자체 난이도는 공식 팩토 단계와 일치하지 않으며, 현재 전체 콘텐츠가 선율의 선행 지식에 맞춰 검증된 상태는 아니다. 복합 수 규칙과 균형 저울 등은 별도의 학습 수준 확인이 필요하다.

회전 문제에서는 모든 등급의 숫자 각도를 제거하고, 오른쪽으로 한 번 돌리는 동작을 그림으로 직접 보여 준다. 높은 등급은 새로운 각도 개념이나 돌리는 횟수를 추가하지 않고 빛 조각 배치를 더 복잡하게 한다. 힌트는 위/아래/가운데와 왼쪽/오른쪽 위치 언어로 설명한다. `tests/creative-age-seven.cjs`에서 각도 표기 제거, 그림 시연, 입력 보존과 모바일 배치를 확인한다.

## 7~8살 생각 놀이 프로필 (현재 기본 출제)

현재 1~3성 출제는 각도·곱셈·나눗셈 선행 학습을 요구하지 않는 그림 관찰·수 세기·조합 중심으로 조정했다. 공식 팩토 단계나 아이 개별 학습 수준을 인증하는 표시는 아니다.

- 문제에서 사용하는 수와 답 조각은 20 이내. 수 규칙은 1씩, 2씩, 1·2 번갈아 늘어나기와 점 그림으로 제시한다.
- 블록 탑은 총 12개 이하, 수 모으기는 1~5 조각으로 합 15 이하를 만든다. 조각에 점을 그려 놓고 에너지 칸이 채워지는 모습을 보여 준다. 다른 합 조합도 인정한다.
- 저울은 보석 하나와 추를 비교한다. 같은 추끼리 짝지어 빼고 남은 추를 세면 된다. 보석 여러 개를 나누는 계산은 제외한다.
- 변신 조각은 색 또는 모양 한 가지만 바뀐다. 분류는 조건 두 가지 이하, 수 배치 격자는 모든 등급 3×3, 논리 배치는 세 조각이다.
- 거울은 최대 3×3에서 빛 세 개 이하, 길 찾기는 최대 4×4·6칸 이동, 회전은 한 번 돌리는 시연을 지원한다.
- 한 문제의 첫 실수는 연습 방패가 막아 HP를 줄이지 않는다. 이후 반격에는 기존 등급별 피해를 적용한다. 반복 실수 후에는 힌트 2~3단계를 자동으로 열어 주고, 입력을 초기화한 같은 문제를 이어서 풀게 한다.
- 힌트를 써도 정답 공격력과 연속 성공 보너스를 유지한다. 문제를 풀면 등급에 따라 생각별 1~3개를 받고, 포획 결과와 별개로 기기에 저장한다.
- `tests/creative-learning-profile.cjs`는 5,400개 문제의 숫자·격자·선행 개념 범위를 검사하고, 추 그림·첫 실수 보호·자동 도움·힌트 이후 보상·생각별 저장을 실제 브라우저에서 확인한다.

## 숲 자원과 집 짓기

- 숲 지역에서 실제 한 칸 이동을 마칠 때 25% 확률로 나무 1개를 얻는다. 서 있거나 막힌 방향으로 이동할 때, 배틀 중, 집 자리 선택 중에는 나무를 얻지 않는다. 몬스터 등장 확률과 별도의 난수를 사용한다.
- 현재 나무 개수와 지은 집 수를 맵에 표시한다. 나무 10개 이상이면 숲의 집 짓기 버튼이 켜진다.
- 빈 땅을 누르면 3×2칸 집 자리 미리보기를 표시하고, 건설 전 사용·잔여 나무를 안내한다. 확인하면 나무 10개를 차감해 집 한 채를 짓는다. 취소하면 나무를 사용하지 않는다.
- 길, 물, 기존 건물, 플레이어/출발지/NPC 위치와 주요 탐험 지점 주변은 건설할 수 없다. 집 아래 출입 공간도 비어 있어야 한다. 지은 집은 통과할 수 없는 맵 건물로 처리한다.
- 나무와 집 좌표를 기존 사용자별 저장 데이터에 함께 기록한다. 지역을 다시 방문하거나 새로고침하면 집을 복원한다. 이전 카드와 생각별 저장을 유지한다.
- `tests/creative-building.cjs`: 숲에서만 적용되는 확률, 10개 잠금 해제, 건설 가능/불가능 자리, 취소, 정확한 비용, 충돌, 길의 연결, 저장 복원과 모바일 범위를 검증한다.
