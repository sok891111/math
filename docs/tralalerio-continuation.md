## 프로젝트 성격

## 다음 작업의 기준

원본 회귀 테스트를 계속 사용한다. 출현 가중치 테스트만 승인된 60:40 확장에 맞춰 조정했다. 맵 왕복, 상점, 회복, 전투 규칙, 공격 연출과 회전 전환 테스트는 유지한다. 원본 기능을 수정할 때 마인크래프트 종도 같은 경로에서 적용되는지 확인한다.

원본이 명시한 미구현 범위는 진화, 트레이너 전투, PC 보관함 출입, 원작 사운드, 30·46번 도로, 포켓몬센터 2층, 날씨·지닌 도구·통신·필드 독 대미지다. 이는 후속 후보 목록이며 이번 요청에서 새 기능으로 임의 구현하지 않았다. 현재 보관함은 6마리 초과 포획의 저장만 지원한다.

## 원본 업데이트와 재현

`upstream/baseline.json`에 원본 전체 런타임의 SHA-256과 전체 커밋 ID를 기록했다. `node tralalerio/tools/check-upstream.cjs [원본 프로젝트 경로]`는 원본의 추가/삭제/변경 및 뜨랠레리오의 로컬 차이를 읽기 전용으로 보고한다. 원본에 새 변경이 생기면 차이를 검토해 병합하고 테스트한다. 60:40 데이터와 개인별 저장을 덮어쓰는 자동 동기화는 하지 않는다.

전체 자산 재생성은 Python Pillow 및 `upstream/README.md`에 명시된 역어셈블 소스 커밋을 준비한 다음 `node tralalerio/tools/rebuild-assets.cjs <소스 경로>`로 실행한다. 네 원본 생성기 → 마인크래프트 확장 적용 → 공개 자산 동기화 순서다. 원본 README도 보존했으므로 데이터 출처와 원래 한계를 확인할 수 있다.

검증 명령:

```sh
npm run test:tralalerio
npm run dev
# 별도 터미널. localhost:3000 서버 필요
npm run test:tralalerio-browser
node tralalerio/tools/check-upstream.cjs
```
