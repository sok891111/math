# 아이별 부모 페이지와 학습 기록

- 주소: `/<개인코드>/parent`. 아이의 로비와 관리자 사용자 목록에서 진입한다.
- 인증: 기존 `/api/admin/auth` 관리자 비밀번호를 재사용한다. 학습 조회 API는 `x-admin-secret`을 검증하며, 개인 주소만으로 조회할 수 없다. 현재 인증은 아이별 보호자 계정이 아닌 전체 아이의 관리자 인증이다. 부모 인증은 탭의 sessionStorage에 보관하고, 기존 관리자 로그인도 사용할 수 있다.
- 대시보드: 기간별 수학/영어 모험/영어 건축 사용 시간, 일별 그래프와 표, 수학 정답·오답·넘김·힌트 사용, 유형/게임 난이도 분포, 영어 발화 시도/전달 결과/표현별 연습 분포.
- 전체 이력: 날짜·검색·결과별 필터와 20건 단위 페이지. 모든 시도는 삭제/덮어쓰기 없이 누적된다. 수학 문제 원본·당시 답안·정오 판정·힌트 단계·풀이 소요를 저장한다. 영어는 목표 표현·인식된 문장·완전/부분 전달·재연습·미인식·기기/서버 오류를 구분한다. 발음 능력의 측정값이 아니다.

## 수집과 저장

`lib/central-state/html.cjs`는 개인 게임 HTML에 `/learning-client.js`를 주입한다. 체험·개발실은 수집하지 않는다. 대상은 뜨랠레리오, 마법영어, 연결된 블록 세계다. 로비나 부모 페이지를 보는 시간은 제외한다.

수학은 `tralalerio/math-puzzle-ui.js`의 실제 제출/넘김 후 해결된 시도만 기록한다. 정답 판정 자체는 기존 게임 로직을 사용한다. 도형 등 비텍스트 문제도 당시 전체 생성 데이터를 저장한다. 페이지에는 지원되는 문제의 수식·문장·보기·모양·표·배치와 답안을 보여준다. 도형/배치 답안은 게임 내 칸별 값 또는 선택 번호로 표시한다.

영어는 공용 `createSpeechRecognizer`가 결과/오류를 마치는 시점에 기록한다. 모든 Stage·반복·일상·몬스터 대화가 같은 경로를 사용한다. 오디오 파일은 로그에 저장하지 않는다. 브라우저의 음성 개인정보 안내에도 인식 문장 저장 사실을 표시한다. 취소하여 완료 결과가 없는 녹음은 저장하지 않는다.

시도는 개인 코드와 이벤트 UUID별 localStorage에 먼저 저장하고 `POST /api/user/<코드>/learning`에 최대 30개씩 재전송한다. 오류가 나도 게임 진행을 막지 않는다. 온라인 전환·다음 개인 게임/부모 페이지 접속·15초 주기로 미전송 기록을 다시 보낸다. 같은 ID는 `putOnce`로 중복 저장하지 않는다. 부분 배치 전송 실패도 같은 내용으로 재시도한다.

영구 저장은 기존 `createMagicStore`의 Supabase `kv_store`를 사용하며 키는 `magic-english:learning:<코드>:event:<UUID>`다. 별도 DB 테이블은 필요하지 않다. 로컬은 기존 `.magic-english-data/` 어댑터를 사용한다. Vercel에서 Supabase 미설정 시 저장에 실패하며 기기의 미전송 기록은 남는다. 자식 코드로의 기록 쓰기 권한은 기존 게임 저장 API와 같고, 조회만 관리자 인증을 요구한다.

## 사용 시간의 정의와 한계

- 보이는 화면에서 최근 120초 안에 조작한 시간을 1초 간격으로 계산하고 약 15초마다 기록한다.
- 탭이 숨겨지거나 페이지를 떠날 때 남은 시간을 저장한다. 여러 탭은 개인 코드별 활성 탭 임대 기록으로 중복을 억제한다.
- 백그라운드 타이머의 큰 시간 점프는 최대 5초로 제한한다.
- 영어 모험과 연결된 건축은 별도로 표시한다. 모험 시간은 이동/대화/전투를 포함하며 문제 풀이만의 시간과 같지 않다.
- 장시간 생각/듣기, 브라우저 강제 종료, 저장공간 부족, 브라우저 데이터 삭제, 다른 기기의 아직 미전송 기록은 집계의 한계다. 정확한 의료적/발달적 평가로 해석하지 않는다.
- 새 수집 이전의 전체 문제/실제 발화/사용 시간을 기존 진행도에서 만들어 내지 않는다. 기존 모험·보상·게임 저장 기록은 변경하지 않는다.
- 현재 조회는 아이별 저장 이력을 읽어 서버에서 요약/검색/페이지 처리한다. 매우 큰 장기 데이터에서는 시간 구간 인덱스/집계 테이블로 확장할 수 있다.

## 부모 계정·이용 관리 업데이트

이 절이 위의 초기 관리자 공용 인증/오프라인 플레이 안내보다 우선합니다.

1. 관리자가 `/admin`의 아이별 **부모 계정 · 비밀번호 설정**에서 부모 ID와 첫 비밀번호(8~128자)를 등록한다. 기존 부모 ID에 비밀번호를 비우고 연결하면 형제·자매를 같은 부모 계정에서 관리할 수 있다. 이때 기존 비밀번호는 바뀌지 않는다. 관리자 비밀번호 재설정은 해당 부모의 다른 로그인도 해제한다.
2. 부모는 `/<아이코드>/parent`에서 부모 ID/비밀번호로 로그인하며 연결된 아이만 조회/제어한다. 부모 페이지에서 현재 비밀번호를 확인하고 새 비밀번호로 변경할 수 있다.
3. 비밀번호는 무작위 salt+scrypt 해시로 저장한다. 세션은 12시간 만료의 HttpOnly/SameSite=Strict 쿠키이며 HTTPS에서 Secure를 설정한다. 원문 세션 토큰은 DB에 저장하지 않고 SHA-256 키만 저장한다. 비밀번호 변경/재설정은 계정 버전을 바꿔 기존 세션을 무효화한다. 계정별 실패 10회는 15분 동안 로그인을 제한한다.
4. `전체 게임 금지 / 허용`은 부모 세션과 아이 연결 관계를 검증한 서버 API만 변경할 수 있다. 학습 로그 업로드는 금지 중에도 허용해 대기 기록을 잃지 않는다. 새 STT 평가/보상 발급은 금지 중 거부한다.
5. 게임 진입은 Next 14 `middleware.js`에서 서버에 현재 제한 상태를 조회한다. 개인 로비/모든 개인 게임, 개인코드가 있는 마인크래프트, 아이 기기의 기존 체험/정적 진입 URL도 검사한다. 새 개인 게임 진입 시 HttpOnly `block_child` 쿠키를 설정하고 체험 진입을 같은 관리 대상 게임으로 연결한다.
6. 모든 개인 게임은 `game-access.js`를 통해 시작 전 상태를 재확인한다. 이미 열린 게임도 10초마다 확인해 금지 시 화면 조작을 막고 휴식 안내로 이동한다. 오프라인·설정 서버 오류 시에도 게임 시작/계속하기를 허용하지 않는다. 백그라운드 브라우저 타이머가 지연될 수 있으며 다시 화면에 돌아오거나 BFCache 복원될 때 다시 확인한다.
7. 부모 페이지·휴식 안내·기록 업로드는 금지 대상에서 제외한다. 모험/보상/학습 저장은 삭제하지 않는다.

운영 환경에서는 `ADMIN_SECRET` 또는 `ADMIN_PASSWORD`를 반드시 지정한다. 기존 공개 기본 관리자 비밀번호 3종은 운영에서 받지 않으며, 설정된 관리 비밀번호가 있는 로컬에서도 받지 않는다. 별도 설정 없는 로컬만 개발용 `admin`을 사용한다. 부모 로그인에는 관리자 비밀번호를 사용하지 않는다.

서버 저장은 기존 `kv_store`의 `magic-english:parent:*` 키를 사용한다. 별도 DB 테이블이나 신규 외부 서비스는 없다. 현재 설정은 프로젝트의 개인 코드/등록된 브라우저에서 관리하는 게임에 적용된다. 사이트 데이터 삭제·다른 개인 코드·새 브라우저의 익명 체험이나 외부 앱까지 기기 전체를 잠그는 기능은 아니며, 그 범위는 OS의 자녀 보호 기능이 필요하다.

### 마인크래프트 플레이와 Speak

‘영어 건축’ 표기를 **마인크래프트 플레이**로 바꾸었다. 건축뿐 아니라 이동·탐험·몬스터 대화 등 해당 게임의 활성 플레이 시간을 집계한다. 새 플레이 시간에는 세션 ID를 저장하고, 플레이 이력은 15초 내부 기록을 세션별로 묶어 시작/마지막 기록 시각·활동 시간·Speak 시도 수를 보여준다. 기존 시간 기록은 2분 이상 간격을 기준으로 묶는다.

마인크래프트 몬스터 대화도 `createSpeechRecognizer`의 공통 로그를 사용한다. 이제 `game: magic-english-world`와 세션 ID를 함께 보관하며, 부모 페이지의 영어 전체 이력에서 **말한 장소**로 마법영어 모험/마인크래프트를 나누어 조회할 수 있다. 마인크래프트 대화 UI도 실제 목표 문장을 명시적으로 전달한다. 이전에 장소 구분 없이 수집한 영어 이력은 어느 게임에서 말했는지 소급 확정할 수 없다.
