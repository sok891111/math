# 수학 마법 러너

Platformer의 기본 진입 화면을 자동 달리기 모험으로 바꾼다. 쿠키런 오븐브레이크의 간단한 조작·수집·능력 발동에서 구조를 참고하고, 이 프로젝트의 Minecraft 그림과 수학 문제로 구성한다. 외부 게임의 캐릭터·그래픽·음악을 복사하지 않는다.

## 실행

- 공용: `/platformer` 또는 `/platformer/index.html`
- 개인: `/{userId}/platformer`
- 기존 자유 이동/캠페인: 화면의 ‘기존 모험’ 또는 `?mode=classic`

기존 `game.js`, 캠페인·배지 저장은 유지한다. `runner-launch.js`가 기본 러너와 기존 모험을 선택한다. 러너 모델은 `math-runner-v1[:개인코드]`에 별도 저장한다. 이전 저장 키를 삭제·변환·덮어쓰지 않는다.

## 플레이와 수학 보상

기본 자동 이동과 큰 점프/슬라이드 버튼을 사용한다. 키보드 Space/↑/Z 점프, ↓/S 슬라이드, Esc/P 일시정지. 수학 도전 세 곳에서 달리기가 멈춘다. 문제 시간 제한·시험 점수 통과 조건은 없고, 오답은 힌트를 읽고 같은 문제를 다시 풀 수 있다. 힌트는 기존 포켓몬 문제의 풀이 방향 안내를 재사용한다.

1. 돌진의 문: 정답이면 8초간 이동속도210→360, 실제 장애물 파괴·점수 보너스.
2. 자석의 문: 정답이면 12초간 주변200픽셀 보석을 높이에 관계없이 자동 수집. 여우 동료는17초.
3. 위더 봉인: 정답으로 보스 봉인을 해제하고 마지막 돌진으로 완주.

정답마다 영구 마법 보석10개·보호막1개·점수300을 준다. 능력 시간은 실제 달리는 시간에만 흐르고, 문제·보상·일시정지 중에는 소비하지 않는다. 정답을 풀지 않으면 다음 구간으로 갈 수 없다. 급하게 점프를 실패하더라도 모은 수학 보상을 잃거나 처음부터 돌아가지 않는다. 부딪치면 보호막을 사용하거나 잠시 느려지고 콤보가 끊긴다.

## 문제

포켓몬 게임과 같은 `learningQuestion`, `levelForType`, `renderLearning`을 재사용한다. 이야기 비교/합치기/두 번 빼기, 표와 이야기, 빈 빼는 수, 구구단, 받아올림, 대화 숫자 수수께끼, 숫자 카드 조건 세기를 무작위로 출제한다. 최소 레벨3이며 고정레벨4 유형은4로 유지한다. 문제 seed를 관문별로 저장해 새로고침으로 문제를 바꾸지 않는다. 기존 문제 데이터나 난이도는 수정하지 않는다.

## 수집·성장

햇살 숲·수정 동굴·노을 구름 성의 세 코스를 제공하며 완주로 순차 개방한다. 지면은 이어지고, 점프/슬라이드 장애물은 일정 간격과 관문 완충 구간으로 배치한다. 기본 이동 기준 약90초이며 문제를 읽는 시간은 제외한다. 코스별 색상과 배경을 바꾸고 기존 Minecraft 스프라이트로 동료와 보스를 그린다.

슬라임은 기본 동료(3단 점프), 1회 완주로 여우(자석+5초), 3회 완주로 워든(시작 보호막3개)이 열린다. 동료는 출발 전에 선택한다. 완주 보상은 점수·보석이며 개인별 최고점·누적 완주·문제 성공 횟수를 저장한다.

## 저장·복구

관문 정답 보상은 solved 마커와 누적 보석을 같은 저장에 기록한다. 중복 제출·새로고침으로 재지급하지 않는다. 완주 시 active를 제거하고 보상을 기록하므로 완주 보상도1회다. 진행 위치·코인/장애물 처리 IDs·관문seed/정답·남은 능력 시간을 저장한다. 재접속은 ‘이어서 달리기’로 시작하며 자동으로 진행 시간을 소모하지 않는다. 포커스/가시성을 잃으면 달리기를 일시정지한다.

## 검증

- `node tests/platformer-runner-model.cjs`: 관문 통과 제한, 실제 돌진속도·파괴·자석, 중복 보상 방지, 이어하기, 개인 저장 분리, 이전 저장 보존.
- 서버 실행 후 `node tests/platformer-runner-browser.cjs`: Chrome와 WebKit 터치, 오답·힌트·재도전, 문제 중 정지, 정답/완주 보상, 새로고침, 전체 한 판과 동료 해금.
- 공용 Next 경로와 기존 모험 부팅, 820픽셀 문제 UI 수평 넘침 없음도 확인.

이번 범위의 코스는 러너용으로 새로 구성했다. 기존 수평/수직 탐색 맵을 자동 달리기로 강제 이동시키지 않는다. 문제 입력 중에는 native dialog를 사용해 뒤쪽 조작을 차단한다.
